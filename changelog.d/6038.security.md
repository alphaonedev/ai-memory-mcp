The Fork-PR refusal in `ci.yml` now runs on docs-only pull requests (#6038). It was skipped when the change touched only documentation, while the checkout on the self-hosted legs that follows it is unconditional, so a fork's tree could be checked out on a self-hosted runner. The refusal's condition now uses the same `docs_only != ''` form as the rest of the workflow, so it runs before every self-hosted checkout.
