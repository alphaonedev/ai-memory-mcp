**Release feature guard: removing a docker job key is one message (#4984).** Removing `jobs.docker.permissions` (or any pinned `DOCKER_JOB` key) gave two messages for one drift, the key-set message and a "is missing" message. A missing key is now reported once, by the key-set message, which still refuses (exit 1) and names `DOCKER_JOB`. Pinned by a message case and a condition mutant; no refusal is loosened.
