**The doc symbol-anchor gate's absent-path exemption no longer covers a qualified anchor or a "split by" line.** `scripts/check-doc-symbol-anchors.sh` skipped its missing-file checks for every `src/...rs` anchor within one line of any line matching `ABSENT_ASSERTION`, and that regex held the bare word `split`, so a line such as "split by #1670" hid a mistyped or deleted file in a `path::symbol` anchor on it (#5201). A qualified anchor (`path::symbol`, backticked or not) now always requires its file to exist, whatever the wording; the bare `split` is replaced by `split into|out|from|off`, `was|been|got split` and `pre-split`, which still say a file is gone. Measured: 2 doc lines turned red (`docs/RECURSIVE_LEARNING.md:175` is a real "pre-split" assertion, now matched by `pre-split`; `CLAUDE.md:1725` names the placeholder `src/path.rs`, now an allowlist entry). A plain path or line anchor next to the remaining absence wording ("formerly", "pre-split", "renamed to", "monolithic", "split from") is still exempt over the three-line window; "split into", "split out" and an arrow exempt only an anchor before them (#5264). The `--self-test` gains seven cases.
