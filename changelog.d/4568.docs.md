**The enterprise deployment guide and the security guide no longer present `RUST_LOG=ai_memory=info` as the default or as the filter to enable.** The default log filter is the bare level `info` (`DEFAULT_LOG_DIRECTIVE`, #3650); the docs now say so. A `RUST_LOG` directive is added on top of that base, so `RUST_LOG=ai_memory=info` does not drop other targets; the `[logging]` file, stdout and syslog sinks do not read `RUST_LOG` and filter on `[logging].level` alone, where a target-prefixed value such as `ai_memory=info` does leave out events from other targets (#4568).
