**Assertion and error messages no longer render the secret they guard (#9017).** A negative leak check (`assert!(!output.contains(secret), ...)`) printed its haystack, which holds the secret exactly when the check fails; more than a hundred such messages under `src/cli`, `src/federation`, `src/handlers`, `src/daemon_runtime*` and `src/config_redact.rs` now name the case instead, and secret-valued loop needles are reported by index. `ai-memory doctor --remote <url>` no longer renders the operator URL verbatim in the report source, the Capabilities note or the HTTP-status error: it renders `scheme://host[:port]/path` only (an ambiguous authority renders `scheme://<redacted-authority>`), so a userinfo password or a query-string token cannot reach doctor output. `tests/codeql_cleartext_msgs_6581_6587.rs` locks the class (Refs #6581 #6586 #6587 #8741).
