**Box-drawing, macron and Ogham dashes inside a script name are caught by the compliance script-name gate (#6633).**
U+2500, U+2501, U+23AF, U+23BA, U+2E0F, U+00AF and U+1680 fold to `-`, and any non-ASCII character
inside a name marks it as a look-alike, so `check-old` + U+2500 + `x.sh` is no longer read as prose.
