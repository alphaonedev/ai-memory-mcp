**Consolidate drops the source attestation (#8532, umbrella #8493).** `memory_consolidate` merged every source metadata key except `agent_id` onto the consolidator-owned row, so a stale `write_signature`, `agent_pubkey`, `pubkey_bound_at`, `attestation_downgraded` or `forged_signature_skipped` (and, on the substrate/curator path, a source `agent_attested` level) landed on a row the sources never signed. Both backends now call `identity::attest::reset_for_reowned_row` (`reowned_by_consolidate`) unconditionally and the merge loop skips attestation keys, so the row reports `claimed`.
