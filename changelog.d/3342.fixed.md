Add `embed_mode` on HTTP `POST /api/v1/memories`: `sync` (default) embeds on
the write path via `spawn_blocking`; `async` stores the durable row immediately
with `embed_status: pending`. A live embed-backfill worker (periodic + wake)
drains Pending rows on both backends without a daemon restart and exports
`ai_memory_embed_backfill_pending`. The create response always reports
`embed_status` and `embed_mode`.
