### Security

- **[governance] IPv4-mapped IPv6 host literals** ([#4415](https://github.com/alphaonedev/ai-memory-mcp/issues/4415)).
  `::ffff:a.b.c.d` and its hex form canonicalise to the IPv4 dotted quad on both
  the rule and the request side, so an IPv4 deny rule applies to the mapped
  spelling and the reverse.
