**The doc symbol-anchor gate refuses a qualified anchor whose `::` is followed by nothing it can read, instead of dropping it (#5698).** When the scanner read nothing after a `src/x.rs::` head (the end of a code span, a glob `*`, an ampersand, a hash, a minus, a lifetime, a parenthesised or bracketed name, a name starting with a digit), or the head was followed by an empty brace list `{}`, the anchor produced no finding and the gate passed. Each is now refused as `UNMODELLED`, backticked or not, cited as written up to the next whitespace or backtick; the `UNMODELLED` detail text and the header name the new case. Base: accepted; tip before this fix: accepted; now refused. Real tree: 0 lines change. The `--self-test` gains 9 cases (#5698).
