**The linux-fed test slot is no longer held while the tests compile (#9511, #9733).**
The `Run tests (impact-aware)` step of the self-hosted linux-fed enterprise-fed
leg took its host test slot before `cargo test --no-run`, so one job held a slot
for 12107 s, 6466 s of it compiling. The step now runs twice: a build phase
compiles every test binary and runs the doc tests under its own build semaphore
(`linux-fed-build`, 1 slot, `BUILD_SEMAPHORE_MAX_WAIT_SECS`, then it proceeds
without a slot and says so) with its own timeout (`BUILD_PHASE_TIMEOUT_SECS`),
and a red build ends the step with the compiler output and no slot taken; only
then the run phase takes the test slot and runs the prebuilt binaries, refusing
to run without the build phase's record. On that leg the load gate now only
measures (`LOAD_GATE_MAX_WAIT_SECS` 0), and the load-gate wait and every
semaphore wait are written as rows of the job summary.
