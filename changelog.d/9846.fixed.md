**CI: the host-slot wrapper refuses a gate its configuration does not hold (#9846).** `scripts/ci/host_semaphore.py` loads `scripts/ci/host_slots.json` (or `--config`) before it takes a slot: a `--name` that is not one of its gates, a repeated `--name`, a gate without a `serving_runners` list of strings, and a configuration that is missing, unreadable, not UTF-8 JSON or without a `gates` object each end as `infra-unknown-runner` with exit code 83 and one error annotation naming the reason, before any slot is taken or the command starts. A misspelled gate name no longer runs with its own fresh lock pool.
