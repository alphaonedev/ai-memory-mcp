Enterprise-fed CI can now run the class (a) Postgres test binaries side by side: behind `AI_MEMORY_TEST_PG_ISOLATE=1` (default off, exported only by the enterprise-fed configure step) `scripts/test/pg_isolated_binary.py` clones one database per binary from a locked age+vector template and runs up to eight at a time, with in-binary `--test-threads=1` unchanged, a `max_connections` budget check that fails closed, an idle-only sweep of orphaned clones, and a residual-serial list for binaries that share a loopback port or path (#6386, umbrella #6383).
