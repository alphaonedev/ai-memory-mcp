**The cert-expiry gate reports a removed `AI_MEMORY_FED_*` identifier even when its name is still mentioned elsewhere under `src/` (#6370).** Section 7 drift compared the set of identifier names at each tree, so removing the live definition from an unwatched file produced no `-AI_MEMORY_FED_*` drift whenever a comment, doc string, test literal or (after #6174) binary blob still named it, and the certificate kept claiming LIVE. The scan now counts occurrences per identifier (`extract_fed_id_counts`) and `fed_id_delta` reports a name whose count fell as removed, annotated with the count change; names new to the head are still the only additions, so an extra mention of an existing identifier is not drift. The `(mask)`, `(mask-gate)` and `(mask-drift)` cells pin the removal (check_change, pull_request and the bound-tree `wire_drift` path) and `(mask-add)` pins that an extra mention stays GREEN.
