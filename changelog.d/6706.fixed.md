**The cert-expiry context check recognises eight more unconditional exits (#6706).** `std::process::abort()`, `::std::process::exit(0)`, an imported `exit(0)`, `std::panic!`, `assert!(false)`, a bare block that returns, `let _ = return ..` and an `if true` block that returns all made the following guarded line unreachable while the gate stayed GREEN. Each is now an exit finding, pinned by the eight `(wrap-exit-*)` cells; an unlabelled break inside an inner `while` no longer counts as a break of the outer `loop` `(wrap-loop-inner-break)`.
