### Security

- **[governance] `network_request` port semantics** ([#4414](https://github.com/alphaonedev/ai-memory-mcp/issues/4414)).
  A rule without a port now matches the host on any port; a rule with a port
  matches only the same effective port (explicit, else the scheme default). The
  LLM client and federation peer POST pass the URL's explicit port to the gate.
