**The env-mutation gate treats a spawn closure bound to a variable as detached (#8033).** `let work = move || { .. }; std::thread::spawn(work);` ran the closure outside the guard of the enclosing fn, but the gate let it inherit the lock. When a spawn argument is a bare identifier, the `let` closure or async block it names in the same fn is now a detached span. Test-infrastructure only.
