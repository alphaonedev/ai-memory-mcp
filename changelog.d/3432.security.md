Redact secret values from every config-printing CLI verb. `config migrate
--dry-run` printed the whole resolved config table in cleartext (including
`[reranker] api_key`, the legacy top-level `api_key` and
`[hooks.subscription] hmac_secret`), `config migrate`'s parse arms
interpolated the `toml` crate's error `Display` — which echoes the offending
source line — and `install`'s dry-run diff printed the MCP client config's
`mcpServers.<x>.env` API keys. All of them now render through one shared
redaction funnel (`src/config_redact.rs`) that masks secret-named fields at
any depth and screens every remaining string for credential-shaped values.
The redaction is display-only: `config migrate` and `install --apply` still
write the operator's real secrets to disk.
