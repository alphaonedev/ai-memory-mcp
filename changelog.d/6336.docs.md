**PR template and AI developer workflow: "Decisions" table and "Review log" so review rounds stop re-litigating settled findings (#6336).**

`.github/PULL_REQUEST_TEMPLATE.md` gains a Decisions table (Decision | Rationale | Where decided) and a per-round Review log. `docs/AI_DEVELOPER_WORKFLOW.md` section 8.4.1 requires the conductor to copy each A2A decision, with its message id, into the Decisions table when it is made, and adds the reviewer rule: a finding that contradicts a settled decision is reported only with a new `file:line` fact, labelled `RE-OPEN: <decision>`, otherwise omitted; a verdict lists earlier findings verified as fixed by sha instead of restating them. Documentation and process only; no code, schema or CI change.
