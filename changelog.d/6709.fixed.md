**A clean copy of a guarded line can no longer mask its disabled original in the cert-expiry context check (#6709).** `wrap_delta` reported a new finding only when an occurrence was lost, so compiling the original out while adding a clean copy in a dead function kept every base occurrence and stayed GREEN. When nothing is lost, a head occurrence carrying findings the base never had for that line is now reported `(wrap-mask-copy)`; a line the base never had stays with the per-line check `(wrap-ctl-new-line-cfg)`. decision: a verbatim copy of an existing guarded line added inside `#[cfg(test)]` is now RED over keeping the mask open, because a false positive costs a cert-doc touch while the mask hides a disable.
