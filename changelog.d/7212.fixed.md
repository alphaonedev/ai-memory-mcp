**The PG wrapper keeps a name owned when the backend settle times out, instead of disowning it (#7212).**

`drop_base` and the setup template cleanup logged a warning and carried on when `settle_backends` returned False, which could disown a name a live backend of the run was still creating. The name now stays owned (the drop is not attempted), `drop_base` returns False and the template cleanup raises, so the run exits 4 and names what to drop by hand.
