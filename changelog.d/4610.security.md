### Security

- The `infra/aws-gpu-burst` memory cloud-init no longer relies on an operator-supplied database password: like the do-hive template it ships only the `CHANGEME` placeholder, mints the role password on the node (`openssl rand`) and stops if the placeholder survives, so no password is ever in instance user-data, which the metadata service serves to every local process (#4610, #4788, CWE-214). `spawn.sh` writes the tfstate copy owner-only.
