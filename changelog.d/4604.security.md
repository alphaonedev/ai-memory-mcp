### Security

- The `infra/do-hive` and `infra/aws-gpu-burst` cloud-init templates feed the `CREATE USER ... PASSWORD` statement to `psql` from a 0600 SQL file on stdin instead of a `psql -c` argument, write the PgBouncer `userlist.txt` under `umask 077`, and render the do-hive `provision.sh` mode 0700 (root only) instead of 0755. `provision.sh` creates its log 0600 before the `tee` opens it and switches xtrace off around every line that handles the password, so the password no longer reaches a world-readable provision log. The gate rules `psql-password-argv`, `cloud-init-readable-secret` and `xtrace-secret` and a dummy-password runtime probe in `scripts/check-docs-no-argv-secrets.py --self-test` pin this. (#4604, #4609)
