A set-but-blank (empty or whitespace-only) `AI_MEMORY_INFERENCE_EGRESS` now fails closed to `deny` with a WARN naming the remedy, instead of silently resolving to `allow`; only an unset knob keeps the legacy `allow` default. A templated `AI_MEMORY_INFERENCE_EGRESS=` on an existing node therefore turns inference off until the variable is unset or set to an explicit mode (#6686, 3-agent vote 6def5ab6, #6053).
