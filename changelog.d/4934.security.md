### Security

- A Postgres DSN that sqlx cannot parse no longer leaks credentials into the `parse url:` error. The driver's parse text interpolates the value it rejected (for example a secret pasted into the `ssl-mode` alias of the screened `sslmode` key), and the userinfo-only URL masker never touched it. The text is now dropped and the error carries only the allowlist rendering of the DSN (scheme, host, port, database). Stale "URL-redacted" comments corrected. (#4934)
