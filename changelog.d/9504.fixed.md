**The schema-behind repair text is per backend and fails safe (#9504).** A
database that is behind this binary used to be told the SQLite repair
whatever the store was, and a backend label the binary did not know fell to
the SQLite command. The refusal now names the PostgreSQL command
(`ai-memory schema-init --store-url <url>`, a `sal` verb) for a PostgreSQL
store, the SQLite command for a SQLite store, and for any other label a text
that says the backend is not known and names no command. One function
(`schema_behind_repair_clause`) builds the text with an exhaustive match on
the backend, and a table test pins every label, its near-miss spellings
(case, spaces, prefix, suffix, empty) and the unknown row with exact text.
