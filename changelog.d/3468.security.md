`ai-memory wake-hub` verifies scoped `a2a-hub/join/v1` delegations under the
current proven v97 identity root. `identity delegate --scope a2a-hub` resolves
SQLite or PostgreSQL enrollment before signing with the matching local key.
The fresh delegated key can authenticate to one named hub; its certificate uses
a separate signing domain and grants no attested-write authority. Legacy,
unknown, closed and retired roots are refused. Proven guardian-recovery roots
are accepted.

`identity hub-cache` derives public root and delegated-key revocation snapshots
from either backend, records changed allow/revoke decisions in the existing audit
spine, then publishes an atomic 0600 file. Unchanged refreshes add no audit rows.
The hub remains store-free. Snapshots expire after 60 seconds and sessions are
rechecked every second, including idle listeners; certificate expiry remains
bounded. Audit failure or record-stop prevents publication. Audit records describe
publication intent, so a subsequent filesystem failure may leave that snapshot
unpublished while the previous snapshot expires normally.

Bundle writes refuse existing files and symlinks before writing private bytes.
Cache reads enforce ownership, exact 0600 mode and regular-file status on one
no-follow descriptor. Empty and 129-byte identities fail before lookup; every
identity refusal is the same `401 unauthorized`. Subscriptions are limited to the
authenticated principal's own inbox at hello and on subsequent subscribe frames.

Peer credentials are checked before capacity, so unauthorized peers receive no
bytes even at the connection ceiling. The handshake frame budget grows to 1536
bytes for the delegation; routed wakes remain capped at 256 bytes. No schema
rung, MCP description, fleet ceiling or release branch is changed.
