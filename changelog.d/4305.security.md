**A forensic log file with a second hard link is refused.** A hard link is a regular file, so a daily forensic file hard-linked to a name outside the audit directory was accepted and every append also landed under that name. Forensic, head-anchor and restore-sanction log files with more than one link are now refused like a symlink (#4305). The witness head-anchor and restore-sanction logs are now also READ without following a link and without blocking on a FIFO, which #4273 had stated but only the appenders did; a FIFO head-anchor log used to hang every database open (#4303).
