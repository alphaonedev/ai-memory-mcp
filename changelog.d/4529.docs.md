**[docs] Architecture reference rows no longer claim a keyless daemon continues unsigned** ([#4529](https://github.com/alphaonedev/ai-memory-mcp/issues/4529)).
The `signed_events.rs` row and the `AI_MEMORY_REQUIRE_ENTERPRISE_FEDERATION_POSTURE` row of `docs/reference/ARCHITECTURE_REFERENCE.md`, and the identity paragraph of `docs/compliance/nsa-csi-mcp.html`, cited stale `src/main.rs` line numbers and described an unsigned-continue path the code does not have.
