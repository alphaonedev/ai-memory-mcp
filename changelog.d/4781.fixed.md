**doctor Webhook delivery totals no longer report a read fault as `0 dispatched / 0 failed` (#4781, WP-FAULT #6051).**
`doctor_webhook_delivery_totals` propagates the SQLite error instead of
`.unwrap_or(0)`, and the Webhook section renders `dispatched_total`,
`failed_total` and `success_rate_pct` as `unreadable` with a
`webhook_delivery_totals_error` fact at **Critical** — a fault on the delivery
table no longer looks like a healthy idle store.
