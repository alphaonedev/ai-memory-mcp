**CI: every script that prints a path, name, label or exception text into a workflow command or an output file now escapes it through one shared module (#9365).**
The escape of #8634 (finding L4) covered only `prune_runner_tmp.py`; the other CI
scripts put a runner name, a URL-file path, a `--label` or an `OSError` text raw
into `::error::`, `::warning::`, `::notice::` and `::group::` lines, so a newline
or a `::` in the value could start a second workflow command, and a newline in a
value written to `$GITHUB_OUTPUT` / `$GITHUB_ENV` could add a second entry. The
escape (`safe_text`) moved to `scripts/ci/workflow_annotation.py`, which builds
every annotation as exactly one line bounded at 1000 characters (`annotation`),
escapes property values (`property_value`), neutralises plain log lines that
carry a path (`log_line`) and keeps every `KEY=value` file line to one entry
(`env_file_value`). Swept: `host_semaphore.py`, `load_gate.py`,
`partition_test_binaries.py`, `pg_isolate_split.py`, `pg_env_preflight.py`,
`prune_runner_artifacts.py`, `prune_runner_tmp.py`, `tier_cred_preflight.py`,
`ci-sweep-target.py`, `pg_isolated_binary.py` and the env-file writers
`shared_cargo_target.py`, `sccache_env.py`, `impact/base_sha.py`,
`ci_full_nightly.py` and `impact/select.py`. The runner also reads the v1 form
`##[` anywhere in a line (actions/runner `ActionCommand.TryParse`), so a value
escaped by `safe_text` holds no line break, no `%`, no `::` and no `##[`, none
forms with a literal after it (a leading `[` stays readable, and no script
literal ends in `##`, a ratchet cell), and `annotation`, `render`, `join` and
`log_line` break every `##[` of the finished line; the plain log lines of the
14 scripts that print a value now go through `log_line`. Exit codes, labels and
every byte of a line without `##[`, `::` at its start or a line break are
unchanged. Tests:
`scripts/ci/tests/test_ci_annotation_escape_9365.py` (an AST ratchet over every
CI script plus per-script cells over a hostile corpus).
