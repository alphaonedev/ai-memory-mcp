**The compliance script-name gate now enforces the closed set of documents that may use `:pinned` (#6173).**
The `:pinned` suffix in `scripts/qc-allowlists/compliance-script-names-allow.txt` was
accepted for any `docs/compliance/` document, so one ledger token could re-open #6170 (an
erratum removed from a document, its entry marked `:pinned`). `scripts/check_compliance_script_names.py`
now holds a closed `PINNABLE_DOCS` set (`v1.0.0-DECLARATION.md`, guarded by the SHA-256
declaration pin, and `ENTERPRISE-FEDERATION-CERTIFICATION.md`, guarded by the cert section 7
gate). A `:pinned` entry for any other document fails, and so does a `:pinned` entry for a
document that carries its own erratum for the name ("unnecessary :pinned").
