Self-hosted CI jobs that run `cargo test` (the `check` matrix, `cert-postgres-age`, `postgres-ignored`, the macOS `lifetime-tests` leg) now set `CARGO_PROFILE_DEV_DEBUG` and `CARGO_PROFILE_TEST_DEBUG` together and end with an always-run `scripts/ci/prune_test_binaries.py` step that deletes only the test executables in `target/debug/deps`, so a full test build no longer leaves ~164 GB per runner on the shared disk while the warm `.rlib` cache stays (#6118).
