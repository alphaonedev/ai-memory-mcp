- **A signed `memory_store` that merges into an existing row no longer lands
  the merged row `claimed` (#10011).** The same-title merge detour and the
  synthesis merge rewrite content through `db::update`, which never mints an
  attestation. A session-sealed or caller-signed store now re-signs the merged
  row as stored with the stdio session signer, verifies it against the bound
  key and persists `attest_level` and `write_signature` in the same write
  transaction. When no session signer covers the agent the merge is refused
  with `ATTESTATION_FAILED` and rolled back, so the existing row is left as
  it was.
