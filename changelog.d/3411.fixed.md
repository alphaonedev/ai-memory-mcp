**`boot` is actually read-only (#3411).** A missing `--db` is refused
(`database does not exist; refusing to create (read-only)`) instead of
`Connection::open` creating the file and running the migration ladder.
`--quiet` yields empty stdout on an unavailable DB (the clap / module /
CLI_REFERENCE contract). Global `--json` is honoured as `--format json`
when `--format` is left at its default (same for `export-reflections`).
A `--db` whose schema stamp is behind this binary is a typed
`SCHEMA_BEHIND_READ_ONLY_REFUSAL` (warn header, both versions, repair
`ai-memory migrate --in-place` / start the daemon) rather than a raw
SQL failure; the file is not migrated. Regression:
`boot_missing_file_in_existing_dir_is_not_created_3411`,
`boot_quiet_with_unreachable_db_is_silent_3411`,
`apply_global_json_overrides_default_format_3411`,
`boot_warns_on_schema_behind_read_only_3411`.
