**`boot` is actually read-only (#3411).** A missing `--db` is refused
(`database does not exist; refusing to create (read-only)`) instead of
`Connection::open` creating the file and running the migration ladder.
`--quiet` yields empty stdout on an unavailable DB (the clap / module /
CLI_REFERENCE contract). Global `--json` is honoured as `--format json`
when `--format` is left at its default (same for `export-reflections`).
