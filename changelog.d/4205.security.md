**A row appended after a torn, unterminated last line is no longer glued to it and dropped from a signed log.**
A crash mid-write can leave a forensic log file, the witness head-anchor log
or the restore-sanction log ending in a torn fragment with no trailing
newline. The next appended row used to be written straight after the
fragment, on the same line, so it could not be parsed: the forensic chain
then continued past it and one signed row silently dropped out of the chain.
All three logs now start the new row on its own line, and the torn fragment
stays a separate line that the readers skip (#4205).
