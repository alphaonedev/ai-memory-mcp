**SQLite write transactions now open `BEGIN IMMEDIATE` (#5084, the #2250 class).** Thirteen production functions (14 transaction sites; `mine` has two) opened a DEFERRED write transaction: 8 read first and then wrote, and 5 wrote first. For the read-then-write eight, a concurrent writer that commits inside the read-then-write window makes the lock upgrade fail at once (`SQLITE_BUSY_SNAPSHOT`, error code 517), which `busy_timeout` does not retry, so a write that should have waited for the lock instead failed. All thirteen now use `WriteTxn::begin` (BEGIN IMMEDIATE with rollback on drop). Read-then-write: `create_guarded`, `materialize_template_for_caller`, `mine` (both transactions), `generate_in_scope`, `stamp_contaminated_descendants_as`, `set_embeddings_batch`, `rekey_peer`, `reclassify_memory_kind`. Write-first: `set_embeddings_batch_reembed` (its plan read precedes the transaction), `sweep_expired_leases_reclaim`, checkpoint `resolve`, `run_repair_schema_version`, `sweep_pending_action_timeouts`. `WriteTxn::begin_deferred` and `SQL_BEGIN_DEFERRED` are removed so the helper can no longer open a deferred write transaction. The two read-only snapshots (`policy_version::with_read_snapshot` and the `keys prune` preview) stay DEFERRED and are allowlisted with a reason. New gate `scripts/check-sqlite-write-txn-immediate.py` (with `--self-test`, run by `tests/sqlite_write_txn_immediate_gate_5084.rs`) refuses the transaction-open forms it scans for in `src/` outside that allowlist; it is not a complete closed-world check, and the known gaps are tracked in #5231, #5232, #5233, #5234 and #5235. Five regression tests (`rekey_peer`, `set_embeddings_batch`, `stamp_contaminated_descendants_as`, `reclassify_memory_kind`, `set_embeddings_batch_reembed`; `*_is_immediate_5084`) fire a second writer inside the window and all five fail on the old DEFERRED code (measured: `0 passed; 5 failed`): three with error code 517, `reclassify_memory_kind` with a wrapped `database is locked`, and `set_embeddings_batch_reembed` because the second writer commits inside the window. The other eight conversions have no regression test; that gap is tracked in #5243.
