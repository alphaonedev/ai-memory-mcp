**The doc symbol-anchor gate no longer carries a dead duplicate of the commit-pin rule.** `PIN_URL` in `scripts/check-doc-symbol-anchors.sh` required a 40-hex commit sha, and `PIN_TARGET` independently required the same anchored GitHub prefix plus 40 hex, so loosening `PIN_URL` alone changed nothing and left a reader believing it still guarded the pin (#5214). `PIN_TARGET` is now the single owner of the pin rule; the abbreviated-sha, hex-named-branch and query-string self-test cases keep guarding it.
