**The compliance script-name gate finds a stale script name in every written form (#6195).**
`scripts/check_compliance_script_names.py` recognised a name only when a backtick span
held exactly `check-*.sh` / `check_*.py`, optionally prefixed `scripts/`. A name with an
invisible format character (soft hyphen, zero-width space or joiner), inside a fenced code
block, in prose, in a URL, or written as `bash scripts/...`, `./scripts/...` or
`scripts/<subdir>/...` passed. The gate now matches the name anywhere on a line, bounded by
non-name characters, after removing Unicode format characters (category Cf) from document
lines. The allowlist reader stays strict, so a ledger entry with a hidden character is still
malformed or stale.
Invisible characters outside category Cf (variation selectors, the combining grapheme joiner,
Hangul fillers, Khmer inherent vowels, Mongolian free variation selectors) also hid a name;
document lines now drop every Default_Ignorable_Code_Point as well, from an explicit range
table in the gate.
