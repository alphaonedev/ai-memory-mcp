**The lab probe matcher no longer reads its log through a here-string (#5197).** A here-string spills a large value to a temp file under `$TMPDIR` (`/tmp` when unset), so a large probe log wrote outside the lab scratch directory. The matcher now reads the file with one awk pass; the structural posture self-test leg is an allowlist (#5539): the matcher body must equal the one allowed statement (one awk command, its program, `"$1"` and one stderr redirect to `/dev/null`), so a here-string, a here-document, a pipe, process substitution, a temp file made by any command or redirect, an extra statement or a changed awk program is refused, and one self-test leg per spelling pins it.
