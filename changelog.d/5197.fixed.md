**The lab probe matcher no longer reads its log through a here-string (#5197).** A here-string spills a large value to a temp file under `$TMPDIR` (`/tmp` when unset), so a large probe log wrote outside the lab scratch directory. The matcher now reads the file with one awk pass; a structural posture self-test leg rejects a here-string, a here-document, a pipe or a temp file.
