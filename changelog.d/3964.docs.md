**#3964 — README no longer claims a per-module coverage floor for every module.**

`coverage/check-thresholds.sh` iterates only the `[modules]` table of
`coverage/thresholds.toml`; a file in the coverage report that is not in
the table is never evaluated. The README's "Features" bullet and the
"Coverage Floor (hard CI gate)" section now say the per-module floor
applies to the listed modules only (179 entries against 545
`src/**/*.rs` files, measured with `git ls-files` at `371b15413`), and that
unlisted files are held only by the global floor. The gate itself is
unchanged; enroll-by-default stays tracked in #3964.
