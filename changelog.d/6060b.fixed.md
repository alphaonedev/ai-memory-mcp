### Fixed

- **[sdk-python, ci] The live-test harness always stops what it started, and its job is hardened** (umbrella
  [#6060](https://github.com/alphaonedev/ai-memory-mcp/issues/6060), round 7).
  `scripts/sdk-python-live.py` stops `ai-memory serve` and `ai-memory wake-hub` on every exit: a startup error of
  any kind (exit 2), and SIGINT, SIGTERM or SIGHUP (exit 128+N), with termination signals ignored while it tears
  down ([#6812](https://github.com/alphaonedev/ai-memory-mcp/issues/6812)). The daemon port defaults to a free
  loopback port instead of 9077 ([#6831](https://github.com/alphaonedev/ai-memory-mcp/issues/6831)). The
  clients-ci `sdk-python-live` job checks out with `persist-credentials: false`
  ([#6813](https://github.com/alphaonedev/ai-memory-mcp/issues/6813)), runs the harness as `python -I`
  ([#6814](https://github.com/alphaonedev/ai-memory-mcp/issues/6814)), and also runs on changes to
  `migrations/**`, `vendor/**` and `rust-toolchain.toml`
  ([#6830](https://github.com/alphaonedev/ai-memory-mcp/issues/6830)).
- **[sdk-python] Review pins that a stale or tampered input now fails.** The wake-boundary pin of
  `sdk/python/ai_memory/wake.py` is re-pinned after its format-only edit, and a Python test compares every
  `sdk-source-bytes` pin with the file so the Python job sees drift too
  ([#6864](https://github.com/alphaonedev/ai-memory-mcp/issues/6864)). The reduced #6721 swarm journal is pinned
  by content and row counts ([#6832](https://github.com/alphaonedev/ai-memory-mcp/issues/6832)). New tests pin
  the post-load inode re-check of a CA file ([#6816](https://github.com/alphaonedev/ai-memory-mcp/issues/6816)),
  that a CA directory loads only hashed entry names
  ([#6835](https://github.com/alphaonedev/ai-memory-mcp/issues/6835)), and that a verified direct-leg session
  leaves a pending proxy leg pending ([#6836](https://github.com/alphaonedev/ai-memory-mcp/issues/6836)).
  Regression tests: `sdk/python/tests/test_ci_live_harness_6060_r7.py`,
  `sdk/python/tests/test_wake_boundary_pin_6864.py`, `sdk/python/tests/test_tls_ca_path_6060_r7.py`,
  `sdk/python/swarm/tests/test_rubric_repair.py`.
