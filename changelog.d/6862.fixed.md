### Fixed

- **[ci-gate] cert-expiry banner Binds-to sha is refused when a word character follows the hex run**
  ([#6862](https://github.com/alphaonedev/ai-memory-mcp/issues/6862)).
  The right boundary added for #6624 only stopped a following hex digit, so a 40- or 64-hex value followed directly by `g`, `z`, `_` or a Unicode digit (Arabic-Indic, fullwidth) was captured as its 40- or 64-hex prefix, a sha the document never states. The lookahead is now `(?!\w)`; punctuation, whitespace and the closing backtick still end the value. Self-test cell (x3) pins each of those values refused and a following period or comma accepted.
