**Atomic config replace with pre-replace backup for `governance migrate-to-permissions` (#10257).** Both in-place merges and `--config-out` writes in `src/cli/governance_migrate.rs` now refuse symlinks at the destination (`#8950`), write a durable owner-only `<file>.bak.<UTC %Y%m%d-%H%M%S>` backup via `snapshot_file::write_new_private_unique` before replacing any existing file, and replace through `snapshot_file::write_replacing` + `require_durable` (mode `0600`, fsynced file and parent directory). A directory fsync failure keeps the complete new file and returns the typed `NotDurable` error without printing a success line.
