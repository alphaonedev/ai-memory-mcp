**The AWS burst cloud-init memory template now starts a daemon (#4616, #4619).** `infra/aws-gpu-burst/cloud-init-memory.yaml.tpl` follows the do-hive precedent: PostgreSQL 18 from PGDG with pgvector and Apache AGE built from source (the apt PG16 package has no AGE), a per-node API key and a self-signed TLS pair minted on the node, and `serve --host --port --tls-cert --tls-key` (serve refuses a keyless non-loopback bind and any plaintext bind). Both memory templates now create `/etc/ai-memory` mode 0700 in `bootcmd`, so the cloud-init write-then-chmod of the store-URL file leaves no window for another UID. New gate `scripts/check-cloud-init-serve-flags.py` (job `cloud-init-serve-flags-gate` in `c8-precheck.yml`) fails on a serve flag that is not a `ServeArgs` field, a missing TLS flag, or a non-ASCII byte.
