**The `--self-test` size check is derived from the tree, not a hand-typed floor (#7991).** `CORPUS_MIN_CASES = 130`
sat below the cases a full run executes, so a corpus that silently lost cases above the floor still reported OK.
`expected_corpus_cases` now counts the manifest entries plus the `test_` methods of the harness (by `ast`, without
importing it) and a full run must execute exactly that many; an unreadable manifest or harness fails closed, and the
explicit `--self-test-subset` form keeps its one-case minimum. Proof: `case_7991_exact_corpus_size` runs stub trees
with an expected size of 6 and ran=6 passes while ran=5, 7 and 0 and a missing manifest fail, and it asserts the real
tree derives `len(MANIFEST)` plus its `Ratchet` test methods.
