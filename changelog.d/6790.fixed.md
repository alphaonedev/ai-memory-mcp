**Lib tests no longer seed the DB-passphrase channel in the shared test process (#6790).**
`db::open` reads the passphrase request (the `AI_MEMORY_DB_PASSPHRASE` variable and the
process-private slot `--db-passphrase-file` fills) on every open, so a lib test that wrote it made a
concurrent, unrelated open fail with the sqlcipher refusal (`macos-fed,sqlite` shard). The two lib
tests that seed the slot now run in an isolated child process, the env-setter case moved to its own
integration binary (`tests/db_passphrase_refusal_6790.rs`), and a `scripts/ci/tests` cell fails the
build if a lib test sets or seeds the channel in the shared process again.
