**The PG wrapper no longer strands a minted database or template on SIGTERM, and its log no longer claims a release that did not happen (#7179).**

Names are owned before CREATE DATABASE and every wrapper psql call carries a per-process application_name. Cleanup cancels that application's backends (a killed psql leaves its CREATE DATABASE running on the server), waits until none remain, drops by name and confirms in pg_database. It reports `NOT released: <names>` and exits 4 when a name still exists, and the signal is re-delivered once the cleanup is proven.
