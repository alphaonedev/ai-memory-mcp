**A first namespace-standard bind above a subtree another principal governs is refused (#4713).** The #4356 ancestor-owner gate looks upward only, so a first bind at an unbound root segment (or an unowned rebind there) was admitted even when another principal already owned a bound `root/proj` below it, placing links and a policy above that governed subtree. The shared verdict now also folds the standards bound strictly below the target into a descendant-side decision: a foreign-owned governing descendant refuses the bind, a severed or dangling one fails closed with its own reason, and unowned, policy-less or caller-owned descendants (and the operator bypass) pass. Wired on the sqlite SET funnels (MCP, HTTP-sqlite, SAL-sqlite) inside the bind's write transaction; the postgres reader is tracked as the remaining half.
