**#5076 — the PgBouncer prepared-statement caveat in `docs/enterprise-deployment.md` section 5.6.6 now names every failure mode.** Besides "prepared statement does not exist", sqlx statement names (`sqlx_s_<n>`) restart on every client connection, so clients sharing one server connection can hit "already exists" errors or run a same-named statement another client prepared; `max_prepared_statements` above zero is stated as mandatory wherever server connections are shared.
