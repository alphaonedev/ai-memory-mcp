**`memory_agent_register` refuses a silent identity overwrite (#3372).**
Re-registering an existing agent id with a different `agent_type` or
`capabilities` used to overwrite the identity with no error and no record
of the prior value. It is now refused with a message naming the stored
identity; pass `update: true` to change it, and the audit row then records
`prior_agent_type` / `prior_capabilities`. An identical re-register still
refreshes `last_seen_at` as before. `update` is type-strict: a present
non-boolean is refused rather than read as `false`. Callers that relied on
the silent overwrite must now pass `update: true`.
