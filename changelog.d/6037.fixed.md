The append-only scratch janitor (`scripts/clear-append-only-scratch.py`) now escapes every character that can hide or reorder a name in its report (#6037): format characters (bidi controls such as U+202E and U+061C, U+200B, U+FEFF) are shown as escapes like control characters, a backslash is shown doubled so no name prints the same as another name's escape, and `%` is written as `%25` on `::error::` workflow-command lines, where the runner decodes it.
