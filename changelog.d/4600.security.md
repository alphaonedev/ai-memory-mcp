### Security

- `ai-memory schema-init` now resolves its store URL through the same ladder as `serve` (`AI_MEMORY_STORE_URL_FILE`, a 0600 file, then `AI_MEMORY_STORE_URL`, then the `--store-url` flag), so the database password no longer has to appear on the command line. With no channel set it fails closed with a message naming all three. The Postgres deployment docs and the `schema-init` examples in the CLI reference use the file form, and the allowlist entry for `schema-init` in `scripts/check-docs-no-argv-secrets.py` is gone.
