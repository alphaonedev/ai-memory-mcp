The janitor reports every path on one line (#6027). A name may hold a newline or any other control character; each C0 and C1 control character, DEL and the two Unicode line separators are now shown as a visible escape in every report line, so a name can no longer start a line of its own in the runner's log - a workflow command or a forged tally - or rewrite the log with an escape sequence. Names with such characters are still walked, journalled and put back exactly; only the report's rendering changes. Neither workflow that runs the janitor is reachable from a fork.
