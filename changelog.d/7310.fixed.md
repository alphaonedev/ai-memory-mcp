**zip-extract guard catches build-time generated modules (#7310).** A `mod name;` whose file is not where cargo looks (`name.rs` / `name/mod.rs` beside a crate root or `mod.rs`, under `<stem>/` for any other file) fails, as does a manifest-declared lib/bin/build path with no file on disk (only a build step could create either), and build scripts are scanned with their string bodies kept (comments still masked).
