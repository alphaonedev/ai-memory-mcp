- **Lib-test child processes no longer reach the operator's real home
  directory (#10176).** Fourteen lib tests that re-run the test binary as a
  child now build it through one shared `SandboxedTestChild` in
  `src/test_support.rs`, which gives the child a private `HOME`,
  `XDG_CONFIG_HOME` and `AI_MEMORY_WITNESS_KEY_DIR` applied after every caller
  setting, so the sandbox always wins. A source ratchet
  (`tests/test_child_spawner_isolation_10176.rs`) fails when any file under
  `src/` other than `src/test_support.rs` spawns the current test executable
  outside its reviewed allowlist.
