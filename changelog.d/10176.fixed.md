- **Lib-test child processes no longer reach the operator's real home
  directory or key custody (#10176).** Every lib test that re-runs the test
  binary as a child now builds it through `SandboxedTestChild` in
  `src/test_support.rs`. The child's environment is built from nothing: it is
  cleared, then given a short named allowlist plus a private `HOME`,
  `XDG_CONFIG_HOME`, `XDG_STATE_HOME`, `XDG_RUNTIME_DIR`, `XDG_DATA_HOME`,
  `XDG_CACHE_HOME`, `TMPDIR` and `AI_MEMORY_WITNESS_KEY_DIR` under a fresh 0700
  sandbox, and its working directory is the sandbox root. The builder has no
  method that hands out or accepts a raw `Command`; a caller-supplied
  variable is refused when it names an isolation or key-custody variable or
  a path outside the sandbox.
- **A new place that can start a process is a gate failure until it is
  allowlisted (#10176).** Layer 1 is clippy: `clippy.toml` lists every
  process-start entry point this repository can call (the std and tokio
  `Command::new`, the `assert_cmd` constructors, the two #1937 chokepoints
  and the libc `fork`/`exec`/`spawn`/`system`/`syscall`/`dlopen` family)
  under `disallowed-methods`, and `src/lib.rs` re-denies the lint, so the
  compiler resolves every alias, re-export, macro and function pointer. Each
  justified call carries an item-level `#[expect(clippy::disallowed_methods,
  reason = "...")]`, and `tests/spawn_gate_pins_10176.rs` holds one fulfilled
  expectation per entry. Layer 2
  (`tests/test_child_spawner_isolation_10176.rs`) makes every lint silence,
  inner silence, `extern` block, inline assembly, out-of-tree `#[path]` or
  `include!` and runnable doctest an exact per-file allowlist row, refuses
  macro-built lint names, silences on a whole module, `impl` or `trait`,
  escaping paths and symbolic links, and pins `clippy.toml`, the
  `src/lib.rs` lint lines, the toolchain, the `Cargo.toml` lint table and
  `.cargo/`. What the two layers do not prove: a second process start inside
  an item that already carries the expectation; code that no clippy job
  compiles; a lint switched off by a build flag outside the tree; and a
  process started by a dependency's own code or by a program that is not
  built from this repository.
