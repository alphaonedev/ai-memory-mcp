Tests share an explicit temporary key-directory helper across unit and integration
builds. A test-support resolver guard panics before accessing any key directory
under HOME. `doctor` reports orphan key files using the configured SQLite or
PostgreSQL agent registry; `keys prune --dry-run` previews them. Pruning requires
`--yes` to delete, retains registered and system authority keys, and skips symlink entries.

Enrolled public-only peer and guardian keys are reported separately by `doctor`
and `keys prune`; deleting them requires both `--include-public-only` and `--yes`.
