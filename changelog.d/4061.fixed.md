MCP `memory_update` refuses a present, non-null `expected_version` that is not a JSON integer (string, boolean, fraction, out-of-i64) with a typed parameter error before any write, instead of reading it as "no precondition" and silently dropping the compare-and-swap fence; omitted/null keeps last-write-wins. The HTTP sibling now refuses a present `If-Match` header that names no integer version with 400 (the RFC 9110 wildcard `*` stays last-write-wins) instead of ignoring it (#4061).
