Tracing no longer logs memory titles. Four `warn!` sites (the why_trace write-provenance warning, the consolidation rollback conflict, and the two `sync_push` rejected-memory skips) put the memory title into stderr and every configured log sink, contradicting docs/telemetry.md. They now log the memory id and namespace. A source-census test (`tests/tracing_no_memory_payload_3990.rs`) fails on any tracing call site that reads a memory's title, content or metadata, and docs/telemetry.md and ROADMAP.md now name that enforcement (#3990).
