**The schema-v54 tier-default-expiry backfill now writes the canonical expiry rendering on its own (#2462).**
The v54 arm stamped legacy NULL-expiry mid/short rows with a `+00:00`,
no-fraction rendering and was correct only because the later v87 heal
normalised it. It now writes the fixed-width `YYYY-MM-DDTHH:MM:SS.ffffffZ`
form directly, so the lexicographically compared `expires_at` column no
longer depends on migration order.
