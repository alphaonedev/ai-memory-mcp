### Security

- The docs no longer teach `ai-memory agents bind-api-key --token <t>`, a form the CLI has refused since #3781 because a token on argv is world-readable; `docs/ADMIN_GUIDE.md`, `docs/compliance/nsa-csi-mcp.html`, `docs/compliance/nsa-csi-mcp-security-mapping.md` and `docs/reference/ARCHITECTURE_REFERENCE.md` now show `--token-file <0600 path>` (or `AI_MEMORY_AGENT_API_KEY_FILE`) ([#4865](https://github.com/alphaonedev/ai-memory-mcp/issues/4865)).
