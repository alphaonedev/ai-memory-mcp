**[release][supply-chain] The release binds compare each bound script with a SHA-256 the workflow pins, not with the job-writable object store (#6908, umbrella #6062).**
The #6275 bind read the expected content of the feature declaration, the
asserter, the deterministic packer and the release-shape proof script from
the job's own `.git`. An earlier step could rewrite the object store (a
forged loose tree, an exploded pack, an alternate store, a redirected or
symlinked `.git`) together with the file, so the bind passed on a rewritten
script. Now every bind checks the files' SHA-256 against digests written in
the workflow text with `/usr/bin/shasum -a 256 -c -` and still requires `HEAD`
to be the verified preflight commit; any difference stops the job. The guard
recomputes each pinned digest from the tree and refuses a stale pin or a pin
of a file it does not bind. Chosen by `3-agent vote (6def5ab6)` (option A,
3-0). Regression: the `6908 ...` guard self-test cases and ten object-store
tamper forms in the runtime bind self-test.
