**The cert-expiry context check reports a guarded line inside a macro invocation's input (#6708).** `stringify! { .. }` or a local `macro_rules!` macro that expands to nothing discarded the guarded line while it stayed byte-identical. The input of any `name! { .. }` / `name!( .. )` invocation is now a finding, reported only when the change introduces it: `(wrap-macro-stringify)`, `(wrap-macro-local)`.
