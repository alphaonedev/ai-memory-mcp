**`check_cert_expiry.py`: the amendment ledger is judged on a canonical subset, not by a Markdown parser
(#6722, #6723, #6724, #6725, #6730, #6732).** The ledger reader modelled CommonMark and differed from
GitHub's renderer on list-item fences, indented code read as a fence, HTML openers inside a paragraph, a
mid-line `<!--`, bare-CR line endings and a collapsible section, so a record GitHub hides could be
accepted. Under design B (3-agent vote 6def5ab6, B 3/0) the gate no longer parses the ledger: from line 1
to the end of the blockquote holding the last amendment header only plain blockquote paragraphs, blank
`>` lines and record lines are accepted, and anything else there (fence, HTML, comment, tab, CR, nested
or indented `>`, indented code, setext underline, link definition, lazy line, invisible or bidi
character, a second STATUS line) is refused with its line number. CR and tab are refused in the whole
doc, and a fence, HTML block, comment or collapsible section left open anywhere in the doc is refused.
