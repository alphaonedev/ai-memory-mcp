**The doc symbol-anchor gate no longer accepts `<dyn 'a + Missing>::m` unchecked (a regression of the #5457 fix).** The self-type scan skipped `dyn` and then found no identifier at the lifetime, so the missing type was never checked and the line passed (it failed before #5457). A leading lifetime or `?Trait` bound of a bound list is now skipped like `dyn`, the type behind it is checked, and a self type that is only a bound (`<dyn 'a>::m`) is refused as an anchor the gate cannot decide. Real tree: 0 lines change. The `--self-test` gains 5 cases (#5493).
