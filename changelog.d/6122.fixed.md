Integration and unit test runs no longer leave orphaned sqlite `.tmp*-wal` / `-shm` side files, `.tmp*` directories, uuid-named `.db` files and `.pre-migration-*.bak` backups in `TMPDIR` (#6122). `NamedTempFile` removed only the primary file, and fixtures that parked a guard with `std::mem::forget`, in a `static`, or by re-pointing `HOME` at a dropped directory leaked everything. A shared `tests/common/tmp_retain.rs` helper (`SidecarTempFile`, `retain`, `DbFiles`) now removes the sidecars on drop and removes retained guards from a single process-exit hook; the audited sites use it, and `tests/tmp_leak_guard_6122.rs` pins that a store fixture leaves nothing behind. Test-infrastructure only; no production behaviour changes.
