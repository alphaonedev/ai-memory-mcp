### Fixed

- **[ci-gate] cert-expiry push lane: the all-zero "before" sha skip no longer accepts any length of zeros**
  ([#6201](https://github.com/alphaonedev/ai-memory-mcp/issues/6201)).
  `scripts/check_cert_expiry.py` tested `GITHUB_EVENT_BEFORE` against an all-zero pattern of any
  length (and tolerant of a trailing newline) ahead of the hex validator, so a malformed value of
  1, 5, 39, 41, 63 or 65 zeros skipped the gate (rc 0) instead of failing closed. The skip is now
  `fullmatch` on exactly 40 (SHA-1) or 64 (SHA-256) zeros; every other value reaches the hex
  validator. New self-test cells pin the 40/64-zero skip, the refusal of the malformed zero
  values with the validator message, and that a 40-hex value starting with zeros is judged, so
  dropping the end anchor or the length turns the self-test red. Further cells pin that 40 Arabic-Indic
  and 64 fullwidth zeros are refused, and that an all-zero `PR_HEAD_SHA` or `GITHUB_SHA` (pull_request)
  and an all-zero push `GITHUB_SHA` are judged rather than skipped.
