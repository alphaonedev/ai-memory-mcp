**Normative certification texts no longer name the deleted `check-cert-expiry.sh` as the N30 enforcer without an erratum (#6141).**
The cert §7 expiry gate was ported to `scripts/check_cert_expiry.py` (#6137, #6138)
and the shell file deleted, but the adopted certification standard, the ballot
procedure and the pinned v1.0.0 declaration still named the old path. The standard
and the ballot procedure are verbatim adopted copies, so each now carries an
`## Erratum (#6141)` block above its header comment naming `scripts/check_cert_expiry.py`
as the current enforcer; the erratum also covers the historical mentions in the pinned
v1.0.0 declaration (text and SHA-256 pin unchanged) and in the amendment history of
`ENTERPRISE-FEDERATION-CERTIFICATION.md`. New gate
`scripts/check_compliance_script_names.py` (run in the cert-expiry-gate job with its
self-test) scans the raw bytes of every `docs/compliance/` document, as written, after
character-reference unescaping and after removing invisible characters, and fails when
a `check-*` / `check_*` script name resolves to no file under `scripts/`, when a name is
visible only after decoding, when a name fragment sits next to markup, or when a line
holds a bidirectional or control character. Exceptions are count-exact
`<doc>:<token>:<count>[:pinned]` entries in
`scripts/qc-allowlists/compliance-script-names-allow.txt`, at most 10, each honoured only
while an erratum block of the fixed shape exists. Exit 0 green, 1 red, 2 undecidable
(unreadable or invalid UTF-8) or self-test failure.
