**Cert-expiry gate scans FED identifiers as raw tree bytes (#6174).** `extract_fed_ids` in
`scripts/check_cert_expiry.py` ran `git grep -I`, whose binary/text decision follows
`.gitattributes`, so a head that marked a source file `binary` could hide a new
`AI_MEMORY_FED_*` identifier from the wire-drift check. It now runs
`git grep -a --no-textconv` with `core.attributesFile` neutralised, so attributes cannot
change what is scanned. Proof: `case_6174_attr_hides_drift` in
`scripts/ci/tests/test_check_cert_expiry_corpus.py`.
