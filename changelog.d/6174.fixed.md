**The cert-expiry gate's `AI_MEMORY_FED_*` identifier scan can no longer be blinded by attributes from the change under test (#6174).** `extract_fed_ids` ran `git grep -I`, and for a tree argument git classifies binary files by the working-tree attributes, which on the required `pull_request` job come from the pull request's own merge commit. A change could mark `src/**` binary, so an added or removed federation identifier outside the watched paths went unreported. The scan now uses `git grep -a` (every blob read as text; a stray match in a real binary can only widen the drift, which fails closed), with no git minimum-version bump. The new `(attr)` and `(attr-gate)` self-test cells pin the identifier drift as RED both in `check_change` and end to end on `pull_request`.
