**Federation nonce cache reports what it measures on `/health`, `/metrics` and `doctor` (#3662, audit #3645 F16).**

Pre-#3662 the per-peer replay-nonce cache swallowed every sqlite-mirror failure as a WARN, counted outer-LRU peer evictions only in a private atomic, never counted per-peer FIFO evictions or replay refusals, and the daemon's boot fallback to an in-memory cache was indistinguishable from a healthy one on every surface but the boot log. Now: `FederationNonceCache` counts replay refusals, fingerprint evictions, occupancy and persistence failures by op (`open` | `insert` | `delete_fingerprint` | `delete_peer` | `hydrate_prune`), tracks the last successful mirror write, and derives a persistence state (`memory_only` / `durable` / `degraded`) and restart-protection classification (`disabled` / `durable` / `lost`; `lost` for 300 s = `actionable`). The snapshot is on `/health` under `federation.nonce_cache` as a #3646 signal object (`state: "available"` + `value`; no peer id or path), on `/metrics` as the `ai_memory_federation_nonce_cache_*` family (closed `op` label set, pre-touched to 0 at boot), and offline in `ai-memory doctor` as "Federation nonce cache (#3662)" (the sqlite mirror's measured shape; N/A on a pre-v51 schema, never a zero). The daemon fallback now uses `new_after_persistence_open_failure`, which reports `lost` with reason `persistence_open_failed_at_boot`. No handler behaviour changes: replay refusal keeps working in-process while persistence is degraded.
