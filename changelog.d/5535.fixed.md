**The doc symbol-anchor gate no longer drops a self type that has no method after it (#5535).** `src/x.rs::<*const NoSuch>`, `<dyn NoSuch>`, `<&mut NoSuch>` and `<NoSuch as Tr>` with nothing after the group were skipped without a look because the scan returned no symbol for a lone balanced group. The group is now handed to the self-type check: its type and bounds are resolved, and a tuple, slice or lifetime self type that names no type is refused. A lone `<name>` or `<name<T>>` (an identifier head with no prefix and no `as`) stays an accepted placeholder, as #5393 and #5433 pin. Base: accepted; tip before this fix: accepted; now reported. Real tree: 0 lines change. The `--self-test` gains 11 cases (#5535).
