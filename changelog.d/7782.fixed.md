**CI and coverage no longer re-run on PR title and body edits (#7782).** `.github/workflows/ci.yml` and `.github/workflows/coverage.yml` now subscribe to `pull_request` types `opened, synchronize, reopened` only (the `edited` type added for #7072 cancelled the in-flight run of an unchanged head on every body edit); a base retarget re-runs CI through the conductor retarget helper (close and reopen), and the pre-merge checklist hard stop on `run_merge_check.py` blocks a merge whose CI run did not merge the head into the current chain tip.
