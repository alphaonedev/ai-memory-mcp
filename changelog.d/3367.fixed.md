**`memory_lease_get` reports an expired lease as absent (#3367).** The read
returned the lease row regardless of expiry, so a lease whose `expires_at`
had passed still read as live to a caller who then believed the action was
held — while the next `frontier` / `next` / `acquire` sweep would reclaim
it. A lapsed lease now reads as `null`, the view the sweep produces once it
reclaims the row. A read changes no state; a live lease reads exactly as
before. Callers that relied on seeing a lapsed lease as held will now see
`null` and must re-acquire.
