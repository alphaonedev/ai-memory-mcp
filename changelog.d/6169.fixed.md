**The compliance script-name gate no longer skips an unreadable directory (#6169).**
`scripts/check_compliance_script_names.py` collected documents with `Path.rglob`, which
silently skips a subdirectory it cannot list, so a document there was never checked and the
gate printed `compliance script-name anchors ok` with exit 0. The gate now walks
`docs/compliance/` with `os.walk(onerror=...)`: an unlistable directory, an unreadable
allowlist directory or a missing `docs/compliance/` exits 2 with `FAIL <path>: unreadable`.
