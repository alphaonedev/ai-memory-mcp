Boot and the live embedding-backfill worker no longer re-scan and re-WARN the same permanently unembeddable rows (undecryptable envelopes, oversize content) on every pass. Those rows are remembered in an `embed_skip` table keyed by memory id and the agent's current encryption-key fingerprint; a restored or rotated key invalidates the skip so the row is retried (healing path). One INFO at boot names the remembered count.
