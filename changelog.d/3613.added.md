**[release] Two-build byte-identity proof for the x86_64 Linux release binary, its tarball and its deb/rpm (#3613, umbrella #6062).**
`release.yml` gains a `reproducible` job that builds
`x86_64-unknown-linux-gnu` twice from the verified commit in two independent
workspaces (no shared cache, a fixed environment, `SOURCE_DATE_EPOCH` = the
commit time, runner paths remapped) with
`scripts/release/reproducible_build.py`, and fails on any byte difference. It
also packs each binary with the deterministic packer the release job uses
(sorted members, the epoch as mtime, owner 0/0, normalized modes, no gzip
timestamp) and builds each deb and rpm with the pinned nfpm 2.41.1, and
compares those too. Every publish job needs it, and the release job's x86_64
Linux leg ships only the binary whose digest the proof produced. Every
artifact job (release, mobile-ios, mobile-android, docker) reads one
`SOURCE_DATE_EPOCH` from a pinned step. Not yet proven, each tracked:
`aarch64-unknown-linux-gnu` (#3613), the macOS binary's ad-hoc code signature
(#6407), the iOS xcframework contents (#6408) and the Docker image layer
timestamps (#6409). No reproducibility claim is made until the proof passes on
a real release run. Regression: `reproducible_build.py --self-test` and the
`3613 ...`, `6274 ...`, `6282 ...` and `6283 ...` guard self-test cases.
