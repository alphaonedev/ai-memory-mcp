### Security

- `ai-memory quarantine` and `ai-memory recover-previous-session` resolve the store URL through the same channels as every other command (`AI_MEMORY_STORE_URL_FILE`, then `AI_MEMORY_STORE_URL`, then `--store-url`), so the DSN no longer has to be passed on argv. `docs/CLI_REFERENCE.md` documents the channels.
