**Removed: the `x86_64-apple-darwin` (Intel macOS) pre-built binary
(#6287, #4770; 5-agent vote 4d3ea1c5, D1 3-2).**

The release matrix now builds three targets: `x86_64-unknown-linux-gnu`,
`aarch64-unknown-linux-gnu` and `aarch64-apple-darwin`. Every artifact must
pass the strict exact-set feature assert by running natively on its runner;
GitHub's last Intel macOS image (`macos-15-intel`) retires in Aug 2027, and a
cross build on arm64 could only be asserted under Rosetta 2, which GitHub does
not guarantee. Dropping the leg keeps the assert strict and unskippable.

**What it costs you.** Intel Mac users build from source (`cargo install
--locked`); the Homebrew formula declares `depends_on arch: :arm64` on macOS,
so `brew install` on an Intel Mac stops with a clear requirement error instead
of installing an unasserted binary. Linux and Apple Silicon installs are
unchanged.

The release guard (`scripts/check_release_features.py`) pins the three
(target, os) pairs and refuses a self-hosted or moved leg (#6279), and pins the
Homebrew SHA loop, tarballs, placeholders and macOS block to the same targets.
