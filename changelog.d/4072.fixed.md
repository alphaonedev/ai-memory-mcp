`ai-memory serve` now drains gracefully on Unix `SIGTERM` as well as `SIGINT`: both signals enter the same path (stop accepting, drain in-flight requests, drain the deferred-audit queue, final witness, WAL checkpoint). `docker stop`, Kubernetes and supervisors that send the default stop signal therefore no longer bypass final certification; the container image declares `STOPSIGNAL SIGTERM` and the admin guide names the stop budget (#4072).
