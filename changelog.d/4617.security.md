### Security

- `deploy/hive-1461/provision/20_pg_age.sh`, `infra/pgbouncer/smoke-test.sh` and `deploy/enterprise-federation-repro/repro.sh` no longer put the database password on a `docker run -e POSTGRES_PASSWORD=`, `docker exec -e PGPASSWORD=`, `psql -v pw=` or password-bearing `psql` URL argument. Secrets reach the peers over ssh stdin into 0600 files, then `docker --env-file`, psql `\getenv` (`bootstrap.sql`) and `AI_MEMORY_STORE_URL_FILE`; `-e NAME` with no value inherits from the caller. Gate rule `env-password-argv` pins it. (#4617)
