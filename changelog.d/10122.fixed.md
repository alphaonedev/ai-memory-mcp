- **`ai-memory skill` read verbs now refuse a malformed `AI_MEMORY_AGENT_ID`
  before opening the database (#10122).** Calling `skill list`, `get`,
  `resource`, `export`, or `compose` with an empty, non-Unicode, or
  shape-invalid `AI_MEMORY_AGENT_ID` now exits with code 2 before any database
  or witness-custody I/O runs, so a malformed caller id paired with a missing
  or unopenable database reports the caller-id refusal instead of a DB open
  error.
