**`memory_load_family` / `memory_smart_load` report the stored `confidence_source`
(#3373).** The loader selected a hand-listed 15-column projection, and the row
mapper defaults any column it does not see, so a row the store had stamped
`auto_derived` came back `caller_provided` — a default that read like a
measurement, indistinguishable from a caller who really supplied it. The
projection is now `SELECT *`, the shape `memory_get` already uses, so the two
surfaces agree by construction and every formerly-defaulted column
(`memory_kind`, `version`, `cid`, `lifecycle_state`, `valid_from` / `valid_until`,
…) carries its stored value on this surface too. Because the wider projection
also reaches a sealed row's envelope, the family read is a discovery scan like
`get_many`: an undecryptable row is skipped (logged, counted) rather than
failing the whole call.
