The sharded enterprise-fed CI suite can skip a test executable whose cargo dep-info key (own sources, local lib/bin closure, Cargo.lock, rustc, features, environment, Postgres server version and run-time files) equals the key recorded by the last green push to the same release/** branch on the same node and tier within 7 days. Only pull requests into release/** look the key up and pull requests never write it; the recording push to release/** runs every binary and never skips one. Documentation-only changes (changelog.d/, docs/, *.md) are hits for every binary that does not read them (scripts/ci/test_binary_cache.py, #6384).
