**The doc symbol-anchor gate no longer reads a line that merely ends in `]:` as a link head.** The #5396 next-line rule matched `]:` at the end of any line, so prose such as `Note [x]:` followed by `src/../gone.rs no longer exists` lost its absence exemption and was a false red (green before #5396). The next line is a link target only after an open `](` or after a real reference-definition head (also inside a blockquote or list item), as CommonMark defines. The #5396 case that planted `Formerly [h]:` now plants a real definition under a separate "Formerly" line; it is still red. Real tree: 0 lines change. The `--self-test` gains 6 cases (#5432).
