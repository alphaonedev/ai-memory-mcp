The governance glob matcher (`permissions::glob_matches`, used to select `[permissions]` rules and agent-action rule namespaces, paths and hosts) now matches patterns that mix `**` and `*` exactly. The previous single-checkpoint backtracker dropped the earlier `**` alternative once it reached a later `*`, so a pattern such as `**/secret/*` did not match `a/secret/b/secret/c` and a configured Enforce Deny silently did not apply to a namespace it covered. The matcher is now a bounded dynamic program over (pattern token, value offset): O(|pattern| x |value|) time, O(|value|) space, no recursion (#4042).
