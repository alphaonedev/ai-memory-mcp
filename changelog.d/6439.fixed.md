**Carrier-ruleset verifier rejects duplicate JSON keys (#6439, carrier gate #6143).** `scripts/check_carrier_ruleset_live.py` parsed the state file, the ruleset payload and the GitHub API bodies with plain `json.loads`, so a repeated key silently kept the last value and the reviewed file could differ from what the verifier (or GitHub) acted on. Every JSON read now uses an `object_pairs_hook` that raises on a repeated key at any depth, and the read fails closed with the existing `VerifyError`. Pinned by six self-test cells run through `tests/carrier_base_fresh_gate_6143.rs` `carrier_ruleset_live_checker_self_test_passes_6143`.
