**The destructive embedding-dim conversion needs both argv flags.**
`ai-memory schema-init` NULLs stored embeddings only when the same call carries
both `--embedding-dim N` and `--force-reembed`. A dimension from
`AI_MEMORY_EMBED_DIM`, from `[embeddings].dim` in the config file or from a
default, combined with `--force-reembed`, over a populated column now refuses
with the exact text naming the configured source, exits non-zero and leaves
every stored vector unchanged. The conversion takes a `ForceReembedOrder` that
only the argv parser builds, so no other caller can authorise it. A matching
dimension is checked before the table lock is taken; the lock is taken only to
convert, and the column dimension and the stored-vector count are re-read under
it. The dimension probe and the conversion resolve the `memories` table through
the same `search_path`.
