**The env-mutation gate no longer trusts a capitalised name as a safe receiver (#8098).** `P.for_each` after `let P = par()`, `Par().for_each`, a `static POOL: LazyLock<Pool>`, `ai_memory::pool::GLOBAL` and an imported `GLOBAL` are all detached; only a name the file proves (a std name, a same-file const or fn, a parameter) is safe, and a declared std type is accepted as the proof.
