**The compliance script-name gate resolves a cited script name to its exact path (#6198).**
`scripts/check_compliance_script_names.py` accepted a name when a same-named file existed
anywhere under `scripts/`, including a nested fixture and a symlink that resolves outside the
repository. A citation now names exactly one path (the components after the first `scripts`
component of the written path, else `scripts/<name>`), which must be a regular file reached
without `.`/`..` components and resolving inside `scripts/`, the same containment already
applied to erratum successors.
