**The `ScratchDb` test helper no longer deletes another run's database (#7125).** `tests/common/pg_barrier.rs` dropped every database that shared its prefix and looked older than 600 s, and its guard dropped its own database, both `WITH (FORCE)`, so a concurrent invocation (idle or with a live session) was destroyed. The guard now owns exactly the database its own `CREATE` made: a plain `DROP DATABASE` retried while a session is still closing, no prefix listing, no age reclaim, no `FORCE`, the admin pool closed on every path, and a database it could not drop is named on stderr as LEFT OVER for manual cleanup.
