### Security

- **[supply-chain] Time-boxed audit exception for RUSTSEC-2026-0459 (libsqlite3-sys 0.30.1)**
  ([#8695](https://github.com/alphaonedev/ai-memory-mcp/issues/8695)). The bundled SQLite can
  read uninitialized page-cache memory when a database is opened with a sibling `-wal` whose page
  size differs. The precondition is an operator-supplied database and `-wal` pair, local only,
  reached whenever such a pair is opened: any open of an operator-chosen database file also opens
  its sibling `-wal`, including the plain `--db` open (`SqliteStore::open` / `db::open`), `migrate --from`
  and restore. The advisory is NOT mitigated by this change. No
  fixed release is usable today (sqlx holds the `links = "sqlite3"` slot below libsqlite3-sys 0.39,
  and the `sqlcipher` feature has no upstream fix). The exception is recorded in
  `.cargo/audit-exceptions.toml` and expires 2027-02-03; removal trigger: an sqlx release accepting
  libsqlite3-sys >= 0.39, tracked in [#8696](https://github.com/alphaonedev/ai-memory-mcp/issues/8696);
  the code guard is tracked in [#8697](https://github.com/alphaonedev/ai-memory-mcp/issues/8697).
