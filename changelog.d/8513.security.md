**Re-owned rows drop the source attestation (#8513, umbrella #8493).** `memory_share`, atomisation and promotion clone a row to a new owner. The clone used to keep the source row's `attest_level` and `write_signature`, so trust surfaces showed an `agent_attested` row for an agent that never signed it. All three paths now call `identity::attest::reset_for_reowned_row`: the clone drops `write_signature`, `agent_pubkey` and `pubkey_bound_at`, reports `attest_level` `claimed` with `attest_reset_reason`, and records the source id and owner under `shared_from` / `atomised_from` / `promoted_from` (plus `*_agent_id`). Both backends: the postgres promote path shares `build_promotion_clone`.
