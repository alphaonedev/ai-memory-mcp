**The doc symbol-anchor gate no longer lets a prose comparison absorb a real over-close.** The count of generic groups still open before an anchor counted every `<`, so `a < b` before `src/x.rs::T<U>>` made the extra closer look like the end of a prose generic and the over-close went unreported (it was red before #5456). A `<` followed by a space, tab or `=` is a comparison and opens no group. The unspaced `a<b` cannot be told from a prose generic and is still counted; it never hides a missing symbol. Real tree: 0 lines change. The `--self-test` gains 5 cases; the unspaced form is pinned as accepted by its own case (#5498).
