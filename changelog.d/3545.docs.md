**#3545 — `docs/integrations/codex-cli.md` no longer calls `wrap codex` "100% reliable" / "recommended".**

The default `wrap codex` strategy passes `--system`, which Codex CLI >= 0.153
rejects (exit 2, `unexpected argument '--system' found`; reproduced on
`codex-cli 0.153.3`). The page now opens with a known-broken notice, points
at the native MCP path and the `--system-flag` / `--system-env` /
`--message-file-flag` overrides, and cites the NOT CERTIFIED entry in the
v1.0.0 certification standard. No code change: the version gate stays v1.x.
