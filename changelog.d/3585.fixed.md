The curator `--daemon` self-signal tests no longer sleep a fixed 200 ms
(or 3 s on the SAL arm) before `kill(getpid, SIGTERM/SIGINT)`. Under host
load that sleep raced the tokio handler install and the default
disposition terminated the whole `--lib` binary (`signal: 15`, zero test
failures). `await_shutdown_signal` now installs SIGTERM and SIGINT before
publishing a test-only ready flag; the kicker waits on that handshake
(and panics rather than signalling if it never arrives) and each test
runs in an isolated subprocess (`run_env_isolated_child_or_spawn`, the
#3355/#2905 pattern) so a lost race can only fail that child.
