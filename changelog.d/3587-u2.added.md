**#3587 U2 — `ai-memory watch --host file:<path>` line-file source.**

`--host file:<path>` (repeatable) is a watcher-layer `WatchSource::LineFile`. `HostKind` stays byte-identical (Copy, kebab-case `--json` wire). Idempotency reuses `transcript_line_dedup` (`host_kind=file`; `normalized_sha256`/`raw_sha256` = `sha256(abs_path ‖ 0x00 ‖ line)`; `metadata.line_sha256` = `sha256(line)`) — zero schema change; the same line in two files is two memories. In-memory `(dev, ino, len, offset)` is only the change detector and resets on inode change or shrink; a trailing line without newline is never consumed. Reads stream at O(max-line) (never the whole tail); quiet ticks do not open the DB; the open is `O_NOFOLLOW` + fstat identity. Whitespace-only lines are skipped.

`agent_id` is always the watch process's resolved `--agent-id`; the parsed actor prefix lands in `metadata.observed_actor` (untrusted). Tags come from `SWARM_LINE_TAGS` (READY/STATUS/BLOCKER/ACK/NOTE/MASTER). Title is `<basename>:<line sha8>`.

Path safety: regular file, no symlink components, same uid, bounded line and file size, `--limit` per source per tick. `--dry-run` writes nothing. Default build `refuse_pg_store`s; `--features sal` writes line-file (and transcript) rows through `recover_turn_idempotent` so a postgres hive works. Under `--features fs-notify`, line-file sources watch the parent directory and fall back to polling only when that directory is unwatchable.
