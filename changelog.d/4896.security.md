### Security

- `deploy/hive-1461/provision/20_pg_age.sh` recreates the `hive-pg-age` container without `--env-file` once the data directory is initialised, so the init-only Postgres superuser password no longer stays in `docker inspect` output or in the postgres process environment. A container that still carries that environment is removed on the failure path, and the script fails if the recreated container still lists `POSTGRES_PASSWORD`. (#4896)
