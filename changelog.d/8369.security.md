Reflection CLI and automatic exports create private mode-0600 files on Unix,
refuse symlink and non-regular destinations, and atomically replace regular
files after syncing a private staging file. Sync the parent directory after
publication and report sync errors without removing the published file. Remove
regular staging leftovers older than one hour on the next export, warning on
cleanup errors. Non-Unix platforms refuse filesystem reflection export because
the private-file and directory-sync guarantees are unsupported: the CLI returns
an error, while auto-export logs a warning and writes nothing.
