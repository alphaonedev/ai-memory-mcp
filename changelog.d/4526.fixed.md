**Hook `namespace` patterns with an unsupported wildcard are refused at load (#4526).** `hooks.toml` validated the per-hook `namespace` for shape only, while the runtime matcher understands exactly `*`, an exact namespace and one trailing `prefix/*`. Any other wildcard form (a mid-path or suffix `*`, `**`, a bare `/*`) loaded cleanly, counted as a hook, and was then compared as a literal, so a scoped guard hook silently never fired. Load now fails with `hook[N].namespace: unsupported wildcard; use '*', an exact namespace, or 'prefix/*'`: a boot load fails loudly and a SIGHUP reload keeps the previous config.
