### Fixed

- **A merged row is always relayable**
  ([#4032](https://github.com/alphaonedev/ai-memory-mcp/issues/4032)). Full replicated rows
  (federation receive, sync pull, import) are validated against replicated-state caps
  (`MAX_REPLICATED_TAGS` = 512, `MAX_REPLICATED_METADATA_SIZE` = 512 KiB) instead of the
  authored-input caps (50 tags / 64 KiB, unchanged for create/update), and the CRDT join is
  bounded by exactly those caps: the tag union keeps the 512 lexicographically smallest tags (a
  join, so replicas still converge) and an over-cap metadata join degrades to the row-LWW winner's
  metadata; both WARN on `crdt.bounded_join`, and the pre-merge row stays in the
  `federation_merge` archive snapshot. The visibility keys (`scope`, `target_agent_id`,
  `recipient_agent_id`) are exempt from the metadata fallback, so a bounded merge never widens who
  can read a row. Residual: past the 512 KiB metadata cap the fallback is commutative but not
  associative (which losing keys survive depends on join order).
