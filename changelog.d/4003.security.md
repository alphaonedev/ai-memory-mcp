### Security

- **[docs][transport] `SECURITY.md` no longer calls the federation transport
  unconditionally mutually authenticated**
  ([#4003](https://github.com/alphaonedev/ai-memory-mcp/issues/4003)). It said
  "mutually authenticated TLS (rustls, TLS 1.3, mTLS fingerprint pinning)". Two
  parts were false: mTLS is opt-in on BOTH ends (`serve` installs client-cert
  verification only with `--mtls-allowlist`, else it logs `TLS enabled but mTLS
  NOT configured`; the sync client presents a certificate only when both
  `--client-cert` and `--client-key` are set), and the listener negotiates TLS
  1.2 or 1.3 (`tls::SUPPORTED_PROTOCOL_VERSIONS`), not 1.3 only. The sentence now
  states both and points at `docs/compliance/honest-limitations.md` §4, which
  already disclosed the opt-in. Docs only; pinned by
  `tests/fit_docs_b_false_claims_4000_4009.rs`.
