**A broken gate helper is a named self-test failure, never a traceback (#6445).** When a
production helper is missing from `scripts/check_cert_expiry.py`, the external corpus records
the error against the case that called it and still runs every other case; the `--self-test`
runner prints `self-test FAILED (<case>: ...)` per case and exits 2 without relaying a
traceback. Proof: `case_6445_base_nameerror`, which runs the runner on a gate copy with
`cert_banner` renamed.
