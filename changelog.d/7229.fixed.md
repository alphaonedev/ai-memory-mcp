The `export_import_roundtrip_3405` suite is hardened in three ways (#7229, #7230, #7232). Its CLI children now pin `AI_MEMORY_KEY_DIR` to the shared test keystore sandbox, so a run no longer loads or generates the invoking user's real host signing key, and a new test asserts the key material lands in the sandbox and nowhere under the caller's HOME (#7232). `memory_rows` panics with the query error instead of mapping it to zero, so the "no row was applied" assertions can no longer pass vacuously, and a new test pins that panic (#7229). The legacy-watermark refusal test now also asserts the refusal reason `anchored_head: 448` (#7230). Test-infrastructure only; no product code changed.
