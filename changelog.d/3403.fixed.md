Every `ai-memory` write verb now dispatches its subscription/webhook event.
`store`, `delete`, `promote`, `link`, `resolve` and `consolidate` route through
a new shared write-event funnel (`crate::write_events`) that binds each
canonical event name to its canonical details type in one place; the MCP twins
were moved onto the same funnel. Because delivery is fire-and-forget, a one-shot
CLI invocation now also drains the fan-out before exiting, using the same drain
the HTTP daemon performs at shutdown.
