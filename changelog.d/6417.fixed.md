**Bidirectional controls written as character references are reported (#6417).**
`scripts/check_compliance_script_names.py` scans every line for bidirectional controls both as written and after
HTML character-reference unescaping (hex, decimal and named, with or without a closing semicolon). A reference
inside a code span is also reported: the scan reads raw bytes and fails closed rather than modelling where the
renderer decodes a reference (#6141, design B).
