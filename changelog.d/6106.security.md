### Security

- **[redaction] A config-file `db =` value no longer reaches doctor, serve or the deferred-audit boot
  errors verbatim** ([#6106](https://github.com/alphaonedev/ai-memory-mcp/issues/6106)). Every
  database-path sink (doctor `source:` and cannot-open findings, the `serve` open error, the
  deferred-audit journal errors, the HNSW, nonce-cache and governance notes) renders the path through
  `url_display::db_path_display`, and SQLite open errors drop the driver message that echoes the path.
