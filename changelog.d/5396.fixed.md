**The doc symbol-anchor gate now sees a CommonMark link with whitespace, a tab or one line ending between `](` and its destination, with an angle-bracket destination, or with whitespace before the closing parenthesis.** `RELLINK` and `ESCAPE_LINK_HEAD` wanted the destination right after `](`, so `[h]( src/gone.rs)`, `[h](  src/gone.rs  )`, `[h]( <src/gone.rs> )` and a destination on the next line passed with the file deleted, and an escape-token target (`src/../gone.rs`) on a "formerly" line kept its absence exemption. A line that ends in an open `](` now takes its destination from the next line, and a destination on the line after an open `](` or `]:` counts as a link target for the escape-token check. A backticked-label link with leading whitespace no longer resolves its file with the space attached. Real tree: 0 lines change. The `--self-test` gains 17 cases (#5396); the "never exempt" statement for a link target in the PR body and the #5343 fragment now hold for these forms.
