Without the knob, the same failures now report the outage like an unreadable tail does: an ERROR naming the directory and cause, the `ai_memory_forensic_sink_unavailable_total` metric, a Critical `Forensic audit log (#4199)` section in `ai-memory doctor`, and a signed `audit.forensic_sink_unavailable` row (#4272).
