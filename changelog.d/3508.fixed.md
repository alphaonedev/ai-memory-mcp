### Fixed

- **Final-tip hotfix: `identity hub-cache` clap conflict, a restore gate that
  stopped checking, and two stale test expectations**
  ([#3508](https://github.com/alphaonedev/ai-memory-mcp/issues/3508)).
  1. `identity hub-cache` declared its principal selector as `--agent-id`,
     colliding with the root `--agent-id` (`global` + `env =
     AI_MEMORY_AGENT_ID`). Clap refused to build the command, breaking
     `ai-memory completions` and `ai-memory man` in debug builds. The selector
     is now `--include-agent <AGENT_ID>` (repeatable); the caller identity keeps
     `--agent-id`. Same hazard and remedy as `agents subkey-certs --principal`
     (#3017).
  2. `restore` published a damaged snapshot over the live corpus. SQLite builds
     the whole-database root list for `PRAGMA integrity_check` from the schema
     table hash, and a VIEW contributes root page **0**, which `btree.c` reads
     as a PARTIAL check: it skips the freelist scan and the "every page in the
     file is referenced" pass, and still answers `ok`. Schema v98 (#3401) added
     the `inbox_namespace_aliases` view, so every database from that rung on
     silently lost both passes. `stage_and_verify` now re-asserts the whole-file
     page accounting itself (b-tree pages + freelist + the reserved pending-byte
     page must equal `page_count`) whenever the schema contains a view, and
     REFUSES to publish a snapshot carrying unaccounted pages. A sound snapshot
     is unaffected.
  3. `memory_subscription_replay`'s envelope echoes the CANONICAL `since` bound
     it applied (micros + `Z`, #3366) rather than the caller's spelling; the K7
     integration expectation still pinned the second-precision input and is now
     updated to the documented contract.
  4. The #3374 numeric/boolean parameter-shape suite pinned a fixed lease
     `holder` while `AI_MEMORY_AGENT_ID` is process-global, so a sibling test's
     caller leaked in and the identity gate (correctly ordered BEFORE parameter
     parsing) answered first. The suite now declares the single-operator posture
     it is written against; the identity-first ordering is unchanged.
