**The doc symbol-anchor gate no longer lets a bare `src/x.rs:N` in plain text borrow the commit-pinned href of an earlier, already-closed HTML link.** For the HTML label form, `pinned_label` in `scripts/check-doc-symbol-anchors.sh` took the last `href` anywhere before the anchor, so text after a closed `<a>…</a>` was exempted as if it were that link's label (#5215). The href is now borrowed only when no closing `</a>` lies between the last opening `<a ` and the anchor. The `--self-test` gains one red case (self-test 103 -> 104 PASS).
