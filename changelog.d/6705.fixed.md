**The cert-expiry context check no longer desyncs on a raw string or block comment inside an attribute, and an unterminated literal is a named error (#6705).** The attribute-body scan skipped only plain strings, so `#[doc = r"\"]` or `#[allow(x) /* [ */]` shifted the bracket count and hid a following `#[cfg(any())]`; a file ending inside a string, raw string or block comment was read to end of file silently. Attribute bodies now use the same tokenizer, and an end-of-file string, raw string or block comment raises a fail-closed error naming it: `(wrap-attr-rawstr-desync)`, `(wrap-attr-comment-desync)`, `(wrap-eof-string)`, `(wrap-eof-rawstring)`, `(wrap-eof-comment)`.
