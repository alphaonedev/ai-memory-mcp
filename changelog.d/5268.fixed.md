**The doc symbol-anchor gate now range-checks a `#L<a>C<c>` column fragment of a relative `src/` link.** The `#L` fragment pattern of `scripts/check-doc-symbol-anchors.sh` allowed no column part, so `[x](src/x.rs#L9999C2)` and `#L1C2-L9999C3` matched nothing and passed unchecked. An optional `C<digits>` after each line number is now accepted and the line numbers are checked like any other `#L` fragment. The `--self-test` gains three cases (#5268).
