### Documentation

- **`--quorum-writes` W counts the local commit**
  ([#4004](https://github.com/alphaonedev/ai-memory-mcp/issues/4004)).
  `docs/CLI_REFERENCE.md` described W as "peer acks required" and
  `docs/GLOSSARY.md` as "how many peers must ack", which reads as W remote
  copies. `AckTracker::is_quorum_met` counts the local commit plus distinct peer
  acks (`acks.len() + 1 >= w`), as ADR-0001 states: a write needs W−1 remote
  acks, and `W=1` needs none. Both entries now say so. An operator who set
  `W=1` expecting one remote copy had none. Docs only; pinned by
  `tests/fit_docs_b_false_claims_4000_4009.rs`.
