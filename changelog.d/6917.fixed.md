**Cert-expiry gate prints default-ignorable code points escaped (#6917).**
`log_safe()` of `scripts/check_cert_expiry.py` escaped every format character
(#6683) but still passed the default-ignorable code points that are not format
characters (Hangul fillers U+115F, U+1160, U+3164, U+FFA0, the combining grapheme
joiner U+034F, U+17B4, U+17B5, the Mongolian free variation selectors, the
variation selectors U+FE00-U+FE0F and U+E0100-U+E01EF, the unassigned
default-ignorables, and U+2800 BRAILLE PATTERN BLANK) through raw, so a printed
workflow file name, job key or approval trailer value could read as the real
trusted name. They are now printed as `\uNNNN` (`\UNNNNNNNN` above U+FFFF) from an
explicit table. No refusal decision changes. Self-test cell `log-safe-di-U+XXXX`
pins it.
