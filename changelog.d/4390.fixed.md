**#4390 — a bundle `archived_memories[]` row can no longer carry an unbounded `version` into a live row.**
The import lane stored the bundle's remote-asserted `version` verbatim (bounded only by the 2^62 receive
validation), so an archived row imported near that bound, restored and edited locally landed above 2^62 and
every peer refused it (the #4373 divergence through a non-federation entry point). The version is now clamped
on that lane exactly as the federation merge funnels clamp it (at most 2^40 for a new row).
