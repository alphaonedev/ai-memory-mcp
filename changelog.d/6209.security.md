### Security

- **[ci] The CLAUDE.md rule comparison masks a credential value whose first word is a count or a switch word**
  ([#6209](https://github.com/alphaonedev/ai-memory-mcp/issues/6209), follow-up of
  [#6163](https://github.com/alphaonedev/ai-memory-mcp/issues/6163), CWE-532).
  `scripts/claude-md-rule-compare.py` left an unquoted credential value
  visible when only its first word was a count or a switch word, so the words
  after it reached the step summary, and a long number written in groups
  (`4111 1111 1111 1111`, `123456789_123_456_789`) passed as a count. An
  unquoted value of several words is now shown only when every later word is
  itself a count or switch word or an all-lower-case prose word of at most 12
  letters (`max_tokens: 20000 per request` stays readable), and the count
  exemption is judged over the whole value: at most 9 ASCII digits in total,
  all in one word. Any other value is masked whole. A table cell or the line
  after a bare credential name may still be a description that starts with a
  capital or holds an acronym of 2-5 capitals. Regression cells: the `#6209`
  self-test cells.
