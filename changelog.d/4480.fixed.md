**Release binaries now ship the PostgreSQL + Apache AGE + pgvector tier.** `release.yml` built `--features sal` only, so every released artifact refused a `postgres://` store while the README and architecture pages advertised it. Every release artifact is now built with `--features sal,sal-postgres` (pure-Rust sqlx on rustls: no libpq, no system OpenSSL), declared once in `scripts/release-features.sh`; the `assert-compiled-features` pin requires `sal-postgres`; a new `release-shape` workflow builds exactly as the release does, asserts `ai-memory features`, checks no native TLS dependency appears, and round-trips a memory through a TLS PostgreSQL service over `sslmode=verify-full`; `docs/INSTALL.md` and the README state the shipped feature set (narrows #3996) (#4480).
