**#3806 x #3822 / #3823 — the `[decision]` endpoint now honours the carrier's inference egress plane in full.** A non-loopback plaintext `http` decision endpoint is refused at config load (naming `[decision].base_url`, or `[llm].base_url` when inherited) and at the boot gate; loopback `http` stays the permitted control. Under `AI_MEMORY_INFERENCE_EGRESS=internal-only` the decision chokepoint uses the same resolve-then-pin gate as `[llm]` and embeddings: a hostname is admitted only when every resolved address is internal, and the client connects only to those pinned addresses, never through a proxy (before this, internal-only refused every decision hostname, so posture 3 could not be served). Decision clients never follow a redirect: a `307`/`308` would have re-sent the body to an origin no gate approved, and it is now reported as an outage (`unavailable`). A `systemone` `base_url` ending in `/v1/systemone` is refused rather than doubled (W1c ruling 2).
