**Cert-expiry gate fails closed on code points it cannot classify (#6918).**
`log_safe()` of `scripts/check_cert_expiry.py` passed a code point the running
interpreter has no assignment for (category Cn: unassigned and noncharacters),
a private-use code point (Co) and a lone surrogate (Cs) through raw, so a
printed name could carry a code point that is a format character in the
renderer's newer Unicode tables. They are now printed as `\uNNNN`
(`\UNNNNNNNN` above U+FFFF); an older interpreter escapes more than a newer
one, never less. No refusal decision changes. Self-test cells `log-safe-cn`,
`log-safe-co` and `log-safe-cs` pin it.
Refs #6140, #6683, #6918.
