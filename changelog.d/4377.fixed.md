**The schema-behind repair hint names a command the CLI actually accepts (#4377).**
`ai-memory doctor`, `ai-memory boot` and the read-only open refusal told
an operator with a database behind the binary to run `ai-memory migrate
--in-place`. That flag never existed, and the default build has no
`migrate` subcommand, so the only repair printed at a one-way schema step
was a usage error. The hint now reads `ai-memory schema-init --store-url
<store-url>` (which runs the forward ladder and exits) in `--features sal`
builds and `ai-memory serve` in the default build, alongside "start the
daemon". A test parses the hint with the real CLI so it cannot drift again.
