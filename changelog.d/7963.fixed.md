**`ai-memory logs tail --follow` no longer prints a half-written final line twice over (#7963).** When the file ended in an unterminated fragment at the tail pass, the fragment was printed as a line and the follow phase then printed the rest of the same line as a second line. The tail pass now stops before an unterminated fragment when following, leaving the offset at the start of that line, so the follow phase prints the line whole and once as soon as its newline arrives; a plain `logs tail` without `--follow` still prints a final unterminated line.
