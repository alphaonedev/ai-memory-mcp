**[release][supply-chain] Every `uses:` of the release workflows is pinned to a full commit sha (#6904, #7010, umbrella #6062).**
The release guard pinned action refs only inside the release, docker,
reproducible and release-shape step lists, so a tag, branch or short ref in
`preflight` (which computes the commit every bind trusts), `supply-chain`,
`crates-io`, `homebrew`, `copr`, `sbom` or the mobile jobs passed. The guard
now refuses any `uses:` in `release.yml` and `release-shape.yml` that is not
`owner/repo@<40 lowercase hex>`, a local `./` action or a `docker://` image by
sha256 digest. Regression: the `6904 ...` and `7010 ...` guard cases.
