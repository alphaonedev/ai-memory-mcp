**Release-feature guard requires every `uses:` to be a 40-hex commit sha (#6904).**
The guard pinned `uses:` only inside the release, docker and release-shape step
lists, so a mutable ref (`actions/checkout@v4`) in `preflight`, `qualify`,
`crates-io`, `homebrew`, `copr` or the mobile jobs passed. `check_uses_pinned`
now walks every `uses:` of `release.yml` and `release-shape.yml` and accepts
only `owner/repo@<40 lowercase hex>`, a local `./` action or
`docker://...@sha256:<64 hex>`. Tests:
`scripts/ci/tests/test_check_release_features_6062.py` (`Uses6904`).
