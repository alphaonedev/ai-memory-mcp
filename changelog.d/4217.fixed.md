#4217 — Every production write that changes an existing memory's data now bumps `memories.version` or appears on a justified allow-list. Writers that now bump: the contradiction marker write and its reversal, the atomisation source archive stamp, curator-report retention stamping (both backends), the agent-registration pubkey bind/revoke/lineage projections (both backends), and the PostgreSQL reflection upsert. A reader holding an older version can no longer pass an If-Match or version-checked consolidation over those changes. The new census gate `tests/version_bump_census_4217.rs` scans every `UPDATE memories` / `ON CONFLICT DO UPDATE` statement and fails on any new writer that neither bumps nor carries a written justification (federation merges are listed as tracked by #4216).
