**`ai-memory logs tail --follow` prints lines the writer appended to the renamed log before it reopened the path (#7950).** When rotation is rename-and-recreate, the follower used to switch to the new inode and never read the tail of the old file. It now keeps the open handle of the followed inode and reads it to EOF (including an unterminated final fragment) before switching to the new file at offset 0, so every byte prints exactly once and in order; truncation of the same inode is unchanged.
