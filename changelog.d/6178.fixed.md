**The cert-expiry self-test refuses a git shim scratch path that contains the PATH separator (#6178).** `run_gate_shimmed` put its scratch shim directory on `PATH`; when the checkout path held the separator (`:` on POSIX) the entry was split, the shim was unreachable and the `(gitver)` / `(anc-error)` cells blamed the gate for what was really the real `git` running. It now raises `GateError` before installing the shim, the three shim cells report "the git shim could not be installed" as a named self-test failure, and the new `(shim-pathsep)` cell pins the refusal. The refusal tells the user the remedy: run the self-test from a checkout whose path has no separator.
