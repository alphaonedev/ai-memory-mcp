### Security

- `deploy/hive-1461/provision/20_pg_age.sh` no longer places the Postgres superuser or `aimemory` passwords on the ssh, docker or psql command line. The passwords travel over ssh stdin into 0600 files on the peer, `docker run` and `docker exec` read them with `--env-file`, `bootstrap.sql` reads the role password with `\getenv`, and `schema-init` takes the store URL from `AI_MEMORY_STORE_URL_FILE`. The three pending entries for these sites are gone from `scripts/check-docs-no-argv-secrets.py`, so the gate now reports 0 argv credentials and 0 pending. This change integrates the #4600 fixes (PR #4782) onto PR #4655 round 3. (#4762)
