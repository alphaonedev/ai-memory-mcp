**The doc symbol-anchor gate now checks a relative markdown link to a `src/` file whatever its label.** `scripts/check-doc-symbol-anchors.sh` read a link only when its label was a backticked identifier (`MDLINK`), so `[the handler](src/gone.rs)` to a deleted or renamed file passed (#5190). A new `RELLINK` rule makes the target of every relative `src/…rs` link a `PATH` finding when the file does not exist (a link `MDLINK` already reported is not reported twice). No scanned doc used the form, so no doc changed. The `--self-test` gains four cases.
