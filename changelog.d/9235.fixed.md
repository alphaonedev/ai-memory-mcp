
**The coverage job survives a pgdg `postgresql-16` upgrade inside the pg-age container (#9235).**
Installing `postgresql-16-pgvector` can pull a newer `postgresql-16` (first seen with `0.8.7-1.pgdg13+2`,
2026-11-12) under the running postmaster, which then cannot load the new `plpgsql.so`. The coverage job now
restarts the pg-age container after the install, and a preflight names a PostgreSQL package mismatch with one
`PG-ENV` class line instead of failing every Postgres test.
