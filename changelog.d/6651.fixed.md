**The cert-expiry shim-probe comparison is pinned against CR padding and case changes (#6651).** `_require_shim_reachable` compares the probe answer exactly, but the `(shim-probe-exact)` cell did not cover an answer with a CR before the newline or an upper-cased nonce, so a later edit that stripped CRs or compared case-insensitively would have kept `--self-test` at rc 0. The cell now runs `(crlf)` and `(upper)` stub gits and requires a named refusal for each; the docstring and the self-test OK banner name both forms.
