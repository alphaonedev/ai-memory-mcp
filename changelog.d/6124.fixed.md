**`check_cert_expiry.py` rule (B) now has an honest pass path while the certification is EXPIRED or VOID (#6124).**
Before, a watched federation-wire or `AI_MEMORY_FED_*` change judged against an
EXPIRED banner could not pass: the banner cannot move again, so the only exit was a
false re-mint. Under the 5-agent vote (4d3ea1c5, T3) the gate now passes such a change
only when STATUS is EXPIRED or VOID at BOTH the merge-base and the judged commit AND
the change adds a NEW dated `> **Amendment (YYYY-MM-DD, ...)**` entry below STATUS
that lists exactly every changed watched path and identifier (exact match, bullet
entries only, outside code fences) and names #6063 (WP-B1) as the only path back to
LIVE. The amendment is a non-discharging record, never a re-mint. LIVE banners keep
rule B and rule C unchanged. Regression: self-test cells `6124-h1..h3`, `6124-f1..f11`.
