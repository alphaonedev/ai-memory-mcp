**The doc symbol-anchor gate no longer lets a comparison-like spelling hide an over-closed anchor (#5531).** The #5498 rule recognised only `<` and `<=`, so `a << b`, `a <<= b`, `a <- b`, `a <> b`, a comparison spaced with an HTML whitespace entity (`&nbsp;`, `&#32;`) or a non-breaking space, and the entity-spelled forms (`&lt;&lt;`) each opened a phantom generic group that absorbed a real over-closing closer after the anchor. A whitespace-delimited token made only of `< > = - !` (an entity counts as its sign) is now an operator and opens no group. This rule alone covered only the whitespace-delimited spellings: whitespace references outside a hand list and a `<` in quotes, parentheses or a code span still opened a group. Character references are now decoded with the full HTML5 table before analysis (#5607), and a `<` that is not provably an opener makes the anchor refused as `UNDECIDABLE_LT` (#5608), so the word-attached `Vec<&nbsp;src/x.rs::T<U>>` case of this entry is now refused, not accepted. Base: accepted; tip before this fix: accepted; now reported. Real tree: 0 lines change. The `--self-test` gains 15 cases (#5531).
