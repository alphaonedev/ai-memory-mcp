**The doc symbol-anchor gate no longer lets a comparison-like spelling hide an over-closed anchor (#5531).** The #5498 rule recognised only `<` and `<=`, so `a << b`, `a <<= b`, `a <- b`, `a <> b`, a comparison spaced with an HTML whitespace entity (`&nbsp;`, `&#32;`) or a non-breaking space, and the entity-spelled forms (`&lt;&lt;`) each opened a phantom generic group that absorbed a real over-closing closer after the anchor. The rule is now a class rule: a whitespace-delimited token made only of `< > = - !` (an entity counts as its sign) is an operator and opens no group, whitespace entities are read as whitespace, and a `<` attached to a word stays a generic opener. Base: accepted; tip before this fix: accepted; now reported. Real tree: 0 lines change. The `--self-test` gains 9 cases (#5531).
