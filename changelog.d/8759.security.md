### Security

- **[coordination] Action transitions and checkpoint resolutions act as the authenticated caller,
  never as a named field** ([#8759](https://github.com/alphaonedev/ai-memory-mcp/issues/8759)).
  `memory_action_transition` and `POST /api/v1/actions/{id}/transition` took their acting identity
  from the caller-supplied `claimed_by`, so one agent could drive another agent's leased action by
  naming the lease holder, and the audit row then attributed the transition to the holder. The
  same shape held for `resolved_by` on `memory_checkpoint_resolve`. A supplied `claimed_by` /
  `resolved_by` is now only compared to the authenticated principal (the MCP process
  `AI_MEMORY_AGENT_ID`, or the HTTP `X-Agent-Id` / per-request anonymous id) through one shared
  control, and a difference is refused with
  `acting_identity_mismatch: caller '<principal>' may only <op> as itself (<field> '<value>')`
  (HTTP 403) before any state change or audit row. The MCP-to-HTTP forward path refuses before any
  network I/O. The field stays accepted when it equals the principal; the MCP single-operator
  posture (no configured identity) and operator-signed `epoch_advance` resolutions are unchanged.
- **[coordination] `POST /api/v1/checkpoints/{id}/resolve` binds an optional `resolved_by` to
  `X-Agent-Id`** ([#8773](https://github.com/alphaonedev/ai-memory-mcp/issues/8773)). One agent
  could resolve another agent's approval checkpoint while naming that agent as the resolver. A
  supplied `resolved_by` that differs from the authenticated caller is now refused with the same
  `acting_identity_mismatch` error (HTTP 403), and a malformed one with HTTP 400. Whether a
  checkpoint should name its permitted resolvers is tracked in
  [#8785](https://github.com/alphaonedev/ai-memory-mcp/issues/8785).
- **[coordination] Leasing a peer's un-held action stays a shared work queue**
  ([#8791](https://github.com/alphaonedev/ai-memory-mcp/issues/8791)). Actions have no read
  visibility gate, so any agent that can read an action may lease it as itself. A regression test
  now pins this by-design behaviour, together with the existing refusals: leasing as another
  agent is refused, and renewing or releasing a lease held by someone else is refused.
