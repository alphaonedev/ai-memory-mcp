### Security

- The `infra/do-hive` and `infra/aws-gpu-burst` cloud-init templates, the do-hive crypto and envelope test scripts, and the Postgres deployment docs no longer put the database password on the `ai-memory serve --store-url` argument line. They write a mode 0600 store-URL file and name it with `AI_MEMORY_STORE_URL_FILE`; the store-URL precedence in these docs now matches `src/store_url.rs` (file, then env, then flag). The AWS template's nonexistent `--bind` flag is replaced by `--host` and `--port`. New gate `scripts/check-docs-no-argv-secrets.py` (job `docs-no-argv-secrets-gate` in `c8-precheck.yml`) fails on a tracked `--store-url` argument that carries an inline password. `schema-init` is allowlisted until it gains a non-argv channel (#4600).
