### Fixed

- **[correctness][http] `POST /api/v1/skill/{id}/promote` decides 404 from the error type, not its words** ([#4622](https://github.com/alphaonedev/ai-memory-mcp/issues/4622)).
  The route used to answer 404 whenever the error text contained "not found", so any
  unrelated error that happened to echo those words (for example an invalid skill name)
  was reported as 404 instead of 400. A missing or hidden reflection or source member now
  plants a typed `ReflectionNotFound` root on the error chain
  (`src/mcp/tools/export_reflection.rs`, `read_reflection_member`) and the route reads the
  type by downcast (`src/handlers/skills.rs`, `promote_error_status`). The text and the MCP
  JSON-RPC code (`REFUSED`) are byte-identical to before, and a hidden member is still
  indistinguishable from a missing one ([#3551](https://github.com/alphaonedev/ai-memory-mcp/issues/3551)).
