**The #5084 gate `scripts/check-sqlite-write-txn-immediate.py` no longer lets a DEFERRED `BEGIN`/`SAVEPOINT` string escape (#6152, #6154, #6155).** The gate reads every string literal of a SQLite source file, whole (a multi-line literal is read to its closing quote), and skips only literals that are arguments of message sinks (`expect`, `context`, `panic!`, `assert*!`, the log and print macros, `write!`, `anyhow!`/`bail!`/`ensure!`, `params!`); a `let`/`const`/`static` value, a `format!`/`String::from` argument, a helper's return value, a `match` arm, a struct field or any other call argument is scanned. Source is lexed once per file (strings, raw strings, byte strings, char literals, nested block comments) instead of a 3-line look-back, so an unbalanced quote cannot blind the lines below it. A `mod x;` declared inside a `#[cfg(test)]` block is test code, but a layout the indent cannot place (or braces that do not balance) is now reported as `R0` instead of resolving a guessed path. `--self-test` runs 56 green and 102 red probes and 14 mutants (sink-skip, literal blanking, raw-string handling, ambiguous-mod guard and each rule), all killed.
