### Security

- **[wake] One shared socket preflight for every wake-plane dialer** ([#9638](https://github.com/alphaonedev/ai-memory-mcp/issues/9638)). Every wake-plane client now dials the hub socket through one shared preflight that refuses a socket with the wrong owner, a group/other-writable socket or directory, and a socket swapped after the check (the connected peer's kernel-attested uid must be the caller's own, with no exemption for root, and a peer whose credential cannot be read is refused), with a named error and before any frame is sent. The `wake-sink` forwarder previously connected without it.
