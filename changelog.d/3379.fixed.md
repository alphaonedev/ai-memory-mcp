Close the cross-tenant content disclosure in `memory_share`, HTTP
`POST /api/v1/share`, and the SQLite `share` CLI path. Source resolution now
applies `is_readable_on_query` before `caller_owns_for_mutation`: collective
readability does not grant permission to share a foreign-owned row. Substrate
rows cannot be shared because share has no namespace parameter; the canonical
ownership predicate retains its inbox-recipient exception. Hidden and missing sources have the same
refusal (HTTP 404); readable foreign-owned sources receive the canonical
ownership refusal (HTTP 403). HTTP applies the existing identity-binding gate,
and MCP/CLI reject malformed configured principals instead of falling back to
single-operator access. Tool descriptions, schemas, routes and CLI flags are
unchanged.
