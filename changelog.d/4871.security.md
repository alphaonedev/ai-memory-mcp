### Security

- **[deploy] The do-1461 and hive-1461 harness no longer puts the admin API key on an argv**
  ([#4871](https://github.com/alphaonedev/ai-memory-mcp/issues/4871),
  [#4872](https://github.com/alphaonedev/ai-memory-mcp/issues/4872),
  [#4873](https://github.com/alphaonedev/ai-memory-mcp/issues/4873)). The harness built
  `-H 'x-api-key: ...'` into the curl command string that `ssh_node` ran on a fleet node, so the
  key was an argument of the ssh client, the remote sshd child and curl (CWE-214), and
  `atlas/ingest.sh` wrote the key into a generated poster script as a curl argument (CWE-312). The
  key now travels as a curl config line on ssh stdin (`ssh_node_with_key`, `ssh_node_keyed`) and
  the curl command carries only the non-secret word `--config -`; the ingest poster reads a 0600
  curl config file that is written over ssh stdin and removed at the end of the run.
