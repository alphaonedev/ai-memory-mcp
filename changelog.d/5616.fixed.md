**The doc symbol-anchor gate refuses a doc or source file it cannot read instead of skipping it (#5616).** The doc loop and the source loop caught the error from opening a file and moved on, so a doc in the checked set that was a directory or had no read permission was never checked and the gate still passed; an unreadable source file dropped its symbols and its anchors were reported as a missing path. Both now print a `SETUP` failure that names the path and the operating-system reason, and the gate exits 1. Base: accepted; tip before this fix: accepted; now refused. Real tree: 0 lines change. The `--self-test` gains 7 cases; the two no-read-permission cases run only when the self-test is not run as root, because root can read a file with mode 000 (#5616).
