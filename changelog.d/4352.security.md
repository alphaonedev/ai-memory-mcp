**An existing `forensic.lock` that other users can read is made owner-only (#4352).** The #4304 lock file is created 0600, but a creation mode does nothing for a file that already exists. Every append now tightens a wider lock file to 0600 through the opened handle, so another user cannot open it to hold the lock and slow every audited write. If the file belongs to someone else and cannot be changed, that is logged once as a warning and the lock is still used.
