CI (workflow-only): the macOS `Check (macos-fed,sqlite)` leg no longer fails a
fully-passing test suite. The #1492 per-invocation hang watchdog was a function
of the tier alone, so macos-fed sqlite ran under the 1500 s budget sized for a
hosted ubuntu runner; on `e06961ca` it terminated the run with 581 test binaries
already green and zero failures. The budget is now `(node, tier)`-aware and the
macos-fed sqlite leg gets 2400 s (~1.6x the measured runtime, still far inside
the 80-minute job cap, so the watchdog rather than a nameless job-level cancel
stays what fires on a genuine hang); both linux tiers are unchanged. The
`check` job also declares `CARGO_PROFILE_DEV_DEBUG=line-tables-only` and
`CARGO_PROFILE_TEST_DEBUG=line-tables-only` in the workflow itself — durable
repo state rather than per-runner `.env` — which cuts test-binary size and link
time on both self-hosted hosts (the growth that filled the f2 root filesystem in
#3453), while keeping `file:line` in every backtrace. Every invocation now
prints its elapsed seconds against the budget, so a suite creeping toward the
cap is visible on green runs instead of only on the run that crosses it.
