### Security

- `resolve_store_url` now refuses a `--store-url` that names a different store than `AI_MEMORY_STORE_URL_FILE` or `AI_MEMORY_STORE_URL` (#4611), instead of silently using the environment store and reporting healthy. This is the refusal `backup` and `restore` already had; it now lives in the single resolver used by `serve`, `schema-init`, `curator`, `audit` and the other verbs, and the duplicate in `cli/backup.rs` is removed. An equal URL is accepted, and the winning channel is logged at info by name (never the URL).
