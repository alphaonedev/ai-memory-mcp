`ai-memory serve --store-url` (and `curator --store-url`) is reachable again on
any deployment whose `config.toml` sets `db =`. The `--db` / `--store-url`
mutual-exclusion guard inferred "the operator passed `--db`" from the resolved
path, so a configured `db` aborted the daemon with `Got --db=<config path>` for
a flag that was never on the command line; `--db` explicitness is now tracked
from the parser (argv / `AI_MEMORY_DB` only). A `sqlite://` store URL with no
explicit `--db` now also binds the daemon's local path, instead of migrating a
second, unrelated `ai-memory.db` in the working directory alongside the store
it was told to use.
