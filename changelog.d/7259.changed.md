CI runs the integration and lib test legs with cargo-nextest (`--profile ci`, `--no-fail-fast`) instead of `cargo test`: one process per test, a per-test timeout, no retries and JUnit output, installed from crates.io at a pinned version. Doc tests stay on `cargo test --doc`. A new `scripts/ci/nextest_args.py` translates the libtest tail, `scripts/ci/compare_test_sets.py` proves a runner swap executed the same tests with the same outcomes, and `scripts/test/pg_isolated_binary.py` accepts nextest (#7259, tracker #7267).
