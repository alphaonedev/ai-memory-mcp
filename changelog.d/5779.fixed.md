**The doc symbol-anchor gate reads or refuses every brace-list item (#5779).** An item or item component that was not an identifier (`&NoSuch`, `(NoSuch)`, `9NoSuch`, `-NoSuch`, a glob, an empty item) was skipped silently, and a path after a brace list (`src/x.rs::{T, U}::NoSuch`) was never read, so those stale anchors passed. Every component must now be an identifier or the anchor is refused as UNMODELLED, citing it as written; an ellipsis item is an elision and is skipped, and a turbofish separator (`T::<U>::m`) is read as a generic group. The `--self-test` gains 10 cases (#5779).
