The telemetry policy no longer claims operational tracing is payload-free: `docs/telemetry.md` §4 and ROADMAP §11.6 now state that four production `tracing::warn!` events (write-provenance miss, consolidation rollback conflict, and the two federation-receive skip paths) log the memory title to stderr and every configured logging sink, with no redaction, and name the call sites so operators route logs only to sinks cleared for titles (#3990).
