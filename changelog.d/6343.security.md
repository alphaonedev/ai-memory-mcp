### Security

- **[ci] The CLAUDE.md rule comparison masks SSH2, age and JSON Web Key private keys**
  ([#6343](https://github.com/alphaonedev/ai-memory-mcp/issues/6343), follow-up of
  [#6211](https://github.com/alphaonedev/ai-memory-mcp/issues/6211), CWE-532).
  `scripts/claude-md-rule-compare.py` recognised a private key block only in
  the five-dash PEM / PGP armour and the PuTTY file format, so an RFC 4716
  (SSH2) private key, an age identity (`AGE-SECRET-KEY-1...`) and the private
  members of a JSON Web Key reached the step summary. The SSH2 armour
  (`---- BEGIN SSH2 ENCRYPTED PRIVATE KEY ----` to its END line) is now a key
  block masked whole, an age identity is masked by its prefix, and a JWK
  private member (`d`, `p`, `q`, `dp`, `dq`, `qi`, `k`) is masked on a line
  that names the key type (`"kty"`) or whenever its value is 16 or more
  base64url characters. Regression cells: the `#6343` self-test cells.
