### Security

- cert-postgres-age.yml no longer runs psql with the postgres URL (password included) on its argv, in the ephemeral-db create, readiness, extension, version-assert and cleanup steps; the URL is read from stdin into libpq PG* variables by scripts/pg-url-libpq-env.py, which fails closed on a parameter it cannot map ([#4889](https://github.com/alphaonedev/ai-memory-mcp/issues/4889)).
