**Lib-test environment and working-directory writes are serialised on one process lock (#6123).**
Every lib-test write to an environment variable or to the working directory now runs under the
crate's single process-env lock (`crate::config::test_env_lock`; the identity lock for the agent-id
surface now delegates to it), and eight test fixtures build their scratch root from
`CARGO_MANIFEST_DIR` instead of the working directory. The new lexical gate
`scripts/check-env-mutation-lock.py` (with `--self-test`, wired into `c8-precheck.yml`) fails on the
unguarded call shapes listed in its docstring. Test code and gate only; no runtime code changes.
Regression: `recover::tests::limit_caps_atomised_lines` no longer fails when run in parallel with a
`migrate` test that changes into a tempdir and deletes it (7 of 10 parallel runs before, 0 of 10 after).
