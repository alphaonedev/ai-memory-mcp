**CI gate against shared test-database references (#7031, H4).**
`scripts/ci/check_shared_test_db_refs.py` fails the `classify` job on any new
reference to the shared bare test database `ai_memory_test`; an ephemeral
`ai_memory_test_*` name never matches. Rules: R1 URL literal, R2 `POSTGRES_DB`,
R3 `--db`/`--dbname`/`-d`, R4 `pg_isready -d`, R5 `KEY=NAME` for `PGDATABASE`,
`dbname`, `db`, `database` and any upper-case `*DB*`/`*DATABASE*` key, R6 a
quoted literal, R7 SQL `DATABASE NAME`, R8 the positional argument of `psql`,
`createdb`, `dropdb`, `pg_dump` and `pg_restore`. Every rule scans in linear
time, so a 1 MiB single line cannot stall the job. The scan covers `docs/`, the
executable top-level directories (`deploy/`, `ops/`, `tools/`, `loadtest/`,
`benches/`, `examples/`, `sdk/`, `clients/`, `conformance/`, `hooks/`,
`plugins/`) and every file directly under the repository root (`Dockerfile*`,
`install.sh`, entrypoint scripts).
The allowlist `scripts/qc-allowlists/shared-test-db-allow.txt` is a shrink-only
ratchet of `path:line  # citation` pins. The gate exits 1 on a violation and
takes exit 2 on: a stale pin (it no longer matches a hit), a whole-file, uncited or
duplicate allowlist entry, an unreadable file or directory, a missing `--paths`
entry or a renamed default directory, or an unreadable allowlist.
One bounded exception: the seven allowlist pins on
`scripts/ci/tests/test_pg_isolated_binary.py` carry `[landing-order #7088]`
because PR #7088 adds those lines. Such a pin is excused only while its line
does not exist yet; any other path, any other PR number or an existing non-hit
line exits 2. Remove the marker, `LANDING_ORDER_PRS` and `LANDING_ORDER_COUPLED`
in the change that lands after #7088 (#7164).
Round 3 (#7155, #7165): lower-case compound database keys (`test_db`, `db_name`,
`database_name`) and the glued `-dNAME` hit; the name matches case-insensitively;
a shell line continued with a backslash is scanned joined; R9 catches the psql
meta-commands `\\c NAME` and `\\connect NAME`; a backtick literal hits outside
Markdown; `//` and `#` comments are suffix-aware, so `#[...]`, `#define` and a
`//` line in a Python or shell file are scanned; a UTF-16/32 file exits 2 and a
NUL inside the name is stripped and scanned; the scope is now every top-level
directory except `target`, `vendor`, `changelog.d`, `.git`, `.local-runs` and
`node_modules`; an allowlist pin path is normalised (`./x` is `x`, `..` or an
absolute path exits 2). Env indirection, string concatenation, escapes and
percent-encoded URLs stay with the runtime refusals.
