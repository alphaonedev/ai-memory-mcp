### Security

- `scripts/postgres-droplet-reinit.sh` builds the schema-init store URL with `sslmode=verify-full&sslrootcert=<PG_SSLROOTCERT>` and refuses (exit 7) when the CA path is unset, unreadable or unsafe, so the 1.0.0 store-URL floor (#3705) is met and the script no longer relies on a URL the binary rejects. (#5143)
