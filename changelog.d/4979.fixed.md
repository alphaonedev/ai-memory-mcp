**`count_subscriptions` no longer reports a read fault as `0` (#4979, WP-FAULT #6051).**
The storage probe propagates the SQLite error instead of `.unwrap_or(0)`. The
doctor Webhook section renders `subscription_count = unreadable` with a
`subscription_count_error` fact at **Critical** (exit code 2), and the
capabilities `hooks.registered_count` is `null` with a `hooks.registered_count_error`
reason when the `subscriptions` table cannot be read — never a healthy-looking
`0`. The healthy wire shape is unchanged (an integer; the error field is absent).
