**Signal-drain test no longer false-reds when the child exits before the
stderr reader catches up (#6142, TEST-02).** `Session::fail_if_exited` in
`tests/mcp_signal_drain_4347.rs` now joins the stderr reader thread (reads to
EOF) after `try_wait` reports the exit and re-evaluates the awaited condition
(`stderr.contains(needle)` for `wait_stderr_contains`, the `entered` marker
file for `wait_entered`) before panicking. It panics only when the condition
is still false on the complete stderr. Pinned deterministically by
`a_child_that_exits_after_writing_the_awaited_line_does_not_false_red_the_wait_6142`
(reader held shut until the child exit is observed). No product code changed.
