**Cert-bootstrap gate LEG B (#7181).** `scripts/check-bootstrap-cert-gate.sh`
LEG B failed intermittently on the same commit with `NOT CERTIFIED ... audit tail
TRUNCATION detected by the off-table anchor`. Cause: the forensic audit sink
defaults to a shared per-user state directory, so an earlier gate run on the same
host left an audit watermark for the same genesis-derived database id and a fresh
bring-up (head below that watermark) was convicted of truncation. Every LEG B
sandbox wrapper now pins its own audit and log sink directories and every role
key directory (`AI_MEMORY_KEY_DIR`, `_WITNESS_`, `_RECORDER_`, `_JUDGE_`,
`_STOPPER_`), the witness and recorder `identity generate` calls run inside the
sandbox and are no longer silenced, and an `EXIT` trap removes every `mktemp`
directory. A failing LEG B now prints a redacted, bounded (last 200 lines per
file) `bring-up.out` and sibling evidence into the job log
(`scripts/cert_gate_evidence.py`), and the `Certified pg+AGE cells` workflow
uploads the evidence directory as an artifact on failure.
