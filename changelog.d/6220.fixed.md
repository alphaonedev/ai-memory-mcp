**The compliance script-name gate matches names in any letter case and checks existence by exact name (#6220).**
`scripts/check_compliance_script_names.py` matched only lower-case `check-`/`check_` names
with lower-case `.sh`/`.py` suffixes, so `CHECK-cert-expiry.sh` or `check_x.PY` was never
checked. Existence used `is_file()`, which on a case-insensitive filesystem (macOS APFS
default, Windows) accepts a case variant of a file or directory that does not exist under
that name in the repository. Names now match in any ASCII letter case (`re.ASCII`, so the
Kelvin sign and long s are not folded in). Allowlist entries accept the same forms, and
every path component must appear under its exact name in its parent directory's listing.
