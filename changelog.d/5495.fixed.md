**The doc symbol-anchor gate no longer accepts a pointer, tuple or slice self type unchecked.** `<*const Missing>::m`, `<(Missing)>::m` and `<[Missing]>::m` named no identifier at the head, so the group was dropped and the missing type passed (at the range base too). `*const` and `*mut` are now skipped like `&`, so the pointed-to type is checked, and a self type with no identifier after its prefix (tuple, slice, a nested leading group, a bare bound) is refused as an anchor the gate cannot decide. Real tree: 0 lines change. The `--self-test` gains 7 cases (#5495).
