**One boolean env grammar for every security knob; `asi-hard` pins the daemon bind posture (#3200, folds #3618 #3619 #3620 #3621).**

The binary carried more than fifty hand-written boolean env parsers in seven shapes, so the same token meant different things to different knobs.
- `AI_MEMORY_REQUIRE_TLS=yes` left the TLS mandate off and bound plaintext without a warning.
- Under `asi-hard`, `AI_MEMORY_REQUIRE_AGENT_ATTESTATION=yes` met the posture floor while the live reader ignored it, so unsigned CLI/MCP stores still landed (#3618).
- `AI_MEMORY_FED_QUARANTINE_UNATTRIBUTED=TRUE` did the same to the quarantine (#3619).
- `AI_MEMORY_PASSPHRASE_FILE_ALLOW_LAX_PERMS` had two readers with two grammars (#3620).
- A padded `AI_MEMORY_ENCRYPT_AT_REST= 1` left at-rest encryption off (#3621).

Every MANDATE (tightens a control) and HATCH (loosens one) boolean knob, and every `asi-hard` floor, now reads through one registry, `src/env_flag.rs`.
- **Accepted tokens.** `1`/`true`/`yes`/`on` enable and `0`/`false`/`no`/`off` disable, case-insensitive and trimmed. An empty value counts as unset.
- **Unrecognised tokens refuse boot.** An unrecognised token on a registered knob refuses boot with a message naming the knob, the token and the accepted grammar. This applies to mandates and hatches alike.
- **Changed tokens warn once.** A token whose meaning changed versus its old reader gets a one-shot boot WARN naming the old and the new reading, in both directions.

**Operator-visible changes.**
- `=yes`/`=on` now ENABLE knobs that used to accept only `1`/`true`. This affects `REQUIRE_TLS`, `REQUIRE_API_KEY`, `ALLOW_PLAINTEXT_NONLOOPBACK`, `GOVERNANCE_FAIL_OPEN_ON_ERROR`, the lax-permission hatches, `SSRF_GUARD_ALLOW_DNS_FAIL`, `ADMIN_HEADER_TRUST`, and the exact-`1` federation trust hatches `FED_TRUST_BODY_AGENT_ID` / `FED_SYNC_TRUST_PEER`.
- `=FALSE`/`=OFF` now DISABLE the default-on federation gates. They used to stay on because those readers were case-sensitive.
- A garbage value that used to be silently ignored now refuses boot.

**`asi-hard`.**
- The posture pins `AI_MEMORY_REQUIRE_API_KEY=1`: `serve` needs a top-level `api_key`.
- `AI_MEMORY_ALLOW_PLAINTEXT_NONLOOPBACK` is pinned closed.
- `serve` refuses a NON-loopback plaintext bind outright. The loopback exemption stays for a same-host TLS-terminating proxy, which is why `AI_MEMORY_REQUIRE_TLS` is not pinned.
- 27 → 29 pinned knobs.

New gate `scripts/check-truthy-grammar.sh` (c8-precheck job `truthy-grammar-gate`) fails on any inline boolean grammar outside `src/env_flag.rs` that has no row in the dated NEUTRAL ledger. It also fails on a stale row, so the ledger only shrinks (#3622).
