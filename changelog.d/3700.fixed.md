**The deployment-shape detector: an undeclared fleet is no longer silent (#3700).**

`AI_MEMORY_SECURITY_PROFILE=asi-hard` pins the machinery that stops one
agent's wrong conclusion from becoming a swarm's shared truth —
`REQUIRE_WITNESS` (corroboration), `REQUIRE_AGENT_ATTESTATION`,
`FED_QUARANTINE_UNATTRIBUTED`, the four `FED_REQUIRE_*_SIG` gates, cause
binding, identity lineage, rollback check, role separation, `CID_ENFORCE`,
`DB_SYNCHRONOUS`. #3714 made the DECLARED `[deployment] shape` the primary
input (`production` / `federated` / `hive` pin `asi-hard` as a floor). What
was still missing: nothing checked the declaration against what the node is
actually configured as, so a federated multi-agent node still declaring
`singleton` booted with every protection OFF and no line in any log.

- **The detector** (`src/config/shape/detector.rs`). At boot the node observes
  content-free signals — federation: `outbound_peers` / `listener_mtls`
  (argv), `inbound_bindings` / `peer_allowlist` (env),
  `mcp_federation_forward_url` (config); multi-agent: `wake_hub` (config),
  an `agent_registry` of two or more agents read from the real store on
  both backends once it opens — and derives the least demanding shape they
  allow (`singleton` / `team` / `federated`). A signal a process cannot see
  is `unobservable`, never `absent`.
- **Undeclared promotion warns and is recorded, never re-postured.** When
  the observed floor exceeds the declared shape the boot WARNS once,
  records it (forensic audit kind `deployment_shape.undeclared_signals`;
  the `deployment_shape` field of capabilities v2/v3) and names the exact
  `[deployment] shape = "…"` line to declare. With the posture at
  `standard` the warning says every anti-cascade protection is OFF.
  Promotion is an operator act.
- **A hardened declared shape with knobs below its floor refuses**, naming
  EVERY such knob and both ways out. A singleton with no signals boots
  byte-identically.
- **`doctor` says it unprompted.** "Deployment shape detector (#3700)"
  follows the declared-shape section in the default report: declared vs
  observed floor, signals, registry, the promotion line, posture and
  origin, the protections that are off, and the boot verdict.
- **Migration honesty.** The detector ships with the refusal: run
  `ai-memory doctor` before upgrading to learn exactly what will refuse.
