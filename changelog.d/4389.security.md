**Coordination creates refuse the quota sentinel namespaces (#4389).** The signal, checkpoint, action and routine create surfaces validated their namespace for shape only, so a create into `_notify` (the per-sender notify aggregate row that the namespace-omitted quota rollup excludes) or `_global` (the v50 backfill sentinel) charged its storage bytes to the sentinel row and hid them from the agent's rollup (self-scoped under-reporting; the per-row ceilings still applied). The shared `coordination_guard::require_namespace` now refuses both sentinels on every create path; other `_`-prefixed coordination namespaces are unchanged.
