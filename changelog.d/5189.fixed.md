**The doc symbol-anchor gate now range-checks the `#L` line fragment of a relative `src/` link.** `scripts/check-doc-symbol-anchors.sh` checked the file (and the symbol) of `[label](src/x.rs#L<n>)` but threw the fragment away, so `#L9999`, `#L0` or a reversed `#L3-L2` passed although GitHub renders them as line links that rot like `:N` anchors (#5189). The `#L<a>` / `#L<a>-L<b>` fragment of every relative `src/…rs` link, whatever its label, is now checked like a `:a-b` anchor and reported as `LINE`; a commit-pinned permalink (an https URL) is immutable and still exempt. No scanned doc used a relative link with `#L`, so no doc changed. The `--self-test` gains eight cases.
