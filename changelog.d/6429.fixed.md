**`--pre-apply` no longer reads a flow-mapping `pull_request` trigger as covering every base (#6429, carrier gate #6143, #6232 follow-up).** `trigger_covers` in `scripts/check_carrier_ruleset_live.py` returned true for `on: {pull_request: {branches: [main]}}` and for `  pull_request: {branches: [main]}`, so a carrier tip whose workflow excluded that carrier passed the precondition and the required contexts would never report after the ruleset `POST`. A flow mapping, or any inline value other than empty, `null` or `~` after `pull_request:`, is now unparsed and fails closed. Pinned by self-test cells run through `carrier_ruleset_live_checker_self_test_passes_6143`.
