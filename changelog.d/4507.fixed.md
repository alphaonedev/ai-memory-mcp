**[docs][tooling] `CLAUDE.md` shrunk from 448 KB to under 80 KB so agent sessions stop loading 200k+ tokens on turn one** ([#4507](https://github.com/alphaonedev/ai-memory-mcp/issues/4507)).
The `## Architecture` and `## Code Style` bodies moved verbatim to `docs/reference/ARCHITECTURE_REFERENCE.md` and `docs/reference/CODE_STYLE.md`; `CLAUDE.md` keeps every rule section plus pointers. `check-docs-vs-ssot.sh` (env-var census, narrative counts, pinned-knob count) and `check-doc-symbol-anchors.sh` read the moved content at its new location, and `scripts/check-claude-md-size.py` fails CI if `CLAUDE.md` exceeds its byte ceiling.
The guard also pins a minimum body size for each of the 15 rule sections, requires `docs/reference/` and both reference files to be real (not symlinks) with their `##`/`###` subsection headings intact, indexes the agent-directed prohibitions that now live only in the reference files as verbatim, line-cited quotes in `CLAUDE.md` (every quote is verified against the cited lines in CI), and treats tilde fences and HTML comments as non-heading regions. `check-docs-vs-ssot.sh` and `check-doc-symbol-anchors.sh` now fail closed when either reference file is missing. About 80 citations of the moved content in docs, source comments, test messages and html pages were retargeted to the reference files.
