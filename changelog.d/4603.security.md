### Security

- The `deploy/do-1461` and `deploy/hive-1461` systemd units, `entrypoint.plan-c.sh`, `deploy/enterprise-federation-repro/{repro,verify}.sh`, `infra/pillar4-envelope/measure-envelope.sh`, `deploy/hive-1461/provision/20_pg_age.sh` and `scripts/postgres-droplet-reinit.sh` no longer pass the store URL on a `--store-url` argument (a systemd or shell expansion put the database password in `/proc/<pid>/cmdline`). The daemon reads `AI_MEMORY_STORE_URL` from the unit's `EnvironmentFile`, the container environment or a 0600 `AI_MEMORY_STORE_URL_FILE`. The two provisioners refuse a pinned binary older than 0.9.0, which has no env channel and would silently fall back to sqlite. `scripts/check-docs-no-argv-secrets.py` now also flags `--store-url "$DSN"`-style expansions.
