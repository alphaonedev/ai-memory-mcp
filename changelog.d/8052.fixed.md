**The env-mutation gate models detaching helpers outside the test file (#8052).** A helper in `tests/common` or in a `#[path]` or `mod` file that hands its parameter to a spawn (`common::bg(move || ..)`, `use common::bg`, `sp::bg(..)`) was not seen, so its closure argument was credited with the lock; such calls now detach their argument, and a helper that runs it inline stays clean.
