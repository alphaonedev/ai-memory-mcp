**The doc symbol-anchor gate's absent-path exemption no longer covers a file named by "split into", "split out" or an arrow followed by a `src/` path.** Those words name the live destination, so `scripts/check-doc-symbol-anchors.sh` now exempts only an anchor BEFORE them (the source the sentence says has gone), not the file after them; "was split into" is no longer a window-wide absence wording. Plain paths next to the gone-file wording (formerly, monolithic, pre-split, was split, split from) stay exempt by design. Real tree: 0 lines turn red. The `--self-test` gains seven cases (#5264).
