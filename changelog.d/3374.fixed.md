Refuse numeric and boolean MCP parameter values whose JSON type contradicts the
declared schema instead of silently substituting a server default. A fractional
or stringy `priority` on `memory_action_create` used to store priority 0 (the
lowest frontier rank), a non-integer `ttl_secs` on `memory_signal_send` or
`memory_lease_acquire`/`_renew` used to mint a signal that never expires or a
60-second lease the caller never asked for, a negative `limit` on
`memory_signal_inbox`/`memory_inbox` used to return the 50-row default, and a
non-boolean `unread_only` or `enabled_only` (or a non-string `kind`) used to
drop the filter and return every row.
