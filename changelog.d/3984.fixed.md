**#3984 — gate scripts compare and sort under `LC_ALL=C`.** `check-required-contexts-live.sh`
sorted its context lists under `LC_ALL=C` but compared them with a bare `comm` in the ambient
locale. Under `en_US.UTF-8`, `comm` warned "not in sorted order" and reported the wrong names: a
context on both sides was listed as drift, so the report no longer showed which declared context was
really missing from live protection. Both `comm` calls now run under `LC_ALL=C`, and a new self-test
cell runs the gate under a non-C locale with punctuation-leading context names. The same prefix is
added to every other bare `comm`/`sort` in `scripts/` (51 call sites across 21 scripts, the two above included; the
frozen historical fixtures under `scripts/test/fixtures/` are deliberately left byte-for-byte), so gate
verdicts and orderings no longer depend on the host locale. The live-context gate now also runs wholly
under `LC_ALL=C` and trims only ASCII space/tab from context names: under a UTF-8 locale the old
`[[:space:]]` trim erased a leading or trailing U+2003/U+00A0, so a different name compared equal to its
ASCII twin and the gate reported "declaration == live" (R4-G1). `check-required-contexts.sh` had the
same trim and is fixed the same way; both self-tests now carry Unicode-padding cells.
