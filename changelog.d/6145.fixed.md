### Fixed

- **[ci-gate] cert-expiry self-test git PATH shim now runs under `python3 -I`**
  ([#6145](https://github.com/alphaonedev/ai-memory-mcp/issues/6145)).
  The `--self-test` of `scripts/check_cert_expiry.py` wrote a `git` shim executed as a
  Python script without `-I`, the one Python entry point in the gate's path that was not
  isolated (the gate itself runs under `python3 -I` in `c8-precheck.yml`). The shim's
  interpreter line is now `<python> -I`, and a new `shim-isolation` self-test cell executes
  the shim's probe and asserts `sys.flags.isolated` is set and the shim's own
  directory is not on `sys.path` (so a module planted beside it cannot be imported). Hardening of the self-test scratch directory only; not a live bypass.
