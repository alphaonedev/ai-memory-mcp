The `PostgresStore::get_any` docstring no longer says no Postgres path writes `contaminated`. It now names the two writers: `link_signed` (HTTP `POST /links`) auto-stamps on a `supersedes` link between two reflections, and the admin swarm rewind stamps the cascade; `kg_invalidate` stamps nothing. `tests/docs_get_any_contamination_4050.rs` pins the docstring to those code facts (#4050, residual of #3925).
