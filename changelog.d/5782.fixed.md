**The doc symbol-anchor gate runs every per-line rule on the decoded text (#5782).** Only the qualified-anchor rule read the decoded readings of a line (#5607); the path rules (PATH, the `path:line` rule, BARE_LN, the link rules) saw the raw text, so a path whose dots, underscore or colon were written as character references was never checked: an entity-spelled `..` segment, an entity-spelled underscore in a missing path, an entity-spelled dot before a line number and an entity-spelled colon all passed. Every rule now runs on each reading of a line (CommonMark and HTML when it, or the line before or after it, holds a character reference, so a link target continued onto the next line is read decoded too); a finding both readings make is reported, and when the readings disagree the line is refused as UNDECIDABLE_REF citing its qualified anchors or, with none, the tokens the readings disagree on (never a bare dash). The header TEXT FORM paragraph and UNDECIDABLE_REF sentence say so. The `--self-test` gains 8 cases (#5782).
