`SECURITY.md` and `docs/encryption.html` no longer advertise a nonexistent `[storage] encrypt_at_rest = true` as the TOML way to enable application-level content encryption: the effective setting is `[encryption].at_rest = true` (or `AI_MEMORY_ENCRYPT_AT_REST=1`), and both carriers now say so and note that `[storage]` has no such field — a broken security-configuration instruction is replaced with the one the resolver actually reads (#4245).
