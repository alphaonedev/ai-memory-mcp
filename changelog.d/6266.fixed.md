**`cargo test --lib` no longer leaves sqlite scratch files, `-wal`/`-shm`/`.pre-migration-*.bak` siblings or `ef-posture-audit-*` / key-sandbox directories in `TMPDIR` (#6266, follow-on to #6122).**
Two test-only leak classes: unit tests under `src/` opened sqlite databases on a
`tempfile::NamedTempFile`, which unlinks only the main file; and two
`static OnceLock<TempDir>` values (`identity::test_key_dir::DIRECTORY`,
`POSTURE_AUDIT_DIR`) were never dropped, orphaning one directory per test process
and per env-isolated child. `src/test_support/sqlite_tempfile.rs` (a `cfg(test)`
copy of the #6122 helper) now owns the sidecars and migration backups, and
`src/test_support/exit_cleanup.rs` removes the static directories at process exit.
Production code is unchanged. Guard:
`test_support::leak_guard_6266::issue_6266_lib_tests_leave_no_scratch_in_tmpdir`.
