The self-test of `scripts/claude-md-rule-compare.py` now runs the comparison as a program and checks its exit code: an unapproved rule change exits 1 with `RESULT: FAIL`, an approved one exits 0 with `RESULT: PASS`, and a shallow repository exits 1 with `RESULT: FAIL (closed)`. Before, a `run()` that returned 0 for a failed comparison kept the self-test green while the CI job read a passing exit code (#6741).
