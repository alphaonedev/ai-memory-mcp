**Cert-expiry shadow scan treats only space and tab as YAML whitespace (#6304).**
The `GUARD SHADOW` scan of `scripts/check_cert_expiry.py` decided which workflow
lines are blank or comment-only with Python `str.strip()`, which also removes NBSP,
U+3000, FF and other characters that YAML keeps as content. A line led by one of
them and then `#` was skipped by the scan and read by a YAML parser, so a second
job named for the required cert-expiry context could pass the shadow scan with no
approval trailer. The blank and comment tests (`_workflow_lines`, `_yaml_hazards`)
now strip a space and a tab only, and a whitespace character other than space or
tab (and the line breaks already refused by #6228) anywhere in a workflow file is
refused as `GUARD SHADOW`, which no trailer waives. The real workflow files carry
none, so no workflow is newly refused. Self-test cells `tr-s-nbsp`, `tr-s-ideo`,
`tr-s-ff`, `tr-s-vt`, `tr-s-nbsp-quoted` and `tr-s-nbsp-block-c8` pin the shapes and
`tr-s-tabcomment` keeps a tab-indented comment with trailing spaces GREEN.
Refs #6140, #6228, #6177.
