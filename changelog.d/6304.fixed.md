**Cert-expiry shadow scan treats only space and tab as YAML whitespace (#6304).**
The `GUARD SHADOW` scan of `scripts/check_cert_expiry.py` decided which workflow
lines are blank or comment-only with Python `str.strip()`, which also removes NBSP,
U+3000 and other Unicode spaces that YAML keeps as content (and FF, VT and U+001C-U+001F, which
YAML refuses outright). A line led by NBSP, U+3000 or another kept space and then `#` was skipped by the
scan and read by a YAML parser, so a second
job named for the required cert-expiry context could pass the shadow scan with no
approval trailer. The blank and comment tests (`_workflow_lines`, `_yaml_hazards`)
now strip a space and a tab only, and a whitespace character other than space or
tab (and the line breaks already refused by #6228) anywhere in a workflow file is
refused as `GUARD SHADOW`, which no trailer waives. The real workflow files carry
none, so no workflow is newly refused. Self-test cells `tr-s-nbsp`, `tr-s-ideo`,
`tr-s-ff`, `tr-s-vt` (FF, VT and U+001C-U+001F are not loadable YAML and are refused all the same), `tr-s-nbsp-quoted` and `tr-s-nbsp-block-c8` pin the shapes and
`tr-s-tabcomment` keeps a tab-indented comment with trailing spaces GREEN.
The refusal names every offending line (the first 8, then `+K more`, with a count)
and every code point (the first 8, then `+K more`); cells `tr-s-ws-lines` and
`tr-s-ws-nine` pin the format and `tr-s-ws-U+XXXX` pins each of the 22 refused
code points, and `tr-s-ws-line1-U+XXXX` pins the same refusal on line 1 of a workflow (#6684). Cells `tr-s-ws-oneline`, `tr-s-ws-dedup`, `tr-s-ws-eight` and `tr-s-ws-count` pin one line number per line, repeated code points listed once in first-seen order, the `+K more` boundary at eight items and the count in lines (#6760-#6763); the `SELF_TEST_OK` line names every round and its cells (cell `summary-rounds`, #6765).
Refs #6140, #6228, #6177, #6554, #6555, #6556.
