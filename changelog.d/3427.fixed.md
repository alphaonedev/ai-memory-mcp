**`GET /api/v1/export?namespace=` is honoured (#3427).** The parameter was
never wired: the handler had no query extractor and the store had no
namespace argument, so an admin asking for one namespace received every
namespace with a `200` and no hint the scope was dropped — an egress verb
lying about its bound. The scope now reaches both backends as a `WHERE`
predicate on the bounded, ordered page query (never a post-filter), is pinned
in the paging cursor (a scope switch mid-walk is refused), and is echoed back
as `namespace` on every body; an edge whose other endpoint is outside the
scope is withheld and counted. Any unknown query parameter is refused with
`400` naming it — silence is the one unacceptable outcome. `POST
/api/v1/memories/bulk` classifies an invalid `kind` / `on_conflict` token as
`VALIDATION_FAILED` (400) instead of `INTERNAL_ERROR`. The Python SDK's
`export_pages(namespace=…)` scopes the walk.
