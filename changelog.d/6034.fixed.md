The append-only scratch janitor (`scripts/clear-append-only-scratch.py`) can no longer delete another run's fsynced journal line when it cuts off a torn tail (#6034). The cut used the length of an earlier read with no lock held, so a line appended in between could be cut with it, leaving that run's widen unrecorded. The cut now happens only under the journal lock of #6032, which no other run can hold at the same time.
