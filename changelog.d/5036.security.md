### Security

- **[gate] The #3607 enterprise-federation posture ladder is now asserted, not
  just recorded**
  ([#5036](https://github.com/alphaonedev/ai-memory-mcp/issues/5036)).
  `scripts/recapture-cert-3607-posture.sh` wrote the four doctor-leg exit codes
  into `posture-legs-exit-codes.txt` and exited 0 on any ladder shape, so the
  cert leg could not fail on a posture regression (for example a bare-env leg
  that began exiting 0 with 22 PASS). The script now ends by running the new
  fail-closed `scripts/check-posture-ladder.py`, which requires leg exits
  `2/2/1/0`, the exact per-capture `[PASS]/[FAIL]` counts, the strictly
  decreasing failure ladder `bare 12/10 > hardened 20/2 > sqlcipher 22/0`, a
  non-empty leg-3 boot refusal that names the control, and (when both binaries
  are supplied) distinct default and sqlcipher binary digests. It carries a
  planted-mutant `--self-test`. Same shape as `check-cert-leg-nonvacuity.sh`
  (#3552). Also: the transcript header prints the UTC run date instead of a
  frozen literal ([#5039](https://github.com/alphaonedev/ai-memory-mcp/issues/5039) part A).
