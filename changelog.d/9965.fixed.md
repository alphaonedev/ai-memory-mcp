Certified AGE build (#9965, #9966, #9967, #9968, #9969): the certified tier is one exact build, Apache AGE 1.7.0, built from upstream PG19 branch commit c6b043d plus upstream fix commit 06ce678d (apache/age#2581) (not a tagged Apache release; upstream has no 1.7.0 release for PostgreSQL 19). The fix is a repository patch file whose upstream sha and sha256 are pinned in `deploy/docker-1461/provision/lib.sh`; `deploy/docker-1461/provision/apply_age_patch.py` applies it at build time in every builder (the Linux images, the do-1461 and do-hive lanes and the macOS f1 steps) and fails the build when the source, the patch or the guard is not the pinned one. The PostgreSQL base image is pinned by digest (`PG_BASE_IMAGE`) and recorded in the CI image summary, every version check is an exact match, `ensure-age-extension.py` requires `pg_config` to be an absolute path to an executable regular file, and the certified-tier ratchet is an allowlist over the whole tracked tree.
