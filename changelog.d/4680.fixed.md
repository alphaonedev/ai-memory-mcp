**The doc symbol-anchor gate now checks a backticked `./src/<path>.rs` anchor.** The `PATH` and `PATHLN` rules in `scripts/check-doc-symbol-anchors.sh` accepted only a `../` prefix, so a backticked `./src/x.rs:<N>` anchor with a stale line, or one naming a missing file, passed unchecked. A `./` prefix is now treated like no prefix. The `--self-test` plants a `./src/` anchor with a stale line and a `./src/` anchor to a missing file (both must fail) (#4680).
