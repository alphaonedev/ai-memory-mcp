**The PG wrapper exits 4 (`NOT released`) when a WrapperError leaves an owned database behind, not the usage code 2 (#7200).**

`main()` mapped every WrapperError to exit 2, so a failure that stranded a minted base or template looked like a usage error to the caller. It now logs `NOT released: <names>` and returns the unreleased exit code (4) whenever an owned name remains; a WrapperError with nothing owned still exits 2.
