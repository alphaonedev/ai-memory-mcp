**The cert-expiry self-test nonce check keeps the named-failure contract (#6650).** The `(shim-probe-exact)` nonce-freshness loop called `run_gate_shimmed` outside `shimmed_cell`, so a git shim that could not be executed ended `--self-test` with a `GateError` traceback (rc 1) and skipped every later cell. The loop now runs through `shimmed_cell`, so the same case is a named `(shim-probe-exact)` failure (rc 2) and the remaining cells still run. The new `(shim-probe-exact-noexec)` cell pins it by leaving the shim non-executable.
