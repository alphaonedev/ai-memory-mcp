**[release][supply-chain] The release packages ship only the bytes the strict assert checked (#6907, umbrella #6062).**
The #4752 record hashed the asserted binary with whatever `shasum` and `cut`
the job's `PATH` resolved, and the package step read the binary again with
`cp` after the compare. A tool shim on `PATH`, a rewrite of the binary while
the assert read it, or a rewrite of the copy between the compare and the
tarball or `nfpm` could ship bytes the assert never saw. Now the bound
`reproducible_build.py` (run with `/usr/bin/python3 -I` under a cleared
environment) hashes the binary before and after the strict assert and the two
digests must agree; the package step reads the binary once, checks it against
the recorded digest and writes the tarball and the `dist/` copy from that one
read; and the deb and rpm step opens each package after `nfpm` and refuses it
unless its only payload file is `usr/bin/ai-memory`, mode 0755, with the
recorded SHA-256. Regression: the `6907 ...` guard self-test cases, seven
package runtime forms in the guard self-test, and the packer's own payload
self-test.
