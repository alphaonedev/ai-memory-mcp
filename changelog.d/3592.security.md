**TypeScript SDK: linear `baseUrl` trailing-slash trim (#3592).**

`AiMemoryClient` no longer strips trailing slashes with `replace(/\/+$/, "")` (CodeQL `js/polynomial-redos`). An end-index scan + one `slice` is byte-identical for normal URLs and stays linear on a 100k-slash input. No API change; SDK version stays 1.0.0.
