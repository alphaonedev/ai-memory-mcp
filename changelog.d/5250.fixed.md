**The doc symbol-anchor gate no longer lets a "formerly" or "pre-split" line exempt a relative link to a deleted `src/` file.** `RELLINK` and the `MDLINK` file branch honoured the absent-path exemption, so `Formerly [the handler](src/gone.rs) held it` passed. A link target is a claim that the file exists; `scripts/check-doc-symbol-anchors.sh` now applies the exemption only to plain path and line anchors. The `--self-test` gains three cases (#5250); the escape-token link form is closed by #5346.
