**The doc symbol-anchor gate no longer treats every arrow as destination wording.** The #5264 change made `->` and the Unicode arrow exempt a missing `src/` file that comes before them anywhere on the line, so a Rust signature (`-> u32`), an HTML comment end (`-->`) or a table arrow hid a stale anchor. An arrow now names a destination only when a `src/` path follows it (as before #5264), on the same line or at the start of the next. Real tree: 0 lines turn red. The `--self-test` gains six cases (#5341).
