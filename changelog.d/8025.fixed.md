**A base ref that resolves but has no merge-base is its own refusal (#8025).** `base_manifest` used to treat a ref whose `git merge-base` failed as unresolved, fall through to the next ref, and then refuse with the false text "no base ref resolves". A ref that resolves (`rev-parse` rc 0) and whose merge-base fails now returns `BASE_ERROR` naming the ref and the merge-base error, and no later ref is tried, so the ratchet reports "ratchet baseline unreadable" and the self-test exits 2. Proof: `Ratchet.test_resolving_ref_with_failing_merge_base_is_undecidable` in `scripts/ci/tests/test_check_cert_expiry_corpus.py` (a scratch repo with a disjoint ref).
