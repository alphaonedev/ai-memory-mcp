**A push to a Promotion carrier (`chain/**`) now runs the required-set workflows (#6117).**
Since #6105 the carrier gated PRs opened *into* it, but a signed merge *onto*
it (a lane PR landing, a release sync, a bootstrap merge) ran no workflow at
all, so carrier-only defects (#6115, #6116) stayed invisible until the next PR
opened against the carrier. `ci.yml`, `c8-precheck.yml`, `coverage.yml`,
`release-shape.yml`, `cert-postgres-age.yml` and `postgres-ignored.yml` list
`chain/**` under `push.branches`. The carrier is also the head of its promotion
PR (#6160), so the three workflows whose cancel group was not yet keyed per
event (`ci`, `coverage`, `c8-precheck`) fold `github.event_name` into it: the
push run and the PR run complete side by side instead of one cancelling the
other (the #2508 class). A carrier push runs the full pipeline and the
range-scoped gates judge the whole carrier against `release/v1.0.0`, so the
push verdict is never narrower than the promotion-PR verdict beside it.
Range and tree: the required `Promotion ancestry soundness` (#3872) step now
measures a carrier push (the pushed sha against `release/v1.0.0`) instead of
answering INAPPLICABLE, so a carrier behind the release is red on the push
run as on the PR run, and at behind=0 the PR merge tree equals the HEAD tree
the push run tests. The four carrier range-start steps read the release ref
from `scripts/check_promotion_geometry.py --print-release` (one source) and
fail with an `::error::` line when the fetch or merge-base fails.
`rehearsal/**` stays off `push.branches`. Pinned by R-CHAIN / R-CHAIN-KEY in
`scripts/test/test_workflow_pr_triggers_5447.py`, C4 of
`scripts/test/test-ci-workflow-invariants.sh`, the `chain/` and `rehearsal/`
PR-head probes of rule (d) in `scripts/check-required-contexts.sh` and
`SHAPE_ON` in `scripts/check_release_features.py`.
The approval evaluator's guards are pinned by killed-mutant tests in the same
module: token prefixes and the PAT tail (#6390), the self-test's `0 failed`
line and PASS count (#6392), the login/association/repo/sha bounds (#6393),
NEL replacement and the stderr cap (#6394), and the empty-operator, gh
timeout and boolean PR-number refusals (#6395).
