**The doc symbol-anchor gate checks every bound and every path component of a self type, and refuses a self type it cannot read (#5610).** Further bounds were checked only when the self type had a `dyn`, `impl` or leading-`+` prefix, so the bare 2015-edition trait object `src/x.rs::<T + NoSuch>::m` was accepted with `NoSuch` never looked up; only the first identifier of the type was checked, so `<T::NoSuch>::m` was accepted too. Every further bound is now checked whatever the prefix, the type is read as a whole path and every component is checked, and a lone placeholder is exactly `<Name>` or `<Name<...>>`. A first bound with text the reader cannot place after it (two words, a `Fn(..)` sugar, a function pointer) is refused as `UNMODELLED`, cited with its whitespace removed. Not modelled: the trait after `as` is not checked (#5460). Base: accepted; tip before this fix: accepted; now reported or refused. Real tree: 0 lines change. The `--self-test` gains 11 cases (#5610).
