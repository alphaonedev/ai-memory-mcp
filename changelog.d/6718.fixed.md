**The #6427 cert-expiry changelog fragment names only real self-test cells (#6718).** The fragment cited `(value-same-line)`, which #6626 renamed, and "the digit-prefix cells", which never existed. It now names `(value-edit-5-to-6)`, `(value-next-line)`, `(trailing-comment-added)`, `(doc-bound)` and `(mask-longer-digit)`. The self-test records the label of every cell that runs, and `(doc-bound)` fails if the fragment names a cell (a backticked `(name)` or "the NAME cells") that did not run.
