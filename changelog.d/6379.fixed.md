**The cert-expiry self-test verifies that its git shim is reachable (#6379).** `run_gate_shimmed` refused only a scratch path containing the PATH separator; a shim that was installed but not executable, or on a mount that refuses exec, still let PATH lookup fall through to the real `git`, so the `(gitver)` and `(anc-error)` cells blamed the gate. The shim now answers a probe argument with a fixed marker, `run_gate_shimmed` runs `git <probe>` through the shimmed PATH before use, and raises "the git shim is not the git on PATH" unless the marker comes back. The new `(shim-unreach)` cell pins it with a non-executable shim.
