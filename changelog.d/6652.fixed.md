**The cert-expiry docs no longer promise RED for a value edit whose old line survives elsewhere under `src/` (#6652).** The docstring, the OK banner and the #6427 changelog fragment said a value edited on the identifier line is always drift. The keyed comparison is a multiset of `(identifier, trimmed line text)` over all of `src/` without the path, so the edit is GREEN while the old line text still occurs elsewhere: in a block comment, a raw string, compiled-out code or an undeclared file. The three texts now carry the qualifier "unless the old line text still occurs elsewhere under src/" and state the multiset bound. The `(value-copy-bound)` cell pins the block-comment copy as GREEN, and `(doc-bound)` requires the qualifier, the multiset statement and the banner entry.
