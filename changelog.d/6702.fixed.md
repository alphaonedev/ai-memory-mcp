**A key/value DSN behind a `sqlite://` scheme no longer renders verbatim (#6702, CWE-532).** The sqlite store-URL renderer redacted only on `@`, so `sqlite://host=db password=<pw>` was printed whole by every sink that renders a store URL or a database path. A `=` in the rendered path part now also renders `sqlite://<redacted-authority>`; a `?mode=ro` query is still dropped from the display, not redacted.
