CLI stdout/JSON hygiene. `serve` and `sync-daemon` wrote their tracing output
(ANSI included) to STDOUT because their subscribers omitted `.with_writer` and
the `tracing_subscriber` default is stdout; every console subscriber now
installs through one funnel that pins stderr, so a long-running verb's stdout
stays a data channel. `--json` is a global flag that clap accepted on all 94
subcommands while only some honoured it — `install`, `wrap`, `man`,
`config check` and `export-forensic-bundle` took it, exited 0, and printed their
ordinary human output; the flag is now classified per subcommand by one
exhaustive match and REFUSED with a clear error where no JSON form exists,
before any work runs. `rules keygen --json` printed a human status line
immediately before its JSON envelope; human status lines now route through a
`--json` contract helper that sends them to stderr in JSON mode.
`verify-reflection-chain <unknown-id>` reported `ok: true` and exited 0 because
an empty walk satisfies the `ok` predicate vacuously; an unresolvable root is now
NOT FOUND with exit 1, kept distinct from exit 2 (verification failed).
