**`ai-memory logs tail --follow` no longer jumps back to an older log file when the file it follows is renamed away or removed (#7964).** The poll switched whenever the newest listed file differed from the followed path, so when the followed newest file was archived (renamed to `.zst`) or deleted while an older log still existed, the follower reprinted that older file from the start. It now switches only to a file that sorts after the followed one, the same ordering used to pick the newest file, and otherwise keeps draining its open handle.
