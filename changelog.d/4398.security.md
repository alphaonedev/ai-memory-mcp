Under the composed #4285 x #4357 rule an explicit value decides: a value that is not a non-negative integer fitting `u32` now resolves to approval threshold `0` / promotion floor `u32::MAX` at that level, on both backends (the per-level classifier is shared), and `memory_namespace_set_standard` refuses the shape at write time; `null` remains the explicit opt-in to inherit.
