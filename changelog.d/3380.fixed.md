canonical mutation ownership before summarization or writes, on MCP (SQLite)
and HTTP (SQLite and PostgreSQL), plus the existing SQLite CLI commands.

shape (HTTP 404, matching reads); readable foreign-owned sources return the ownership error (HTTP 403).

be readable; the ordinary no-caller MCP posture retains its ownership bypass.
