### Security

- `infra/do-hive/main.tf`: `db_password` no longer has a published default and is validated at plan time (at least 24 characters from `[A-Za-z0-9._~-]`). The value is spliced into the cloud-init role block inside shell and SQL single quotes; the alphabet cannot close a quote, start a substitution or carry a newline, so a crafted value can no longer run a command as root or make the SQL error echo the password into `cloud-init-output.log` (#4654).
