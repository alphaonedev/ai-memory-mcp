**The signed-approval escalation router returns a typed outcome (#4378).** `approvals::signed::route_escalation_to_approval_gate` returned a bare pending id both when the `pending_actions` row was written and when the write was only deferred to the calling thread's open write transaction (#4116), so a caller that trusted the value could hand out an id whose row may never exist. It now returns `EscalationRouting::Queued(id)` (the row exists) or `EscalationRouting::Deferred(id)` (reserved, lands when the transaction ends), and the refusal text is derived from the variant.
