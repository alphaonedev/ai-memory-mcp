**Cert-expiry gate prints Unicode format characters escaped (#6683).**
`log_safe()` of `scripts/check_cert_expiry.py` escaped C0, DEL, C1, U+2028 and
U+2029 but passed Unicode format characters (category Cf: bidi embeddings,
overrides and isolates, zero-width characters, soft hyphen, BOM) through raw, so a
workflow file name, a job key or a `Rule-Change-Approved-By:` value could be shown
reordered or invisible on the step log and the checks page (the `GUARD CHANGED`
tamper-evidence annotation included). They are now printed as `\uNNNN`
(`\UNNNNNNNN` above U+FFFF). The Unicode 15.0 format characters come from an
explicit code-point table, so Python 3.9 (which does not know U+0890, U+0891
and U+13439-U+1343F as format characters) and 3.12 print the same text. No
refusal decision changes. Self-test cells `log-safe-cf-U+XXXX`,
`log-safe-cf-sweep`, `log-safe-cf-table`, `log-safe-plain`, `tr-log-cf-who` and
`tr-log-cf-name` pin it.
Refs #6140, #6175, #6683.
