**The compliance script-name gate fails closed on an unreadable allowlist path (#6353).**
`scripts/check_compliance_script_names.py` treated any error while probing the allowlist
path (a symlink loop, a permission error) as a missing allowlist, which the gate accepts
when no document needs an entry. Only a path that does not exist (or whose parent is not a
directory) now counts as missing; any other error is reported as an unreadable allowlist
(exit 2). A path that exists but is not a regular file still suppresses nothing, as before.
