### Fixed

- **`cargo test --lib -- federation` is no longer decided by a race on the
  process-global governance wire-action hook**
  ([#3515](https://github.com/alphaonedev/ai-memory-mcp/issues/3515)).
  Every federation peer POST is built by
  `federation::sync::build_governed_peer_post`, which consults the
  `NetworkRequest` gate through `governance::wire_check::check_governed` — a
  FAIL-CLOSED check that refuses with `HOOK_NOT_INSTALLED_REASON` while the
  process-wide `GOVERNANCE_PRE_ACTION` `OnceLock` is still empty. In the `--lib`
  test binary that `OnceLock` is populated as a side effect of
  `daemon_runtime::tests::test_bootstrap_serve_*`, so at default parallelism
  whether a federation egress test saw an installed hook was pure scheduling
  luck: on the reporting host `cargo test --features sal,sal-postgres --lib --
  federation` failed 20/20 runs with 3-8 of
  `federation::tests::{action_transition,archive}_quorum_*`,
  `..._id_drift_peer_records_drift_not_ack` and `bulk_catchup_push_*` reporting
  quorum-not-met / zero peer calls, because the refusal is surfaced as an
  ordinary peer miss (`AckOutcome::Fail`) rather than a crash. The federation
  test fixtures (`federation::tests::build_config`,
  `federation::push_dlq::tests::cfg_with_peer`) now seed the gate through a new
  `#[cfg(test)]` helper, `governance::wire_check::ensure_installed_for_test`,
  whose first-write-wins install keeps any real hook a sibling test already
  placed. Test-only: the gate, its fail-closed posture and the one-shot
  `OnceLock` are unchanged — a save/restore RAII guard is structurally
  impossible on a one-shot lock and was deliberately NOT invented, and the
  unset-hook refusal contract stays pinned by
  `tests/governance_wire_check_fail_closed.rs`, a separate test binary with its
  own `OnceLock`. The slice now passes 30/30 at default parallelism.
