**The doc symbol-anchor gate now normalises a `src/<path>.rs` anchor once and range-checks line numbers.** `scripts/check-doc-symbol-anchors.sh` consumed only a `../` prefix in its `QUAL` rule, so a backticked `./src/x.rs::symbol` (or brace list) naming a removed symbol passed (#4699); a `:0` line anchor passed, and so did a line one past the end of a file that ends with a newline, because the line count was newlines plus one (#4700); and a doubled-slash form such as `.//src/x.rs:9999` or `src//x.rs:9999` was not matched at all (#4701). The gate now strips any number of leading `./` and `../` segments and collapses repeated slashes before the `PATH`, `LINE`, `BARE_LN` and `QUAL` rules run, and a line must satisfy 1 <= N <= the file's line count. The `--self-test` gains 23 cases (79 PASS with #4714 and #4716, base 43) covering each failing form and its neighbouring valid form.
