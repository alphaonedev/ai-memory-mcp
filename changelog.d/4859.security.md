### Security

- `scripts/check-docs-no-argv-secrets.py` now flags `psql -v`/`--set`/`--variable` password assignments wherever `psql` appears on the line: at line start, after a path, after a semicolon, or inside a command substitution. (#4859, #4817, #4808)
- The same gate now reads the psql segment the way the shell does (quotes and backslashes removed) and flags any `psql -v` variable whose name contains pass, secret, token, key, cred, pw or auth, with no locator-suffix or redaction-token exemption; eleven spellings that passed are now red self-test probes. (#5399; the array-form limit is #5398)
- `deploy/hive-1461/provision/20_pg_age.sh` builds the image with `-f` and an empty context directory, so the CA key and the secret files are never sent to the docker daemon. (#5401)
- `scripts/postgres-droplet-reinit.sh` runs the pg_dump backup with `PGSSLMODE=verify-full` and a pinned local CA (`PG_DUMP_SSLROOTCERT`), and refuses with exit 7 before the backup when the CA is unusable. (#5402)
- `ai-memory --db <path> curator` opens the explicit database on every store-backed arm (`--rollback-last`, `--prune-reports`, `--reflect`, `--once`), not only the sweep. (#5218)
