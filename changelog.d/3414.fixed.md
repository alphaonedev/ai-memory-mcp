### Fixed

- **[cli] not-found and MCP-param leaks on archive restore, skill retire, entity-register, atomise**
  ([#3414](https://github.com/alphaonedev/ai-memory-mcp/issues/3414)).
  `archive restore <missing-id>` now refuses with `not found in archive: <id>`
  and a non-zero exit on every output mode (JSON no longer writes
  `{"restored": false}` and exits 0; text no longer `process::exit`s).
  Skill CLI maps MCP `skill_id` / tool-name prose onto `--id` /
  `--namespace` / `--name` at the CLI boundary. `entity-register` maps
  `title cannot be empty` onto `--canonical-name`. `atomise` source-too-small
  / tier-locked messages name `--max-atom-tokens` and the CLI verb, not
  MCP params. Denied + allowed pins; sqlite CLI surface (postgres is
  refused by `refuse_pg_store`).
