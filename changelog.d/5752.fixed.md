**Test scratch no longer leaves an undeletable `audit.log` (#5752, source side of #5657).**
The audit sink's compiled default is `append_only = true`, so a test that booted
the real binary with `[audit] enabled = true` in a `.local-runs/.tmp*` scratch
directory left an `audit.log` carrying the OS append-only flag (`chflags uappnd`
on macOS). Such a file cannot be unlinked, so the next `actions/checkout` on a
self-hosted runner failed with EPERM. The `logging_pipeline_3651` harness now
writes `append_only = false` for its scratch audit trails, and the in-crate test
that does request the flag clears it through a drop guard on every exit path.
The production default is unchanged.
