### Documentation

- **The v1.0.0 release notes no longer say `cert-postgres-age.yml` builds and
  runs the deploy image** ([#4008](https://github.com/alphaonedev/ai-memory-mcp/issues/4008)).
  Four passages (and `docs/postgres-age-guide.md`) said the workflow BUILDS
  `deploy/docker-1461/Dockerfile.pg-age-vector`, runs that image as the
  postgres under test, and that CI's artifact is "the SAME artifact the deploy
  SSOT ships". The workflow's own header records that the per-PR `docker
  build`/`docker run` was removed: it creates a per-job database on the
  self-hosted runner's native PostgreSQL/AGE/pgvector tier and asserts that
  tier's live versions against the pins in
  `deploy/docker-1461/provision/lib.sh`. The text now says that, and that it
  certifies the pinned versions, not the image artifact. Docs only; pinned by
  `tests/fit_docs_b_false_claims_4000_4009.rs`.
