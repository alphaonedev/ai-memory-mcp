`backup --keep` no longer deletes real backups on the say-so of file
modification times. Rotation now counts only backups whose signed manifest
verifies, orders them by their signed creation time, and never deletes a
file it cannot verify. Before, a file in the backup directory with a future
mtime pushed genuine snapshots out of the retention window and deleted
them. Skipped files are named in a WARN and reported in `backup --json`
(`rotation.kept_unverified`), as is any file rotation failed to remove
(`rotation.remove_failures`). On a host without an operator key, backups are
unsigned and are therefore never rotated.
