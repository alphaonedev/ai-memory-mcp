**The tracing section of the enterprise and production deployment guides and the telemetry policy now describe what the code emits.** They no longer say every governance decision and every federation event emits a `tracing::info!` span: only MCP tool calls run inside a span (`mcp_tool_call`), governance decisions are written to the forensic audit log by `record_decision`, and federation emits info events on its push, DLQ-replay, receive and sync paths. The telemetry policy's span-format block and its claims of per-policy, per-federation and per-audit-row spans are replaced by the same description (#4567).
