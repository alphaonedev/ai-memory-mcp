**The tracing section of the enterprise and production deployment guides and the telemetry policy now describe what the code emits.** They no longer say every governance decision and every federation event emits a `tracing::info!` span: MCP tool calls run inside the `mcp_tool_call` info span (HTTP requests run inside a separate `request` debug span), `record_decision` records governance decisions as forensic audit rows when the forensic audit sink is running, and federation emits info events on its push, DLQ-replay, receive and sync paths. The telemetry policy's span-format block and its claims of per-policy, per-federation and per-audit-row spans are replaced by the same description (#4567).
