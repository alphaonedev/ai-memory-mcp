**The batman-active compose init now rewrites only the top-level `api_key` (#4291).** The #3838/#4213 rotation step took the first `api_key =` line anywhere in `config.toml` as the stored key, and removed every such line on each `up`. That deleted an `api_key` inside a TOML table (`[llm]`, `[embeddings]` or any other). For `[llm]`/`[embeddings]` this silently turned the boot refusal an inline key causes into a boot. It also edited lines inside multi-line strings, and printed "API key rotated" when the only key was table-scoped. The rewrite now lives in `scripts/docker/set-api-key.sh` (shell builtins only; the key comes from the environment, never argv). It touches only the TOP-LEVEL key: lines before the first real table header, outside multi-line strings and multi-line array values. It refuses (exit 64, file untouched) when that scope cannot be established, because a guess could leave two top-level keys (a boot refusal) or drop an operator line. It reports a rotation only when a top-level key existed and changed. Found by the SECPROG L8 retest of #3838.
