CI disk (#8216): new `scripts/ci/runner_disk_hook.py`, the GitHub Actions job-started and job-completed hook for the self-hosted runners. Below 150 GiB free after a job (60 GiB at job start) it removes the cargo `target` directories of its own runner's work folder, and at job start it ports the old `.local-runs/test-tmp` cleanup and removes the cargo targets when the work folder is over a named byte ceiling (`WORK_FOLDER_CEILING_GIB`, 40 GiB; an unreadable folder refuses, a symlink is not followed). A directory is removed only at `<work root>/<repo>/target`, as a real directory on the work root's device whose `CACHEDIR.TAG` carries the cargo signature, through `O_NOFOLLOW` directory descriptors that never cross a device; a failed free-space read refuses to decide. The hook exits 0 on every path and appends one log line per call. Operator notes: `docs/ci/runner-disk-hook.md`.
