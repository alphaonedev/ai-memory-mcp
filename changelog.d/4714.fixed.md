**The doc symbol-anchor gate now resolves `.` and `..` segments inside a `src/` path.** `scripts/check-doc-symbol-anchors.sh` left `src/./mcp/x.rs:9999`, `src/mcp/../mcp/x.rs::removed` and `src/../nope.rs` unmatched, so those anchors bypassed every rule (#4714). The path is now normalised with `posixpath.normpath` once per doc line before the `PATH`, `LINE`, `BARE_LN`, `QUAL` and `MDLINK` rules run, and a token whose `..` segments leave `src/` is refused as a `PATH` finding. The `--self-test` gains 8 cases.
