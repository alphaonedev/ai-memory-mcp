**`check_cert_expiry.py`: the amendment ledger is append-only on every cert-doc change (#6423, #6726).** A
change that touched the cert doc while it was EXPIRED/VOID could delete, re-date, edit or reorder
existing records, or delete the doc, without a watched-path change; and a change that set a new
Binds-to value or moved EXPIRED to VOID skipped the check on every path. The append-only check now runs
on every such change, on the doc-only path and on the re-issue/voiding hatch; only a head whose banner
is LIVE (a re-issue, held to rule C and #3899) is exempt. A change that touches no watched path or
identifier may not add a record either (#6731): a record is added only by the wire change it records,
where its grammar, citation, placement and date are checked. Regression: self-test cells `6124-d*`.
