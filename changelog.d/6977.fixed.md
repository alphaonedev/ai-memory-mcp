**Cert-expiry gate reads the cert doc fail-closed (#6977).** `scripts/check_cert_expiry.py`
`cert_banner` used to report the cert doc as ABSENT on ANY `git show` failure, so a read error
(unresolvable tree, missing or corrupt object, timeout) looked the same as a missing file and
let a wire change through. A new `read_blob` helper returns the bytes, or `None` only when
`git ls-tree` exits 0 with empty output (provable absence); every other outcome, including a
non-file entry, raises `GateError`, which the gate already reports as an `ERROR ... (fail-closed)`
violation. Proof: `case_6977_banner_read_error` in
`scripts/ci/tests/test_check_cert_expiry_corpus.py`.
