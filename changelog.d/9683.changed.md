**A pull request that changes only documentation no test reads no longer spends the cert-postgres-age, postgres-ignored and token-budget runs (#9683).** Each of the three jobs now opens with one `Docs-only short-circuit (#9683)` step (`.github/actions/docs-only-gate`, `scripts/ci/impact/docs_only_gate.py`). It judges the whole pull request, from the base sha to the checked-out merge ref, with the allowlist coverage already uses (`rules.json` `cargo_skip` docs globs minus every never-skip and test-read glob), so a Markdown file under `.github/` or `scripts/ci/` and a doc a test or `include_str!` reads still count as code. On a pull request the action's one step copies the base commit's gate files (decider, rules and helpers) into the runner's temp directory with fixed `git show` commands at the event's base sha and then runs that base copy, so the Python that judges the diff and writes `docs_only=true` comes from the base commit. The action file and the workflow YAML that calls it still come from the pull request head; a pull request that edits either is a CI-tree change by the base rules, which is a full run, and a base commit without the gate files (the pull request that adds them) leaves `docs_only` empty with a notice, which is a full run too. The diff is read as NUL-separated data with named exits (full run, docs only, unreadable). Only the docs-only exit skips work: a push, merge queue or other event, a main, develop or release base, a missing base or one that is not the event's, a base that cannot be fetched, an unset runner temp directory, an empty, unreadable or over-bound diff, a decider exit other than docs-only, a timeout and any error run the job in full. Text in the gate's notice goes through the same workflow-command escape as the shared annotation module (#9365). The jobs, their names, conditions and required contexts are unchanged; only the steps after the gate are guarded, and the always()/failure() cleanup steps still run. CodeQL and the coverage c8 gates keep their full runs: a skipped analysis would leave the head without a scan, and the c8 gates read docs.
