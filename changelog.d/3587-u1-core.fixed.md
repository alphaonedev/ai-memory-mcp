Preserve an existing `ruling_key` through ordinary upserts on SQLite and
PostgreSQL, so subsequent keyed stores can still find their predecessor.
CLI resolve now returns an audited `ArchivedPredecessor` refusal when the loser
was archived for another reason; authorized supersession replays remain no-ops.

SQLite keyed stores select the newest predecessor by its parsed RFC3339 instant,
preserving sub-millisecond ordering and using descending ID only for equal times.
Malformed predecessor timestamps fail closed before insertion.
