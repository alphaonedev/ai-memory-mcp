**The compliance script-name gate reports a document symlink loop as a loop (#6217).**
`scripts/check_compliance_script_names.py` caught every symlink resolution error under one
message, so a loop between two documents was reported as "resolves outside the repository",
which misdirects the reader. It also depended on the Python version: 3.9 to 3.12 raise on a
loop and 3.13 does not. A document symlink is now probed with `os.stat` first, and `ELOOP` is
reported as "document symlink loop (refused)" on every Python version. An escape stays
"resolves outside the repository", and any other resolution error is reported as "cannot be
resolved". Each remains a violation.
