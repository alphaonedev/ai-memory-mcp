`ai-memory audit show` / `re-anchor` / `restore-attest` / `bootstrap-node` now
honour the global `--db` / `AI_MEMORY_DB` for reads and writes. Each verb
recomputed the store path from `config.toml` and silently read from — and wrote
to — the config-resolved database (or a stray `./ai-memory.db`) instead of the
one the operator selected. The resolved path is now threaded from the top-level
parser into every audit verb, and the same recompute was removed from the MCP
inference-egress refusal audit.
