**`ai-memory logs tail --follow` keeps following after the operational log rotates or is truncated (#7946).** The follow loop picked the newest file once and watched only that path, so after a minutely, hourly or daily rotation it went silent. Each poll now re-lists the log directory: a newer-named file makes the loop drain the rest of the old file and continue from offset 0 of the new one, and a followed file that shrank or was replaced under the same name (new inode on unix) is re-read from the start with a one-line note on stderr.
