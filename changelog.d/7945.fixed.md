**`ai-memory logs tail --follow` no longer drops lines appended between the tail pass and the follow baseline (#7945).** The follow offset came from a separate `metadata` call made after the tail pass had already reached end of file, so bytes written in that gap were counted as seen but never printed. The tail pass now returns the byte offset it consumed and the follow phase starts exactly there, so every later byte is printed once, with no gap and no duplicate; an unterminated trailing fragment is held back until its newline arrives so a line is never printed in two halves.
