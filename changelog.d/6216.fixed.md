**The compliance script-name gate checks a written path at the path given (#6216).**
`scripts/check_compliance_script_names.py` reduced any citation without a `scripts`
component to its bare name, so `infra/check_x.py`, `tools/scripts/check_x.py` or
`./check_x.sh` passed whenever a same-named file existed under `scripts/`, although the
path the reader follows does not exist. A written path is now checked from the repository
root as written; leading `/`, `.` and `..` components and a URL's host part are dropped only
when a `scripts` component follows them. A symlink outside `scripts/` counts only when it
resolves inside the repository, and the violation names the path that was checked.
