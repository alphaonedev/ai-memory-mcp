**The batman-active compose stack boots, and its API key can be rotated.** `scripts/docker/docker-compose.batman-active.yml` now starts on v1.0.0 (real `serve` flags, an explicit entrypoint on every service, the key-guarded non-loopback bind) (#3838). `AI_MEMORY_API_KEY` is required, must be at least 32 characters from `[A-Za-z0-9._~+/=-]`, and is stored only in a 0600 `config.toml` in 0700 directories, never in argv. Changing it and running `docker compose up -d` again now rotates the key: the old key stops working once the services restart, which they do automatically (#4213); before, the old key was silently kept.

Operator notes:
- `AI_MEMORY_API_KEY` is the source of truth. An `api_key` edited by hand in the stack's `config.toml` is overwritten with the variable's value on every `docker compose up`; change the variable, not the file.
- The stack needs Docker Compose 2.17 or later, for `depends_on: restart: true` (the automatic service restart that makes a rotated key take effect).
