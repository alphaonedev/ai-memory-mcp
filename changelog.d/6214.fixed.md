**The compliance script-name gate checks the name a reader sees after rendering (#6214).**
`scripts/check_compliance_script_names.py` matched the Markdown source only, so a Markdown
backslash escape, an HTML entity, an inline tag or comment, emphasis or strikethrough
markers, a non-ASCII hyphen (U+2010, U+2011, U+2212), a combining mark, a fullwidth form or
a Cyrillic/Greek look-alike letter inside a deleted script name showed the reader that name
while the gate saw none. Each document line is now also scanned in a rendered, folded form
(an explicit look-alike table, NFKC, dash folding, mark removal). The table covers only some
look-alikes, so in addition a script name with a non-ASCII letter (or a letter carrying a
combining mark) where it has a letter is reported as a look-alike script name, even when it
imitates an existing script. A name split across code spans, links,
images, comments or tags, also over line breaks, is found by scanning the document as one
text with that markup removed, and reported on the line it starts on. These scans only add
findings; errata are still read from the canonical erratum lines.
Round 9 closes the forms that scan still missed. The look-alike scan no longer applies NFKC
to letters, so a fullwidth, mathematical or Kelvin-sign letter stays a non-ASCII letter there
(NFKC had turned it into its ASCII letter and the name passed). Any non-ASCII, non-space
character where a name has `-`, `_` or `.` (a CJK, Hangul, Lisu, Canadian syllabics or
modifier-letter glyph that looks like the separator) is a look-alike separator. An inline
tag runs to its first `>` outside a quoted attribute value, so a quoted `>` or `<` no longer
cuts the tag short and leaves its tail as visible text. A link closer is removed with its
full inline destination and title: nested and escaped parentheses, an angle-bracket
destination, and a quoted or parenthesised title. The coverage is the characters and forms
above, not every Unicode script: a letter that NFKC and the look-alike table both map to an
ASCII letter is folded, and a separator glyph inside the ASCII range is not a look-alike.
