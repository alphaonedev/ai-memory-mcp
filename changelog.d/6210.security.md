### Security

- **[ci] The CLAUDE.md rule comparison masks credentials written in Markdown forms**
  ([#6210](https://github.com/alphaonedev/ai-memory-mcp/issues/6210), follow-up of
  [#6163](https://github.com/alphaonedev/ai-memory-mcp/issues/6163), CWE-532).
  `scripts/claude-md-rule-compare.py` did not recognise a backtick-quoted
  value (``password: `v` ``), an emphasised name (`**password**: v`,
  `password:** v`) or a Markdown table row whose cell is a credential name
  (`| password | v |`), so those values reached the step summary. All three
  are now masked; in a table row every cell after the name cell is masked
  unless it is a count, a switch word or short prose. Regression cells: the
  `#6210` self-test cells.
