#3692 / #2893 / #2894 — the consolidation rollback path, fixed as one unit. The operator-reversible rollback entry is now written BEFORE `consolidate` (both the curator `ConsolidationPass` and the autonomy Pass-1 path), tagged pending, and committed with the summary id after `verify`; a failed write-ahead aborts the cluster with nothing touched, a failed Stage-6 rollback keeps the pending row (the exact originals) and `curator --rollback` reverses it. A Stage-6 rollback that cannot restore an original — its `(title, namespace)` slot is held by another id, or the restored row is not reachable on the read path (present but hidden, #2894) — is INCOMPLETE: it names every such original and the id holding its slot, RETAINS the summary (the only remaining copy of that text), and halts the sweep fail-closed; the squatter is never clobbered. Before this the collided original was skipped and the summary deleted anyway (content in zero places), and a hidden restored row counted as restored. #2894's restore visibility itself is characterised, not changed.
