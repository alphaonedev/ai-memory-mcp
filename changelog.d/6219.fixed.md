**An erratum inside a Markdown link reference definition no longer clears a stale script name (#6219).**
`scripts/check_compliance_script_names.py` read the text of a link reference definition
(`[//]: # (Erratum ...)`, also with the title on the next line or continued over lines), a
footnote or link text as reader-visible, although GitHub may never render it. An erratum line
must now start `Erratum (#<issue>): ` at column 0 and carry no `[` or `]` outside code spans,
so no definition, footnote, link or image form can carry one. Stale names are still found on
every line.
