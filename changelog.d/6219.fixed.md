**An erratum inside a Markdown link reference definition no longer clears a stale script name (#6219).**
`scripts/check_compliance_script_names.py` read the text of a link reference definition
(`[//]: # (Erratum ...)`, also with the title on the next line or continued over lines) as
reader-visible, although CommonMark and GitHub never render it. A blank-line-delimited
paragraph that starts with a definition line is now removed from the erratum reader. Stale
names are still found on every line.
