**The cert-expiry context check keys a `mod NAME;` declaration by its inline-mod path (#6715).** A `mod child;` moved inside `mod hidden { .. }` points at `hidden/child.rs`, so the original `child.rs` is no longer compiled, but the scan keyed declarations by bare name and still treated it as declared. Declarations are now keyed `hidden/child` and the parent search walks up the directories `(wrap-decl-inline-mod)`; `pub(crate) mod` declarations, an inner cfg in the parent `mod.rs` and a removed top-level declaration are pinned as well `(wrap-decl-pubcrate)`, `(wrap-parent-inner)`, `(wrap-undeclared-nested)`.
