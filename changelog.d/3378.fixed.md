`tools/list` compacted descriptions keep the verb-noun gist (#3378).

`compact_description` still prefers a 32-byte first-sentence / word-boundary
cut, but a cut that would end on a dangling `+`, preposition, article, or
conjunction is extended up to 80 bytes (first sentence when it fits) so
labels such as `Report per-agent +` and `Skill body +` no longer ship.
Budget-by-tool: only the dangling tools spend the extra bytes; a clean
first sentence (e.g. `Calibrate confidence baselines`) is unchanged.
Pinned by `tests/mcp_compact_description_3378.rs` plus unit tests next
to the trimmer. Enum lists on the wire and per-description capabilities
pointers are later units of the same issue.
