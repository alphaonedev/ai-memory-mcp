The count-assertion gate (`scripts/check-count-assertion-declared.sh`) now skips a new assertion only when its file is added in the same commit and the assertion exists nowhere else (rename and copy sources are compared), parses the commit's own `Count:` line from the trailer block and compares it with the diff for every hit, and accepts late `Count-Declared: <40-char sha> <what> <old> -> <new> (<why>)` trailers from later commits (#5499, #5517, #5518). It is wired into `c8-precheck.yml` over the PR range (merge-base..head); carrier-history offenders outside a PR range are not checked.
