### Fixed

- PostgreSQL TTL GC locks one victim set for archive copies, link snapshots,
  erasure and deletion, preserving concurrently imported expired memories (#4037).
- AGE projection locks and reads canonical link validity on every path, including
  duplicate replay and outbox reconciliation, and clears stale NULL properties.
  Unlink serializes with projection; node-removal markers fence memory writers
  through the absence check and detach (#4038, #4039).
- Embedding dimension conversion locks both vector-bearing tables before reading
  dimensions or counting embeddings, so a non-forced migration cannot erase a
  concurrently committed vector (#4040).
- PostgreSQL pools with fewer than two maximum connections fail immediately with
  an explicit configuration error before attempting schema bootstrap (#4041).
