**Wake-hub sysusers fragment: create `ai-memory` and `ai-memory-hub` so the shipped unit can start on a fresh host (#3578 item 3b).**

`packaging/systemd/ai-memory.sysusers.conf` is the systemd-sysusers record for both users (`u ai-memory` home `/var/lib/ai-memory`, `u ai-memory-hub` home `/run/ai-memory-hub`). Distro packages install it as `/usr/lib/sysusers.d/ai-memory.conf` (AUR `PKGBUILD` does); the systemd README documents `systemd-sysusers` as the create path. `tests/wake_hub_process_isolation_3578.rs` pins both names (allowed + a denied fragment that only creates the daemon user).
