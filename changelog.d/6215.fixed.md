**A literal `<!--` in a code fence or code span no longer hides a later erratum (#6215).**
`scripts/check_compliance_script_names.py` treated every `<!--` as an HTML comment opener,
including one shown literally inside a fenced code block or a backtick code span, so a
correct erratum later in the document was ignored and the gate failed a legitimate document.
The erratum reader now tracks fenced blocks (backtick and tilde) and code spans; a `<!--`
inside either opens nothing. Fence marker lines are not reader-visible text.
