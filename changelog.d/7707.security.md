### Security

- **[auth] Admin elevation requires a key-attested identity once per-agent keys are enrolled** ([#7707](https://github.com/alphaonedev/ai-memory-mcp/issues/7707)).
  `is_admin_caller_trusted` and `require_admin` refuse a shared-key `Claimed` admin id in every identity mode, `advisory` and `off` included, once any per-agent key is enrolled.
  One snapshot decides, `require_admin` refuses before its allow audit row, boot warns on unkeyed admin ids (refuses under the certified posture), and a keyless daemon is unchanged.
  Every `require_admin` refusal returns one generic `403 admin role required` (identical status, headers and body for an unknown id and an unattested admin), so the admin allowlist cannot be enumerated; the reason is only in the `rejected_unattested_admin_identity` audit outcome and the operator WARN.
