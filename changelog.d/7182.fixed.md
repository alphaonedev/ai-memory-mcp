**Cert-bootstrap gate hermetic config (#7182).** `scripts/check-bootstrap-cert-gate.sh` now exports `AI_MEMORY_NO_CONFIG=1` and a private `XDG_CONFIG_HOME` before any ai-memory invocation, so a host `~/.config/ai-memory/config.toml` can no longer redirect the gate to a live database. `AI_MEMORY_NO_CONFIG=1` is the config fence; the private XDG dir (removed on every exit, including `--self-test`) keeps key-directory lookups off the user profile.
