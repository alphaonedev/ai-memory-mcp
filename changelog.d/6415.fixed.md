**An erratum hidden in a collapsed `<details>` element or behind an HTML comment no longer covers a stale script name (#6415).**
`scripts/check_compliance_script_names.py` decided erratum visibility by emulating how GitHub closes fences,
comments and `<details>` elements, and every divergence from the renderer let a hidden erratum count. The
emulation is deleted (#6141, design B): an erratum must be an ATX `Erratum` heading followed by plain paragraph
lines, and only blank lines, ATX headings and plain lines may precede it. A `<details>`, comment, fence, list,
quote, table or any other construct before or inside the block fails the gate, naming the construct and the line.
