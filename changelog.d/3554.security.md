### Security

- **[ci] declared required-context set is now pinned to live branch
  protection**
  ([#3554](https://github.com/alphaonedev/ai-memory-mcp/issues/3554),
  recurrence of
  [#2712](https://github.com/alphaonedev/ai-memory-mcp/issues/2712)).
  The soundness gate (`check-required-contexts.sh`) compares the
  hand-authored declaration to the workflows and has no API access by
  design, so a declaration that grew without the companion protection
  call was structurally undetectable. The three later integrity gates
  (capacity-claim, benchmark-claim, cert-expiry) are now live-required
  on `release/v1.0.0`. `scripts/check-required-contexts-live.sh` fails
  CI when declaration != the committed live-pin (regenerated only by
  `--pin-from-live`) and, when the token can read protection, when
  either != live; `--self-test` plants the exact 38-vs-35 shape.
  `enforce_admins=true` / `strict=true` stay asserted. Certified-pin
  jobs remain #3552; cert-expiry watch-set / VOID-banner hardening
  remains #3556.
