### Fixed

- **[data-integrity] `export | import` could not round-trip its own bundle: the
  exporter emitted graph edges pointing at memories it had withheld**
  ([#3405](https://github.com/alphaonedev/ai-memory-mcp/issues/3405)).
  `memories[]` and `links[]` are two independent reads: the memories read
  applies the fail-closed lifecycle allow-list (a `tombstoned`/`quarantined`
  row never leaves) and then the confidentiality screen (forbidden-class rows
  are dropped), while `storage::export_links` filtered only on expiry. Every
  bundle producer therefore emitted edges naming rows the artifact does not
  contain. Because `memory_links` carries `REFERENCES memories(id)` and
  importers run with foreign keys ON, the destination could never materialise
  such an edge — so `ai-memory export` exited `0` and `ai-memory import`
  exited `3` on that same artifact, on the first run and forever, with no
  disposition an operator could take (a permanently red restore leg ends as
  `|| true`, which then also silences the genuine refusals #2490 closed).
  Executed at the parent commit on a corpus with two consolidation-tombstoned
  sources: `export` emitted 3 edges to withheld rows and exited 0; `import`
  reported `links_refused: 3` and exited 3.

  The control is at the PRODUCER: `export_scope::retain_resolvable_links` is
  the single funnel every bundle producer (CLI `export`, `export --full`, and
  the HTTP admin export on both SQLite and Postgres) passes its edges
  through, so an artifact never claims an edge it cannot carry. The drop is
  reported, never silent: the count rides in-band under
  `withheld.dangling_links_withheld` and the rendered `"<source>-><target>"`
  labels ride the operator stderr channel only (an endpoint named there is by
  construction a withheld id, so publishing it in-band would leak exactly the
  index the #2490 objection-O3 boundary keeps out of the artifact). A dropped
  edge is not counted as a NEW partiality — the endpoint omission that caused
  it is already accounted for, and double-counting would pin any corpus
  holding one forgotten-but-linked memory permanently at exit 3.

  On the consumer side `import` now distinguishes an endpoint the BUNDLE
  never carried (a dangling artifact — a producer defect, counted
  `links_skipped_dangling`) from an endpoint the bundle carried whose row did
  not land (a genuine reconstruction failure, still `links_refused`). The
  first is gated by a new explicit `import --allow-dangling` ratchet: the
  default stays fail-closed at exit 3 and the message names the override; the
  flag governs the exit code only — the edge is still skipped, still counted,
  and still announced, and it never launders any other refusal.
