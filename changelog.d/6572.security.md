`scripts/claude-md-rule-compare.py` no longer counts a `Rule-Change-Approved-By` trailer whose value is made only of invisible characters (zero width and bidi controls, soft hyphen, BOM, the Hangul fillers U+115F, U+1160, U+3164, U+FFA0 and the braille blank U+2800) as an approval. Such a value names nobody and is now treated like an empty value, so the comparison fails with "no commit in the range carries". A visible name that happens to contain an invisible character still counts (#6572).
