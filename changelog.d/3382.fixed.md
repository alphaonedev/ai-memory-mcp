Scope MCP archive list and statistics to the resolved caller using canonical
query visibility and archive ownership. Invalid caller identities fail closed;
substrate rows require an explicit namespace on list and are excluded from
statistics. Visibility filtering precedes pagination and aggregation, and
canonical inbox namespace aliases remain supported.

Route MCP restore through the caller-gated SQLite twin and assert canonical
mutation ownership on SQLite and PostgreSQL SAL restore. Non-owner and absent
ids return the same refusal without restoring the row. The existing owner,
inbox-recipient, legacy-unowned and explicit SAL admin restore paths remain.

Restore preserves the original expiry; the tool documentation now states that
an expired row can be collected again. No descriptions or schemas change.
The checked MCP `as_admin` escalation remains reserved for #3455.
