### Security

- **Curator-derived rows are signed and owned by one curator identity**
  ([#8863](https://github.com/alphaonedev/ai-memory-mcp/issues/8863)). The curator and the
  forensic bundle picked the first key in sort order from the key directory, so whichever label
  sorted first (any agent's key) signed derived rows and manifests. Both now use only the daemon
  key (`DAEMON_KEYPAIR_LABEL`). The curator generates it through the same helper the daemon uses
  (`identity::keypair::ensure_and_load_label_keypair_in`), so `curator --once` / `--reflect`
  create the daemon key when it is absent. The forensic manifest never generates a key: it is
  unsigned when the daemon key is absent or public-only and fails with an exact error when the
  key file is unreadable.
