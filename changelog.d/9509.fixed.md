**CI and tests: model-backed tests run from a verified, job-private offline cache and never fetch a model (#9509, #9515).**
The embedder and cross-encoder tests used to reach the hf-hub download when the
model cache was missing, so a cell passed or failed by test order and network
luck, and the cache was shared through the runner user's home directory. Every
workflow that runs Rust tests now sets `AI_MEMORY_EMBED_OFFLINE` once at
workflow level, and every test resolves the models from the staged cache only
(`Embedder::new_local_staged`, `CrossEncoder::new_neural_staged`, or an empty
hub for the degraded path); a test census fails on any test that names a
network-capable constructor. The three CI jobs that need the models stage them
the same way: a job-private `HF_HOME` under the runner temp directory, an
exact-key cache restore whose key names both pinned model revisions (no
`restore-keys`), `scripts/ci/stage_hf_cache.py` (standard library only, pinned
revision and sha256 per file, files under the repo's `blobs` or `snapshots`,
non-empty, a non-UTF-8 or non-pinned `refs/main` refused with a named layout
reason and exit 10), and a save only after a verified stage. The fetch child
runs without any Hugging Face token and its output is redacted. Tests:
`scripts/ci/tests/test_hf_cache_staging_pin_9509.py`,
`scripts/ci/tests/test_stage_hf_cache_9509.py`,
`scripts/ci/tests/test_hf_home_private_9509.py`,
`src/reranker/hf_home_9509_tests.rs`, `src/embeddings/offline_home_9509_tests.rs`.
