CI: the two enterprise-fed `Check` legs (`linux-fed,enterprise-fed`, `macos-fed,enterprise-fed`) now do work on chain carrier PRs (head branch `chain/...`), on pull requests into any non-chain base (`release/**`, `rehearsal/**`, `main`, `develop`), on pushes and on merge groups (#8174). On a topic-branch pull request into a chain carrier they are rerouted to a hosted runner and skipped, so a self-hosted runner is no longer held for 2 h 09 min to 2 h 37 min per PR run; the check names still report, the skipped legs fail (exit 1) if the base is not `chain/*`, and sal-postgres coverage on those PRs stays in `cert-postgres-age.yml` and `postgres-ignored.yml`. The decision is `scripts/ci/check_legs.py`.
