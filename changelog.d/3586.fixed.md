**`wrap` surfaces `boot`'s read-only refusal (#3586).** Since #3411
`ai-memory boot --quiet` refuses an unreachable `--db` (missing /
schema-behind / schema-ahead) with **empty stdout and stderr** so a hook
cannot inject a warn header into the agent's context. `ai-memory wrap`
inherited that silence, so the operator got no signal at all and the
agent started preamble-only. `wrap` now recovers the same typed refusal
(read-only `open_existing_read_only` probe — no create, no migrate) and
emits exactly ONE operator-facing line on **wrap's own stderr**:
`ai-memory wrap: memory boot refused (<reason>); running agent without
boot context`. The wrapped agent's system message is unchanged
(preamble-only), and no line is emitted for `--no-boot` or a disabled
`[boot] enabled` (neither is a refusal). Regression:
`wrap_unreachable_db_emits_operator_stderr_line_3586`,
`wrap_unreachable_db_system_message_is_preamble_only_3586`,
`probe_boot_refusal_returns_reason_for_missing_db_3586`,
`probe_boot_refusal_returns_none_for_healthy_db_3586`,
`probe_boot_refusal_returns_none_when_boot_disabled_3586`.
