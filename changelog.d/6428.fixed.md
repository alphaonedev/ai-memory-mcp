**The cert-expiry self-test shim owns its scratch directory with one `try/finally`, decodes the probe tolerantly and pins the probe timeout (#6428).** `run_gate_shimmed` removed the `gitshim.*` directory only when the reachability probe raised `GateError`, so any other exception leaked it; the probe decoded git output as strict UTF-8, so non-UTF-8 output crashed instead of being refused by name; and the timeout branch had no pin. One `try/finally` now owns the directory from creation, the probe uses `errors="replace"`, and the new `(shim-clean-any-exc)`, `(shim-probe-decode)` and `(shim-probe-timeout)` cells pin all three.
