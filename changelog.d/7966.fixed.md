**The `logs tail --follow` rotation and truncation tests no longer race a writer thread against the poll window (#7966).** Four tests slept 50 ms in a helper thread and relied on an 8 x 20 ms poll window, the same flake class as #7934. They now build the cursor directly, perform the filesystem change, and drive one `follow_poll` per step, so they use no threads and no sleeps and cannot be reordered by a loaded host.
