**The doc symbol-anchor gate reads literal and decoded text in one normal form (#5781).** A Unicode format character (category Cf: a zero-width space, a word joiner, a soft hyphen, a bidi control) was dropped only when it came from a decoded character reference (#5607); a literal one ended the path or symbol scan, so `src/x.rs::T` with a literal zero-width space before `::NoSuch` passed while its entity spelling was reported. Every Cf character is now dropped from the whole doc before any rule runs, a line ends only at CR, LF or CRLF (a Unicode line or paragraph separator no longer splits an anchor), and a `src/` token that still holds a non-ASCII letter, mark, digit, private-use or unassigned character is refused as UNMODELLED. The header gains a TEXT FORM paragraph and the UNMODELLED sentence names the refusal. The `--self-test` gains 12 cases (#5781).
