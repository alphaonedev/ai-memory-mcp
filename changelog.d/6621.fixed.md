**The compliance script-name gate reports a name fragment that joins into a script name (#6621, #6631).**
`scripts/check_compliance_script_names.py` walks the markup after a name fragment (comments, tags, code
spans, links, images, escapes, character references and a line break), and when dropping that markup
completes a script name it reports the join; no allowlist entry suppresses it. The walk covers the
fragment's line and the next line; markup that closes two or more lines later is covered by #6753 and
#6757. Markup it cannot resolve within 512 characters or 4096 steps is reported as undecidable instead of
passing.
