The production-vs-test filter shared by the hard-block gates (`scripts/lib/production-lines.sh`, used by the C8 `for_admin` privacy-bypass gate, the hardcoded-literal gate and the vendor-literal gate) no longer treats a file as test-only because of its NAME. A `*_tests.rs` / `test_*.rs` / `*_test_*.rs` name now only triggers a declaration check: the file is skipped only when every `mod` / `#[path]` / `include!` declaration of it is `cfg(test)`-gated in the declaring file's production text. An undeclared or ambiguous file, or one with any production declaration (for example `src/mcp/dispatch_test_hook.rs` or the `cfg(any(test, feature = "test-support"))` `src/identity/test_key_dir.rs`), is production and is gated (#4054). The MCP transport-isolation gate, which skipped every `src/mcp` file whose name merely contained `test`, now uses the same declaration rule (#4145).
