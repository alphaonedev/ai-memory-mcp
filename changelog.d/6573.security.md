`scripts/claude-md-rule-compare.py` now refuses a shallow repository (`git rev-parse --is-shallow-repository` anything but `false`) with `RESULT: FAIL (closed)`. In a clone whose base was fetched with `--depth 1`, the shallow boundary hid that an old commit is an ancestor of the base, so a merge parent could carry an earlier, real `Rule-Change-Approved-By` trailer into `base..head` and count it for a new rule change. The CI checkout uses `fetch-depth: 0`, so the gate is unchanged there (#6573).
