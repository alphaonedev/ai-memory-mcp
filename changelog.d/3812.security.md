TypeScript SDK: `DelegationBundle.load`'s Windows leg (no `O_NOFOLLOW` / `O_NONBLOCK` in `node:fs`) no longer checks the credential's mode and owner on the path and then reads the path again (CodeQL js/file-system-race, alert 355). It now opens once, `fstat`s that descriptor and reads from it, exactly as the POSIX leg does; the symlink refusal stays as a best-effort `lstat` pre-check, so the only residual on Windows is a link swapped in between that pre-check and the open, never a check-then-read on the path (#3812).
