**The cert-expiry self-test probe for the PATH git shim is exact and per run (#6567, #6562).** `_require_shim_reachable` now takes a per-run random nonce (`secrets.token_hex(16)`) instead of a fixed marker, and accepts only that nonce plus one newline on stdout. A substring, prefix, ignore-decode, stdout-plus-stderr or Unicode-whitespace-padded answer was previously accepted (mutants R06, O1, O2, S03, S09, S10 kept `--self-test` at rc 0). The new `(shim-probe-exact)` cell runs stub gits that answer with a loosened form of the nonce, a different nonce or a stderr-only nonce, demands a named refusal for each, and demands that the exact nonce passes.
