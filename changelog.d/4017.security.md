### Security

- **[federation] A same-id attested push no longer releases a quarantined row whose stored bytes are not the attested unit**
  ([#4017](https://github.com/alphaonedev/ai-memory-mcp/issues/4017)). The #1948 route-OUT
  dequarantine-on-attest on both `/sync/push` funnels released a quarantined row whenever the id
  `merge_inbound` returned equalled the inbound id (#3901 closed only the cross-id case). Same id is
  not proof: `merge_inbound` field-merges into the existing quarantined row, so the stored row can
  keep the LOCAL unattested text (the inbound loses LWW), the local `agent_id`
  (immutable-to-local), the local `created_at` (min-merged), or a secret-screen redacted body — and
  the release then un-hid content or an attribution the attestation never covered.
  - The release now goes through a new atomic primitive, `db::dequarantine_if_attested_unit` /
    `MemoryStore::dequarantine_if_attested_unit` (sqlite `BEGIN IMMEDIATE`; postgres `SELECT … FOR
    UPDATE` in one transaction with the guarded `UPDATE`). It re-reads the stored row and releases
    it only when `models::stored_row_is_attested_unit` holds against the row THIS node verified
    (before any receive-side rewrite): the same 6-field `SignableWrite` surface and the same
    non-empty `write_signature` — the predicate #2863 already uses to stamp a merged row
    `agent_attested`. A released row is therefore always the attested unit. The trait default is
    `Ok(false)` (an adapter that cannot prove the bytes never releases).
  - Fail closed: a refused release leaves the row quarantined (operator release remains the
    route out) and emits one WARN naming the id only. No merge-outcome type was added, so the
    #3962 `MergeApplied` design is unaffected.
  - Pinned on both backends by `tests/federation_dequarantine_same_id_4017.rs` (LWW loser, foreign
    attribution, foreign genesis refused; the same signed unit arriving newer is still released).
    The #3901 same-id control now seeds the quarantined copy as the same signed unit (same
    `created_at`); its old fixture depended on the defect.
