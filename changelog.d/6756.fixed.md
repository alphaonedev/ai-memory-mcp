**The compliance script-name gate scans long path-like lines and dense name fragments in linear time (#6756).**
`scripts/check_compliance_script_names.py` copied the written path before every script name on a line and
re-derived each character's visibility on every view, so a document of 16 ceiling-length path-like lines
took about 22 seconds; its join walk also rebuilt an index of closing characters for every fragment.
A citation whose path would pass the 4096-byte path limit now names no file without its path being copied,
the per-character visibility answer is cached, and the closing-character index is built only when the walk
meets an opener. The same documents now take about 2 seconds, pinned by two wall-time self-test cells.
