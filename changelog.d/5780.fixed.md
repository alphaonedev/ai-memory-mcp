**The doc symbol-anchor gate reads or refuses every `::` in an anchor (#5780).** Only the `::` directly after the file head was refused when nothing readable followed it (#5698); after a later component the anchor ended silently, so `src/x.rs::T::&NoSuch`, `src/x.rs::T::(NoSuch)`, `src/x.rs::T::9NoSuch` and a glob passed, and a nested brace list (`src/x.rs::T::{a, b}`) was dropped unchecked. Such a `::` is now refused as UNMODELLED, cited as written, and a nested brace list is read with each item checked as `T::a`; one that is empty, holds braces or is followed by `::` is refused. The header UNMODELLED sentence and the reporter detail say what is refused. The `--self-test` gains 9 cases (#5780).
