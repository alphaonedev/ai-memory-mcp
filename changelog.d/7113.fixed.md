**The admin sweep no longer destroys a live test family (#7113).** `scripts/test/pg_isolated_binary.py setup` marks an auto-minted `ci_base_*` base ACTIVE (a verified JSON COMMENT naming the base, its OID and the run), `teardown` marks it TERMINAL before any drop, drops the base last and exits 2 when a drop failed, and the new admin `revoke` sub-command marks an idle abandoned family TERMINAL. `sweep` reclaims only aged TERMINAL families with no live member and never a clone of an ACTIVE family; unmarked, malformed and ACTIVE families are preserved, so age alone is no longer ownership.
