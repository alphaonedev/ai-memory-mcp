CI guard tests no longer import PyYAML (#9813): `scripts/ci/tests/test_ci_progress_notice_9430.py`, `test_ci_tainted_job_boundary.py` and `test_pgbouncer_smoke_compose_4734.py` read workflow and compose files with the shared standard-library reader (`workflow_text.read_document` / `read_all_steps` / `parse_text`, built on `taint_boundary.parse_yaml`), so they load on a fleet node that has no PyYAML. The reader admits only a closed subset of YAML: it refuses every form outside it (a tag, anchor, alias or merge key, a flow collection where a block is read, a multi-line plain or quoted scalar, a document marker or directive, a tab or control character, a duplicate key, nesting past its limit), and compares every document it accepts with an independent line reader (`scripts/ci/tests/yaml_line_oracle.py`), refusing on any difference. The file is opened once without following a symbolic link and must be a regular file of at most 8 MiB, valid UTF-8, with no byte order mark and some content. A refusal is a `WorkflowReadError` naming the file, the line and one reason constant, never the document text; a guard that gets a refusal fails, it never skips or substitutes a default. `scripts/ci/tests/test_workflow_text_yaml_9813.py` pins each refusal and value, and puts every code point outside the YAML 1.2 printable set (and every other code point, at the value position) at each modelled position: each is refused with a named reason or read as written. `scripts/ci/tests/test_ci_tainted_job_boundary.py` compares the reader with the line reader on every workflow, action and compose file it guards. `scripts/ci/tests/test_ci_stdlib_imports_9813.py` is the class guard: every tracked Python file under `scripts/` imports only the standard library or a repository module, through an import statement or a literal argument of `__import__`, `import_module`, `find_spec`, `run_module` or `exec` / `eval` text; a non-literal argument, and any read of one of those callables as a value (`e = exec`, `f = importlib.import_module`), is a finding; a callee reached through a string (`getattr`, `globals()`, `sys.modules`) is not decided and is listed in its docstring. Each exception is an allow row with its exact count, reason and issue. `scripts/ci/tests/test_ci_module_attribute_reads_9817.py` refuses every attribute read, `getattr` / `patch.object` literal and from-import of a name a repository module does not define, so a name removed from one guard module cannot leave a sibling reading it.
