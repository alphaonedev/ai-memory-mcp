**The doc symbol-anchor gate refuses an anchor with a Rust keyword in its path instead of citing the keyword as a missing symbol, and skips a precise-capturing bound (#5611).** The #5537 fix covered only the `for` binder: `src/x.rs::<impl T + use<'a>>::m` (stable Rust 2024) was cited as the missing symbol `use`, `<fn(u8)>::m`, `crate::T`, `self::T`, `<Self>::m` and `T::fn` cited the keyword, and a lone `<fn(NoSuch)>`, `<unsafe fn(NoSuch)>`, `<extern "C" fn(NoSuch)>` or `<fn>` was accepted as a placeholder. A `use<...>` bound is now skipped; a strict or reserved keyword (2024 edition) anywhere in a checked path is refused as `UNMODELLED`, cited as written with its whitespace removed, and is never a placeholder. Not modelled: a function-pointer or `crate`-rooted path is refused, not resolved. Base: reported under a keyword or accepted; tip before this fix: the same; now accepted (the `use` bound) or refused. Real tree: 0 lines change. The `--self-test` gains 15 cases (#5611).
