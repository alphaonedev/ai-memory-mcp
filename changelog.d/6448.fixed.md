**The cert-expiry self-test pins each half of the git shim reachability probe (#6448).** `_require_shim_reachable` refuses when the exit code is non-zero or the marker is missing, but the real git fails both halves at once, so dropping either half left the self-test at rc 0. The new `(shim-probe-half)` cell runs two stub gits, one that exits 0 without the marker and one that prints the marker and exits 1, and demands a named refusal for each.
The `(shim-pathsep-clean)` cell also pins that a scratch path holding the PATH separator, refused by name, leaves no `gitshim.*` directory behind (#6428).
