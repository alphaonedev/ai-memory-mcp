`ai-memory identity delegate --scope a2a-hub` now stamps the delegation's
`not_before`/`not_after` at whole seconds. The wake-hub verifier renders its own
clock truncated to the second, so a nanosecond stamp put a freshly minted bundle
in that clock's future for up to a second and a wake listener presenting it
inside the same second was refused as not-yet-valid. Truncation cannot widen the
window: the start moves earlier by at most 999 ms, never later, and the end moves
with it so the requested TTL is exact. The precision is now part of the
documented `a2a-hub/join/v1` format.

Every base64 value option of `audit bootstrap-node`, `identity` and `agents
pending approve` — `--recovery-pubkey`, `--successor-pubkey`, `--challenge`,
`--attestation` and `--approval` — accepts a value beginning with `-`, so a
URL-safe-base64 key or signature is no longer parsed as a flag. The documented
clap trade-off applies: an option whose value is omitted now swallows the next
flag as its value (`--recovery-pubkey --json` reads `--json` as the key)
instead of reporting a missing value, so pass these as `--opt=<value>` in
scripts.
