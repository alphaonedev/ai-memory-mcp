**The cert-expiry self-test pins the refused-shim call-site conversion (#6380).** The wrapper that turns a git shim that cannot be installed into a named self-test failure is now the module-level `shimmed_cell`, and the `(shim-pathsep)` cell calls it and asserts it returns no verdict and records exactly one failure naming the shim and the PATH separator. A regression that swallowed the error or dropped the failure report previously left the self-test at rc 0, including from a checkout whose path contains `:` where the `(gitver)`, `(anc-error)` and `(shim-control)` cells then never ran.
