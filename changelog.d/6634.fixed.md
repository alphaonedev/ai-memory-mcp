**The compliance script-name gate scans every Markdown document under any `compliance` directory (#6634).**
Every docs/ directory whose name folds to `compliance` is scanned, with every GitHub Markdown extension
(`.md`, `.markdown`, `.mdown`, `.mkdn`, `.mkd`, `.mdwn`, `.mdx`, `.mkdown`, `.livemd`, `.ronn`, `.scd`,
`.workbook`) and names such as `A.md.txt`. A name that is Markdown only after an invisible character, a
trailing space or a look-alike form is removed fails the gate instead of being skipped.
