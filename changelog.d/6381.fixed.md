**The cert-expiry self-test pins that the git shim restores `PATH` (#6381).** `run_gate_shimmed` prepends its scratch shim directory to the process `PATH` and restores it in a `finally`, but nothing checked that: removing the restore left the self-test at rc 0 and every later cell running with a deleted directory at the head of `PATH`. The new `(shim-path-restore)` cell snapshots `PATH` before the shim cells and fails by name if any of the success, gate-verdict or refusal paths changed it.
