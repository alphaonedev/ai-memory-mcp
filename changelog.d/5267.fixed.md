**The doc symbol-anchor gate now range-checks a backticked line range with spaces around the dash.** `scripts/check-doc-symbol-anchors.sh` matched a `src/<path>.rs:<a>-<b>` range only when the hyphen, en dash or em dash touched both numbers, so `` `src/x.rs:2 - 9999` `` passed unchecked past end-of-file. Whitespace around the dash is now allowed; a closed code span followed by prose ("`src/x.rs:2` - 9999 things") is still not a range. The `--self-test` gains five cases (#5267).
