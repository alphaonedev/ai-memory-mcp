**`memory_checkpoint_resolve` shape-validates `resolved_by` (#3368, partial).** The resolver principal is now checked with `validate_agent_id` (shape and reserved internal ids) before any lookup, state change or audit emit, so a value carrying control characters or injected text is refused instead of reaching the persisted row, the signed audit row and the log line (the #3009 vector, closed for `claimed_by`). The check is shape-only: it does not bind `resolved_by` to the node's own `AI_MEMORY_AGENT_ID`, because on the `epoch_advance` lane the resolver is the operator, authenticated by its detached signature. The supplied-but-unused `signature` / `resolved_at` half of #3368 is not fixed here, and no caller binding for this tool is added (it is not among the tools #3363 names).
