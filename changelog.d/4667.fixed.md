**PgBouncer: `session` mode is the only supported pool mode (#4667).** The
enterprise guide (section 5.6), `infra/pgbouncer` and the ROADMAP prescribed
`pool_mode = transaction`, which the Postgres adapter is not safe behind: the
migration advisory lock, the connect-time `search_path` and the connect-time
`statement_timeout` / `lock_timeout` live on the server session. The executed
probe `scripts/probe-pgbouncer-pool-mode.py` exits 1 on `transaction` and
`statement` pooling (a second client was granted the migration lock, saw the
first client's `search_path` and timeout, and a reused backend kept its temporary
table and prepared statement), exits 0 on `session`, and exits 2 when a client
never got a server connection. The guide states session mode (or no pooler), the
sizing rule `sum(AI_MEMORY_PG_POOL_MAX) (+ reserve_pool_size per PgBouncer pool)
<= max_connections - superuser_reserved_connections` with the T4/T5 numbers
recalculated, and guidance for deployments that already ran transaction mode.
`infra/pgbouncer` ships `pool_mode = session`, SCRAM, `server_reset_query =
DISCARD ALL`, verified TLS (`verify-full`) on both hops, separate admin and stats
roles, a loopback-only published port and no fixed password, and its smoke test
is now `smoke-test.py` (it reads `SHOW CONFIG`, uses a published image tag, and
passes secrets by environment only). The guide's section 5.6.4 step that copies
the role's SCRAM verifier into `userlist.txt` now fails and leaves the old file
in place when `psql` fails or does not return exactly one SCRAM verifier line,
and it keeps the admin and stats entries. `scripts/check-pgbouncer-pool-mode-claims.py`
(CI job `PgBouncer pool-mode claim gate (#4667)`, not yet a required context)
scans every tracked text file as a closed world: every line, wrapped pair of
lines and paragraph neighbourhood that mentions a pooler mode in any spelling
(plurals, `tx`/`xact`, `session` next to a pool word, a bare `mode =` key) must
be a bare `pool_mode = session` assignment, optionally with a fixed-vocabulary
comment, whose neighbouring lines are config lines, or be listed on
`scripts/qc-allowlists/pgbouncer-pool-mode-allow.txt` under a written reason.
An entry with no reason, a reason shorter than a sentence or the
`REASON REQUIRED` placeholder fails the gate, so
`scripts/regen-pgbouncer-pool-mode-allow.py --accept-new` cannot turn a red line
green without a human-written `--reason`. The self-test runs a red probe for
every wording the reviews found, a green probe per approved shape and a mutant
per rule (86 mutants, each killed; a mutant that survives fails the self-test).
Round 5 closes the round-4 findings: abbreviation, spelling, look-alike and
invisible-character detection (#4741, #5085); no silent skip of large, NUL-bearing
or UTF-16/32 files, streamed in windows, with unreadable files named in
`pgbouncer-pool-mode-unread.txt` under a reason (#5086, #5090); forbidden and filler
allowlist entries refused by the gate and by regen (#4961); a paragraph-sized
neighbourhood (#4950); each allowlist entry bound to its neighbourhood by a
`ctx:` fingerprint, re-bound only by `regen --refresh-context` (#5087, #5088);
guide 5.6.4 handles a tab-separated old entry (#4735); two false reasons
corrected (#5091); 17 more mutants (#5089).
Round 6 closes the round-5 findings: more look-alike, dash, filler and invalid-byte
forms folded back to the mode word (#5085), and look-alike partner words paired
(#5211); an ASCII magic prefix no longer makes a text file binary, a text-named
file in the unread list fails the gate, and that list takes its own
`--skip-reason` (#5206); a non-UTF-8 allowlist or unread list is a fault (rc 2),
not a traceback (#5207); `regen --refresh-context` needs a written `--reason` and
leaves a dated record above each re-bound entry (#5208); a `--reasons-file` reason
must stand without the quoted line (#5209); `regen --set-reason` re-writes a
selected entry's reason, and one false reason was corrected with it (#5091); a
group whose entries `--drop-stale` removes takes its reason with it (#5257). The
gate self-test now has 204 cases and kills 86 of 86 mutants (#5089), and
`scripts/test-regen-pool-allow.py` (22 cases, 25 of 25 mutants killed) runs in CI
(#5210). ROADMAP 4.B scopes the plan-cache statement to `src/` (#5077) and names
`server_reset_query = DISCARD ALL` as the guard for session-mode reuse (#5213).
Making the adapter safe under transaction pooling is tracked in #4679.
