**`memory_consolidate` no longer drops the namespace-standard warning on a read fault (#4977, WP-FAULT #6051).**
`is_namespace_standard` returns `Result<bool>` and propagates a `namespace_meta`
read error instead of folding it into `false`. When the check cannot be
completed the consolidation still commits, but the response `warning` now says
the standard check could not be completed and why, so an operator can verify
no consumed source was a namespace standard (fail closed to WARN, never to
silence).
