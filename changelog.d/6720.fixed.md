**The cert-expiry identifier line key is pinned against whitespace, case and trim normalisation (#6720).** The `(identifier, trimmed line text)` key of the #6427 comparison had only a digit edit pinned, so a refactor that collapsed interior whitespace, lower-cased the key or trimmed only ASCII blanks would have kept `--self-test` at rc 0. The `(value-edit-ws)` and `(value-edit-case)` cells require an interior-whitespace-only and a case-only edit of the value on the identifier line to be RED, and `(value-trim-nbsp)` requires a trailing U+00A0 to be trimmed like any other blank (GREEN). The OK banner names the three cells and `(doc-bound)` requires it.
