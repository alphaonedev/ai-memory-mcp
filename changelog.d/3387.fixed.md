Close a cross-tenant read oracle in `memory_detect_contradiction`: both ids are
now resolved through the same caller-scoped visibility funnel `memory_get`
uses, before any LLM call. Previously the tool read both rows unscoped, so a
caller who is told "memory not found" for an id still received that memory's
title in the response and had its full body shipped to the external model. A
row that exists but is not visible to the caller now refuses with the same
message an absent row does, so the tool cannot be used as a presence oracle.
