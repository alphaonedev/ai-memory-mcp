Reflection-export refusal diagnostics Debug-escape and bound stored memory IDs and namespaces, marking truncated values with their original byte length. Per-file write errors and wrote stdout lines apply the same escaping and bound to stored IDs while clean IDs print unchanged. Markdown frontmatter escapes control and Unicode format characters plus U+FFFE/U+FFFF. Canonical lowercase UUID identifiers, letter-leading namespaces with interior slashes, and reader-safe created_at timestamps retain their plain bytes; titles and other free text outside the safe set are double-quoted. The YAML 1.1/1.2 string allowlist and quoting preserve stored values without injecting keys or changing field types; created_at is plain only for years 0001-9999 and seconds 00-59, and reflection_depth remains an integer (#8605).
