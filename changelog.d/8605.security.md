Reflection-export refusal diagnostics Debug-escape and bound stored memory IDs and namespaces, marking truncated values with their original byte length. Per-file write errors and wrote stdout lines apply the same escaping and bound to stored IDs while clean IDs print unchanged. Markdown frontmatter quotes unsafe stored scalars, escapes control and Unicode format characters, and preserves string types for values resembling YAML booleans, nulls or numbers so stored values cannot inject additional YAML keys or change field types (#8605).
