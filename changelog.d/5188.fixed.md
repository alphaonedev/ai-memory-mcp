**The doc symbol-anchor gate now range-checks a `src/x.rs:a-b` line range written with an en dash or em dash.** `PATHLN` in `scripts/check-doc-symbol-anchors.sh` accepted only the ASCII hyphen as the range separator, so `:2–9999` (en dash) or `:2—9999` (em dash) was read as the single line 2 and a past-end-of-file or reversed end passed (#5188, residual of #4716). The separator class is now hyphen, en dash or em dash; no scanned doc used the dash forms, so no doc changed. The `--self-test` gains four cases.
