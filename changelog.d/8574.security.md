### Security

- **[auth] Header-trust opt-in is bootstrap-only on the credential routes**
  ([#8574](https://github.com/alphaonedev/ai-memory-mcp/issues/8574), umbrella
  [#8493](https://github.com/alphaonedev/ai-memory-mcp/issues/8493)).
  `AI_MEMORY_ADMIN_HEADER_TRUST=1` re-admitted a merely claimed admin header on
  pubkey bind, bind challenge, api-key mint and api-key revoke even when an
  enrolled per-agent key registry existed to backstop them. The opt-in now admits
  only while the registry is empty (bootstrap, or after every key is revoked; confirmed by an authoritative store read, and a store error refuses with reason `header_trust_refused_registry_unreadable`); once any api key is
  enrolled it is ignored on those four routes in every identity mode and the
  request is a `403` with a deny row, reason `header_trust_refused_registry_enrolled`.
