**[release] The bare, non-arch-qualified `ai-memory` binary is no longer published as a release asset (#6502, umbrella #6062).**
The release job's checksum sweep used to skip `dist/ai-memory` and leave it in
`dist/`, so the upload, attestation and GitHub release globs
(`dist/ai-memory*`) published it from every matrix leg under one name, each
leg overwriting the others'. The sweep now deletes it after the tarball and
the deb/rpm are built from it. Install from the arch-qualified
`ai-memory-<target>.tar.gz` (what `install.sh` already fetches) or the
packages. Regression: guard self-test cases `6502 ...`.
