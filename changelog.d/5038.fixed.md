The #3607 posture recapture now stamps the UTC date of the run in the header of `posture-legs-exit-codes.txt` instead of the fixed template date 2026-09-11, and refuses to finish if the header it wrote disagrees with the run date (#5038). The script is ported from `scripts/recapture-cert-3607-posture.sh` to `scripts/recapture-cert-3607-posture.py` under the Python-not-shell rule; its other outputs, including the sanitizer labels the cert certifies as byte-identical across re-issues, are unchanged (checked by running both against the same stub binaries). Already-committed evidence bundles are historical artifacts and stay as recorded. Hardening (#7648-#7652): every child process runs in its own fresh empty 0700 cwd with its own HOME, so a store keygen makes can no longer reach a leg and two consecutive runs give byte-identical captures; an existing bundle is verified against its committed `MANIFEST.sha256` before anything is published (a mismatch refuses the run, naming the file) and a new manifest is computed only over the files freshly captured; guarded paths are resolved with `os.path.realpath`; the sanitizer replaces every occurrence of each sensitive value, longest first, in raw, JSON-escaped and percent-encoded forms (a longer path that shares a prefix is over-redacted, which fails closed). Evidence tooling only; no product code changes.
