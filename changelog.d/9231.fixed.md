**CI: a host-slot wait with no slot is now a named outcome, not an idle hour (#9231).** `scripts/ci/host_semaphore.py` waits at most 600 s (was 3600 s) and ends without a slot as `infra-no-slot`: one error annotation whose message carries that token (a job log shows the message only), a title without colon, and the reserved exit code 82. A runner missing from `scripts/ci/host_slots.json` ends as `infra-unknown-runner` (83), a command that itself exits with 82, 83 or 84 is reported as 84 with an annotation, and the wrapper prints a `slot-acquired` line before it starts the command. The CI failure-classifier class for this outcome is tracked in #9833. `scripts/ci/host_slots_check.py` (run in the shard partition unit test step) parses the workflows and ties registered runners, serving runners, slot count and wait bound together.
