**CI: a host-slot wait with no slot is now a named outcome, not an idle hour (#9231).** `scripts/ci/host_semaphore.py` waits at most 600 s (was 3600 s) and ends without a slot as `infra-no-slot`: one error annotation whose message carries that token (a job log shows the message only), a title without colon, and the reserved exit code 82. A runner missing from `scripts/ci/host_slots.json` ends as `infra-unknown-runner` (83), a command that itself exits with 82, 83, 84 or 85 is reported as 84 with an annotation, and the wrapper prints a `slot-acquired` line before it starts the command. The wrapper refuses a wait above the 900 s idle seat ceiling of `scripts/ci/host_slot_limits.py` at run time, whatever its source (the `--max-wait-secs` flag, a repeated flag, or the `HOST_SEMAPHORE_MAX_WAIT_SECS` environment key), and also an empty, non-integer, 0 or negative wait and a flag that differs from the key: that ends as `infra-wait-refused` with exit code 85, before any slot is taken or the command starts. The CI failure-classifier class for these outcomes is tracked in #9833. `scripts/ci/host_slots_check.py` (run in the shard partition unit test step) parses the workflows and composite actions and ties registered runners, serving runners, slot count and wait bound together; it requires exactly one `--max-wait-secs` per wrapper call and refuses any run-text use of `HOST_SEMAPHORE_MAX_WAIT_SECS` other than its env mapping key or a plain `$` read. The checker reads every file under `.github` and accounts for every `host_semaphore` token in it: each one is a classified call (the literal path `scripts/ci/host_semaphore.py`, one configured `--name` and one `--max-wait-secs` within the ceiling, each call on a line checked on its own, comments and quoted arguments never read as flags) or a finding with its reason (a `-m` module run, a path split by a quote or an escape, an unlisted `HOST_SEMAPHORE_` name, a comment that is not a listed comment site, a file that is not UTF-8); a glob or an expression in the path is judged by the wrapper-step rules of #9847, and a path taken wholly from a variable is not text a scan reads (#9882 closes that at run time); the scan itself is #9844. A wait value is one grammar shared by the wrapper and the checker, `PLAIN_DECIMAL_PATTERN` in `scripts/ci/host_slot_limits.py`: ASCII digits with no leading zero, so non-ASCII, superscript and zero-padded digits are refused with a reason.
