**Dead `Write(...)` deny rules in `.claude/settings.json` (#6165).** The three
`permissions.deny` entries that enforce the "no agent-created files under /tmp,
/var/tmp, /private/tmp" project rule were written as `Write(path)`, a form Claude
Code never matches against file-editing tools (every launch printed "Permission
deny rule ... is not matched by file permission checks - only Edit(path) rules
are"), so the rule was a no-op. They are now `Edit(/tmp/**)`, `Edit(/var/tmp/**)`
and `Edit(/private/tmp/**)`, which cover Write, Edit and NotebookEdit. The new gate
`scripts/check-settings-deny-rules.py` (with `--self-test`, wired into the
`c8-precheck.yml` docs gate job beside the CLAUDE.md size guard) fails when any
`permissions.deny` entry starts with `Write(`.
