**The doc symbol-anchor gate's absent-path exemption no longer covers a file named by "split up into", "split across" or "renamed to".** These words name the live destination, like "split into" (#5264), but `It was renamed to `src/gone.rs`` and `It has been split up into `src/gone.rs`` still exempted the missing file through the window-wide absence wording. `scripts/check-doc-symbol-anchors.sh` now treats the three as positional destination wording: only an anchor BEFORE them is exempt, and `(was|been|got) split` followed by `up into` or `across` is not absence wording.
