The key-directory test helper `identity::test_key_dir::private_tempdir()` now allocates under `isolated_temp_root()` (a root outside HOME by construction, the #3859 precedent) instead of `$TMPDIR`, so the `mcp::tests::*` key-directory tests no longer panic on the #3355 HOME guard when `TMPDIR` is under HOME (#7450). The `handle_verify_*` test that bound `AI_MEMORY_KEY_DIR` to a raw `tempfile::TempDir` now uses `private_tempdir()` too, and the two `mcp_capabilities_*` tests take `verify_key_env_guard` because `memory_capabilities` resolves the key directory and so reads the process-global `AI_MEMORY_KEY_DIR` the verify tests rebind. Two new tests pin the posture. Test-infrastructure only; no production code changes.
