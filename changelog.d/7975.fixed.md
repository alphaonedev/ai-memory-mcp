**Cert-expiry `--self-test` is fail-closed on corpus size (#7975).** The self-test used to report
OK when an inherited `CERT_CORPUS_FILTER` (or `CERT_CORPUS_NESTED` plus a filter) left the corpus
with `ran=0`. The runner now drops every inherited `CERT_CORPUS_*` variable from the child's
environment, and refuses a summary that is not exactly the manifest-derived size (#7991; one case for the explicit
`--self-test-subset` form the corpus's own nested run uses). Proof:
`case_7975_selftest_fail_closed` in `scripts/ci/tests/test_check_cert_expiry_corpus.py`.
