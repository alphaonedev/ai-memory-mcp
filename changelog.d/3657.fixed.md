Wake-plane counters that already existed in-process now scrape on the
daemon `GET /metrics` registry (#3657). `SinkMetrics` drop methods and
the hub's per-cause drop counters dual-write onto
`ai_memory_wake_drops_total{cause=...}` (closed set, never a single
unlabeled drops total). Listener backstop polls increment
`ai_memory_wake_backstop_reliance_total` — that series is what tells an
operator the wake plane has quietly died. The daemon also publishes
`ai_memory_wake_fallback_state` (0 = unobserved, 1 = hub live, 2 =
backstop, 3 = forwarder installed and connecting) and
`ai_memory_wake_queue_pressure` (UDS hand-off occupancy). The gauge is a
measured ladder: a successful forwarder install reads `connecting`, never
`backstop`; `hub live` only after an authenticated handshake (a co-hosted
hub on install); `backstop` when a session breaks or the sink is dropped.
Two causes the audit named now have their own series — `delegation_revoked`
(the recipient's session authority no longer verifies) and `malformed_frame`
(an undecodable frame refused before routing) — and the hub writer counts
wake frames it actually wrote to a recipient socket as
`ai_memory_wake_delivered_total` (control frames excluded; also
`traffic.wakes_written_total` on the hub snapshot). No new HTTP surface:
#3646 owns exposition.

Review rework (#3657): the fallback gauge has ONE owner once a forwarder
exists — the forwarder task. `UdsWakeSink::spawn` stamps `connecting`
synchronously BEFORE `handle.spawn`, so on a multi-thread runtime the
task's own `hub live` / `backstop` can never be overwritten by a late
"connecting"; boot writes the gauge only for refusals that leave no task
(a post-spawn `AlreadyInstalled` refusal is left to the task, which stamps
`backstop` as its channel closes). The ordering is pinned on a
`multi_thread` runtime (`tests/wake_fallback_ordering_3657.rs`): with a
hub that accepts the socket but never answers the hello, the gauge reads
`connecting` the instant install returns and stays there until the
handshake deadline flips it to `backstop`.
