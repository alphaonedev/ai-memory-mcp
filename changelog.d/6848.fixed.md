**Key-directory tempdirs in integration tests no longer depend on the ambient umask (#6848).**
`rotate_with_succession_end_to_end` and 14 sibling tests handed a bare `tempfile` directory to
`keypair::save`, which refuses a group- or world-writable key directory (#3198). `tempfile` creates
directories with `0o777 & !umask`, so the tests passed under umask 022 (CI) and failed under umask 002.
They now request mode 0700 explicitly, and a `scripts/ci/tests` cell fails the build if a key-dir
tempdir is created without an explicit mode again.
