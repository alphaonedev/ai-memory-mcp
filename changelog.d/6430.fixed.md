**`--pre-apply` requires the carrier workflow to run for every pull request into the carrier (#6430, carrier gate #6143, #6232 follow-up).** `trigger_covers` in `scripts/check_carrier_ruleset_live.py` looked only at `branches` and `branches-ignore`, so an `on.pull_request` with a `paths` or `paths-ignore` filter, or a `types` list that drops `opened`, `synchronize` or `reopened`, passed the precondition although GitHub would skip the workflow for some pull requests and a required context would never report. Those shapes now fail closed; `docs/ci/CARRIER-BRANCH-GATES.md` states the rule.
