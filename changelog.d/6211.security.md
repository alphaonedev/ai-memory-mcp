### Security

- **[ci] The CLAUDE.md rule comparison masks unlabelled token shapes and a value on the line after its name**
  ([#6211](https://github.com/alphaonedev/ai-memory-mcp/issues/6211), follow-up of
  [#6163](https://github.com/alphaonedev/ai-memory-mcp/issues/6163), CWE-532).
  `scripts/claude-md-rule-compare.py` masked only labelled values and a few
  provider token prefixes, so a JSON Web Token, a GitLab personal access
  token, a Google API key, an npm token, a PuTTY private key file and a value
  written on the line after its credential name (`api_key:` then the value)
  reached the step summary. Each is now masked: the token shapes by their
  prefix (a JSON Web Token by its `eyJ` header alone), a PuTTY key from its
  `PuTTY-User-Key-File-<n>:` header to its `Private-MAC:` line, the first
  non-blank line after a credential name with no value unless that line is a
  heading, a table row, a nested `key:` (which passes the wait on) or a
  description of two or more prose words (never under a password or
  passphrase name), a nested `key: value` judged by its value, and every line
  of a YAML block scalar (`private_key: |`, `secret: >-`) more indented than
  its name line. The value lines are found on either side of the diff, so a
  value rotated under an unchanged name line, or under a name line outside
  the hunk, is masked on its `-` and its `+` row. The module docstring lists every masked shape. Regression
  cells: the `#6211` self-test cells.
