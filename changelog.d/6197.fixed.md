**The compliance script-name gate scans `.MD` documents and refuses symlinked directories (#6197).**
`scripts/check_compliance_script_names.py` matched documents with the case-sensitive
`*.md` pattern and did not descend into symlinked subdirectories, so a stale script name in
`docs/compliance/<name>.MD` or behind a symlinked directory passed. Documents are now
selected by a case-insensitive `.md` suffix. Symlinked directories, including
`docs/compliance/` itself, are refused as violations and never followed, and a document
symlink that resolves outside the repository is refused; a document symlink inside the
repository is still scanned.
