**The compliance script-name gate scans backtick runs in linear time (#6419).**
`scripts/check_compliance_script_names.py` measured every later backtick run, one character at a
time, for each unmatched run, so backtick runs of distinct lengths cost the number of runs times
the length of the line (400k characters took 42 seconds). One pass over the runs of a line now
pairs each run with the next of the same length. The verdicts are unchanged (a 300000-string
differential against the previous scan shows no difference).
The code-span pairing was later deleted with the rest of the Markdown emulation (#6141, design B).
