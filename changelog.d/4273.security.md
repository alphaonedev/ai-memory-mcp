**Forensic log files must be regular files: a symlink or FIFO under a daily forensic file name is refused.** A FIFO named like a daily forensic file (`forensic-YYYY-MM-DD.jsonl`) used to hang every `ai-memory` command at start-up, and a symlinked daily file sent forensic reads and appends outside the audit directory. Forensic log files, and the witness head-anchor and restore-sanction logs, are now opened without following a symbolic link and without blocking, and anything that is not a regular file is refused. A non-regular daily file makes the forensic log unavailable: the process degrades with the #4199 outage signals, or refuses to start under `AI_MEMORY_REQUIRE_FORENSIC_SINK`. `ai-memory audit verify --since <date>` also refuses such a directory instead of reading through it (#4273).
