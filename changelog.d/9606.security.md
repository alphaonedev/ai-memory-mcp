### Security

- **[export] Reflection and persona file exports pass the export confidentiality boundary**
  ([#9606](https://github.com/alphaonedev/ai-memory-mcp/issues/9606)). `ai-memory export-reflections`,
  the `post_reflect` auto-export hook and the auto-persona file export wrote memory rows to disk
  without the export taxonomy screen that `export`, the HTTP admin export and the forensic bundle
  apply. All three now run `screen_memories_for_export_audited` before render and before any path
  is opened.
  - **Forbidden classes are never written**: a row classified as private-key material, a master or
    threshold secret, a governance signing key or a biometric embedding is dropped, in Markdown and
    in JSON, and leaves exactly one signed `export.forbidden_class_refused` audit row. A failed
    audit append is logged and the row is still dropped.
  - **Secret values are written redacted** when secret screening is on; clean rows are written
    byte-identical to before.
  - **Operator signal**: the CLI prints the structured `export_report` stderr line when a row was
    withheld or redacted and exits `3` (`EXIT_EXPORT_INCOMPLETE`) when a row was withheld, the same
    contract as `export`; the other files are still written. The hooks write nothing for a
    withheld row, log a warning and stay notify-class.
