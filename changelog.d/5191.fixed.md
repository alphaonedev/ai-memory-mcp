**The doc symbol-anchor gate now checks an unbackticked `src/<path>.rs::<symbol>` anchor.** `scripts/check-doc-symbol-anchors.sh` matched the `QUAL` rule only when the anchor started with a backtick, so the same anchor in prose, an HTML code element or a code-block comment passed unchecked even when the file or symbol was gone, and the `BARE_LN` failure text tells authors to use exactly that form. A new `BARE_QUAL` rule resolves such an anchor like `QUAL` (the file must exist and every named symbol must be defined in it). At the PR base (e35c77eed) 18 scanned doc lines carried the form; two were stale (`docs/RUNBOOK-curator-soak.md`, `docs/memory-rules.html`, fixed under #5192 and #5193). The `--self-test` gains six cases (#5191).
