**CI: self-heal the AGE extension on the macos-fed runner (#6161).** A Homebrew
upgrade relinks the `postgresql@18` trees and drops the hand-built Apache AGE
files, failing `Configure enterprise-fed tier` with `extension "age" is not
available`. New `scripts/ci/ensure-age-extension.py` runs before `CREATE EXTENSION`
(macos-fed only). It treats AGE as present only when `pg_available_extensions`
lists it AND the five AGE files (`age.dylib`, `age.control`, three SQL scripts)
are installed with their pinned sha256. Otherwise it restores exactly those five
files from a node-local, brew-independent directory after rejecting symlinks,
foreign-owned or group/world-writable sources and hash mismatches. Writes are
atomic per process (safe for concurrent runners, lib before share; a failed run
leaves only complete, pinned files), the tier password reaches psql through `PGPASSWORD` rather than
argv (only the password: allowed path- and name-valued keys such as `sslkey` stay on argv). A URL is refused without printing any value when
it does not start with the exact lowercase `postgres://` or `postgresql://`; holds a TAB, CR, LF or NUL
(VT, FF, DEL and NBSP pass, as in libpq), raw space, `#`, `%` without two hex digits or `%00`; has more than one `@` in the host
part, an `@` after it or an empty host part; or has an empty query segment (one trailing `&` is
accepted), a segment without exactly one `=`, or a key outside a case-sensitive allowlist that is a
subset of the non-secret libpq parameters (`sslpassword`, `sslkeylogfile`, `require_auth`, `gsslib`, `replication`, `ssl` and the like
are refused, naming only known libpq keywords; `ssl=true` is a JDBC alias libpq maps to `sslmode=require`, refused so the mode is spelled `sslmode`). Decoding is percent-decoding only: `%XX` is one raw
byte, so `%FF` reaches `PGPASSWORD` byte-exact, and `+` stays literal (#6221, #6251). psql runs with a
15 s connect timeout (a URL `connect_timeout` must be 1..60, since libpq reads 0 as no limit, #6338) and
SIGTERM/SIGINT/SIGHUP stop the psql child, also during its spawn, instead of orphaning it with the password
(#6252, #6337, #6338). ci.yml runs the helper as `python3 -I` (#6339). Every failure is one `ensure-age-extension:` stderr line with a non-zero exit. Pinned by
`scripts/test/test_ensure_age_extension_6161.py`.
