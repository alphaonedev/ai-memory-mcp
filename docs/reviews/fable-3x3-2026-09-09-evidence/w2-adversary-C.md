## 3. Evidence-schema and five-clock corrections

**Five clocks vs the harness.** `continuity-cycle.py` does *not* measure clock 2. `resume_ms` (`:96`) = 500 ms sleep (`:91`) + loader drain + `start_daemon()` + time-to-health-200. Health-200 requires a storage connection check (`transport.rs:1235-1250`) and nothing about retrieval; the recall probe at `:104` is untimed. The harness already records the honest number — `health_ok_ms` (329–382 ms in `continuity-a56d9a.json`) — and the dashboard publishes `resume_ms` (997–1089 ms), which overstates the daemon's own restart-to-health by roughly 3×, in the daemon's *disfavour*. Corrections to §0.3: relabel historical figures `clock_1_harness_restart_to_health_ok_ms`, publish `health_ok_ms` as clock 1, mark clock 2 `NOT_MEASURED` (retrieval untimed), and note `embedder_ready` is a config constant. Clocks 3–5 can be measured **without a real host** using a harness-owned scripted agent and a mock external-effect sink; a real host is needed only for G2's per-host claim. The standard should say so instead of tying clocks 3–5 to G2.

**Schema.** Items already in the table above; the three that block any bundle today: no `durability_class` on receipts, no definition of `independent`, and `REQUIRED` fields that no `cargo test` row can fill. The standard does not make every cargo test SKIPPED — it makes every cargo test *unrecordable*, which is worse, because G7 then cannot be green by the standard's own §1.

## 5. Overall verdict

**Audit §0: SUSTAINED.** None of the counterexamples above reaches the five reasons in §0; the answer to the bet-the-farm question is still no. But three §3/§5 rows are overstated and should be rewritten before wave 3: **F7 falls as stated** (the 121 suites do run in two required contexts; the real gap is certified-pin and ignored-cell execution), **F9 is materially weakened** (docker-1461 D5/D6 is a tracked certified-pin mesh harness), and **F8 mis-attributes the 95 % figure** (which has no producer at all — a stronger point for N7). A27's mechanism is wrong and its defect is deeper (`embedder_ready` is a constant; the harness already holds the honest clock-1 number). F5 is hygiene, not evidence corruption.

**Standard: NOT ISSUABLE AS WRITTEN, for reasons internal to it.** Four clauses cannot be satisfied by any vendor on this tree — RPO needs a receipt field that does not exist, `PASS` needs a definition of "independent" that does not exist (and G7 is unsatisfiable without it), G8 names a script that cannot establish its property and §5's widened watch set has no enforcer, and §0.5 fails on two open `deferred-v1.x` issues with no §6 carrier. Three are gameable in ways a procurement reviewer would find in an afternoon (NOT-CERTIFIED as a parking lot for blockers, seven sessions as seven reviewers, RTO by scripted agent). The five-clock relabel in §0.3 is itself mislabelled. Every fix is a text or small-code change; none requires a redesign. Recommended for wave 3: apply the proposed text above, add §6 items for the receipt durability class, the cert-expiry widening, the bundle validator, `doctor --posture`, and the #2671/#2631 ruling, and re-run N1/N7/N24/N25/N27 scopes against §1 of this ballot.
