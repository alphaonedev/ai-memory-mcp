## Needed draft corrections and retained dissent

1. The assessment's voting section still says three jurors/nine ballots while its header and evidence promise seven/21. Replace that historical section only after the seven-juror waves actually finish. This is a documentary blocker, not a product defect.
2. Preserve the current distinction between correct empty responses, expected refusals, persisted state and successful missions. The NHI 0/8 strict mission outcome is a failed demonstration with dirty-state/scoring caveats, not proof of zero useful work. Favorable 4.5/5 questionnaires cannot override that outcome either.
3. Keep read fidelity as the strongest independently reproduced retrieval defect. Do not inflate additional missing SQL fields into unexecuted lifecycle/validity leak claims. Preserve genesis CID semantics separately from current revision.
4. The plan's abstention requirement is correctly about appropriate agent behavior, not mandatory deletion of every weak neighbor. Maintain positive-task tests so permanent refusal cannot win the benchmark.
5. The plan should accept external authenticated backup controls and an explicitly disclosed live-scan export contract. Its current independent-trust-anchor and snapshot-versus-live-scan wording does so. Product-native signing and full snapshot export are not universal prerequisites.
6. The assessment now credits real cascade/rewind, consumption, native enterprise, supply-chain and relevance infrastructure. Retain this. A recommendation to qualify one core contract is not a recommendation to abandon the working platform or rewrite storage wholesale.

My remaining dissent is against absolutist formulations of both sides: this is already useful infrastructure, and unknown comparative benefit does not erase successful state recovery. Conversely, a capable substrate plus many passing deterministic calls does not prove correct applied memory, reliable capture, or mission completion. The added D/F/G evidence changes the breadth of the practical remediation plan, not the basic conditional-yes/no/no ballot.
