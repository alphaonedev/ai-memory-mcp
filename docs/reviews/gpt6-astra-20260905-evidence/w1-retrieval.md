## Strongest counterargument and grand slam gates

Against my YES: for facts already in source/ADRs, CodeGraph + git + rg is authoritative and cheaper than maintaining a parallel corpus; memory adds stale-state failure modes. Against my NO: a disciplined caller can get every result by ID, supply namespaces, interpret confidence correctly and use external task tests. Those workarounds preserve value but impose tool/token costs that a grand slam should remove.

Grand slam means demonstrably superior agent outcomes on a preregistered task suite, not meeting every speculative TRACT end-state. Proposed gates: (a) zero value/version/provenance disagreement across get/search/keyword/hybrid/rerank/backend lanes on correction fixtures; (b) positive and negative retrieval suites with calibrated abstention and filter-before-budget completeness; (c) 100% critical approved directives recovered in controlled restart/interrupted-session tests; (d) randomized paired tasks against no memory and git+CodeGraph+RAG, showing task-success improvement and lower total tokens/tool calls, with confidence intervals and failure disclosures; (e) multi-epoch reflection experiments demonstrating factual precision does not deteriorate and corrections invalidate descendants. Do not invent performance or accuracy wins from the existence of these mechanisms.
