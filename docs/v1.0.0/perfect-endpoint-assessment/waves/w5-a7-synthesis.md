## ARCHITECTURE-FOR-INFINITY (frozen shape)

```
L0 EDGE     SQLite · MCP/CLI · local disk · keyword→semantic by RAM budget
            Role: capture, local recall, offline, mobile/IoT A–B
L1 MODULE   Postgres+pgvector+AGE · PgBouncer · admission control
            Role: multi-writer fleet, durable ANN, KG; bound by AGE write X
L2 MESH     W-of-N federation · eventual · local-first recall
            Role: compose modules; never one global linearizable brain
L3 DERIVED  HNSW/FTS/AGE projection · rebuildable · erase-lockstep
            Role: acceleration only; death ≠ amnesia if embeddings/claims hold
```

**Graduation (A1):** write lock / multi-writer → hub; multi-AZ/HA → hub; NFS multi-replica → never SQLite; past module AGE envelope → **compose modules**, do not stretch one primary; vector-only horizontal → optional specialist **beside** hub, not full MemoryStore replace.

**Endpoint physics (A4):** Tier ∅ = gateway-held L1; Tier A = L1 keyword; Tier B = light daemon; Tier C = hub+curator. Binary ~31 MB / idle ~18–25 MB. `FeatureTier::from_memory_budget` is the mechanical floor.

**Corpus infinity (A3):** unbounded *time* with **bounded live working set**, recoverable cold plane, signed EXPIRE/EVICT/DISTILL history — dual-plane instinct of W4-A6 applied to **capacity**.

**Cognitive infinity (A6 + W1-A3):** artifacts outlive models; improvement requires provenance + handoff + (eventual) decorrelated refinement — not a graveyard of unstamped prior-generation prose.
