## KILLER_OBJECTION

**“If perfect endpoint memory needs observability, evaluation, schema rigor, and evolutionary search, those belong in-tree for cohesion.”**

**Kill:** Cohesion of *products* is the opposite of separation-of-powers. Welding the optimizer, the viewer, and the law into one crate optimizes agent velocity and **destroys** the §0 claim (verifier-as-player, claim inflation, release coupling). Perfect systems are **federations of roles**, not monorepos of features. Grep-provable one-way dependency is the constitution, not a packaging preference.

---

## TOP_RISK

**Soft absorption via “just one helper.”**  
A thin `src/rqgm_export.rs`, a “temporary” in-process panel breeder for tests that graduates to production, or MCP tools that *look like* epoch administration without Ed25519 packs — each is a single PR that fails the §3 test only after the dependency graph already points the wrong way. Mitigations: keep `check-l3-boundary.sh` HARD-BLOCK; refuse compile deps from substrate→sibling; require operator-signed packs for any law mutation; ban “implements RQGM” claims forever (§25.6).

**Secondary risk:** Over-cutting **export/verify/FFI** while correctly cutting **apps** → perfect L3 and edge hosts cannot attach without private forks of the substrate.
