▸ Verified safe-by-default

Attempted, could not break.

  • Macaroon capability verify: version-pinned, closed issuer allowlist, verify_strict, subtle::ct_eq HMAC chain, attenuation-only append-only fold, domain separation. No forgery/attenuation/replay.
  • Webhook SSRF guard: DNS-rebind TOCTOU closed (resolve-then-pin), IPv4-mapped / NAT64 / CGNAT / cloud-metadata canonicalized and blocked, fail-closed DNS, redirects disabled.
  • SQL: parameterized on both backends + centralized escape_like_pattern + FTS5 sanitizer (#1846 OR-tree DoS guard). No Regex::new from user input.
  • Process spawns via Command::new(...).arg() (no shell); hook payload delivered over stdin. Skill-export path traversal fixed (#1453).
  • No request DecompressionLayer (no ingest decompression bomb); global 2 MiB body cap on all routes incl. bulk/import/sync; MCP stdio 16 MiB line cap.
  • verify_strict on all Ed25519 paths; fail-closed federation signature defaults at the v1.0 tip; forged signatures rejected regardless of the require-knob.
  • Per-peer partitioned + disk-persisted federation nonce cache; bulk/import admin-gated with per-row attestation (#1919); constant-time api-key compare (#1060); low-cardinality /metrics (no PII/keys/namespaces); admin fail-closed by default.
▸ Remediation

Prioritized plan.

  • Quick wins (contained): LM1 forget-LIKE escape · LM2 webhook ACK cap · L3 redirect policy · L4 Cypher self-defense.
  • Hardening defaults: M2 TLS-or-refuse for non-loopback · M3 default inflight cap · L1 drop ?api_key= · L2 auth backoff · L5 default REQUIRE_API_KEY on 0.0.0.0.
  • Architectural (root of H1/M1): bind the HTTP read/mutate/admin principal cryptographically — per-request attestation/signature or per-agent keys (re-opens the intent of #1570/#1582).
  • Defense-in-depth: LM3 partition link-verify replay cache + default require_nonce · L6 cert-SAN ↔ X-Peer-Id cross-check.

Full evidence, exploit scenarios, and per-finding remediation: tracking issue #2032. Reproduce the NSA re-verification from a fresh checkout: AI_MEMORY_NO_CONFIG=1 cargo test --features sal --test <name> per the control-test matrix.
