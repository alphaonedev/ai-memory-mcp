# cert-55 evidence sanitization (2026-08-28 20-check recapture)

These files are **recorded artifacts** of the §5.4(2) four-leg
`ai-memory doctor --posture enterprise-federation` run at **20 checks**.
They supersede the `cert-54/` §2 captures (18-check, 2026-08-13) as the
posture-leg evidence of record. They are **not** regenerated by CI;
each is a localhost run of the release-built binary at `f61dcab2`
(`release/v1.0.0` after Wave-2 B1/B2/B3). Removal-proof artifacts remain
in `cert-54/` (unchanged; this recapture is posture-only).

## What was sanitized

| Pattern | Replacement | Files |
|---|---|---|
| Absolute local repo path of the operator checkout | `<repo-root>` | `actual:` lines that named `AI_MEMORY_FED_PEER_FINGERPRINTS` / `AI_MEMORY_KEY_DIR` |

No other substitutions; verified zero occurrences of the operator
username, hostname, or home path across the bundle after substitution.

## What was NOT present (and therefore not redacted)

- No API keys, passphrases, PEM blocks, or `AI_MEMORY_DB_PASSPHRASE` values.
- No operator home directory beyond the substitutions above.
- No live droplet / LAN IPs.
- Private Ed25519 fixture keys used to generate `operator.pub.b64` were
  **not** copied into this directory (they live only in the uncommitted
  `.local-runs/cert-55-fixtures/keys/` tree).
