## Provenance note — the header of `posture-legs-exit-codes.txt`

The header reads `2026-09-11 #3607 re-issue recapture (22 checks) @ eae99be43`.
The date/issue label is the FIXED header string of the recapture script that
produced the legs (`scripts/recapture-cert-3607-posture.sh`, whose own header
declares the 22-check set); the `@ eae99be43` is that script's
`git rev-parse --short HEAD` of the worktree it ran in, recorded verbatim, and
it equals the bound SHA. The label is left as the script emitted it rather than
edited: a provenance line that records what actually ran is worth more than one
tidied to match the banner. The script's stale label is a cosmetic defect of the
script, not of the evidence.

- The Ed25519 key pair and the operator key used by the posture legs are
  **throwaway**, generated into a scratch fixture directory outside this bundle
  and not committed.

  `peer-attestation.json` a placeholder peer; neither names a real host.

  worktree paths and the host name were NOT captured into any file here: the
  four `.out` files are the `doctor --posture` renderings only, and
  `test-results.txt` carries the `test result:` summary lines only. Verified by
  grep for the scratch, mount and home prefixes across the bundle (zero hits).
