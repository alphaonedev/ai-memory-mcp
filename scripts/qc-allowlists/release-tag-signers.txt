# release-tag-signers.txt — the SSH keys allowed to sign a RELEASE tag (#3546).
#
# Read by scripts/release/verify-tag.sh through `gpg.ssh.allowedSignersFile`
# in the release preflight, from the workflow's own commit (never from the
# tree the tag points at). Native OpenSSH `allowed_signers`(5) format, the
# same format as enrolled-commit-signers.txt.
#
# HAND-ENROLLED, NEVER GENERATED FROM A LIVE API CALL. Adding a key here
# grants release authority; it is a reviewed PR to this file, like
# enrolled-commit-signers.txt. Every line must also appear VERBATIM in
# enrolled-commit-signers.txt (release signers are a subset of commit
# signers), which scripts/test/test-release-hardening.sh asserts. It is a
# separate file so that enrolling a future commit-signing key does not
# silently grant it release authority.
